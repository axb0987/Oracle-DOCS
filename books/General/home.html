Partner Offerings: Cloudflare at OCI

Cloudflare @ OCI lets OCI customers purchase and manage Cloudflare service bundles in the OCI Console using UCM credits.

What are partner offerings?

Oracle Cloud Infrastructure (OCI) provides a platform capability that integrates strategic partner offerings directly into the Oracle Cloud Console. This capability presents partner solutions alongside native OCI services, providing a unified customer experience. OCI customers can purchase partner offerings using Universal Credits Model (UCM) credits.

Minimum tenure is 1 year. Rates are also available in the OCI rate card.

Note

If you're looking for Marketplace, see Learn about Marketplace.

Before You Begin

Before you begin ensure that you:

  1. Have access to the OCI Console.

  2. Create a provisioning group.

    1. Create an IAM group for users who provision Cloudflare subscriptions.

    2. Add the required users or service accounts to the provisioning group.

    3. Configure policies for the provisioning group.

  3. Use the following policy to allow a provisioning group to create self-service Marketplace subscriptions for a specific provider type.

    Generic Policy Syntax

    Allow group <group-name> to {MARKETPLACE_SELF_SUBSCRIPTION_CREATE} in tenancy
                            where target.provisioning.subscriptionType = '<subscription-type>'

    Example Policy

    Allow group cloudflareProvisioningGroup to {MARKETPLACE_SELF_SUBSCRIPTION_CREATE} in tenancy
                            where target.provisioning.subscriptionType = 'CLOUDFLARE'

Example: group

cloudflareProvisioningGroup

Integrating Cloudflare @ OCI

You can purchase and manage Cloudflare service bundles directly from the Oracle Cloud Infrastructure Console by using Universal Credits Model (UCM) credits. The Partner Offerings capability integrates Cloudflare services with native OCI services and includes bundle subscription, usage visibility, and billing support.

Typical Workflow for Cloudflare @ OCI

  1. You sign in to the OCI Console and select the Cloudflare @ OCI offering from the Console service catalog. The Console displays the Cloudflare product details, including available bundles, pricing, and subscription information.

  2. You review the product information, select a bundle, enter the required Cloudflare provisioning request-account information, and select Request Provisioning to submit the request.

  3. The Console triggers a subscription notification event to the Email Delivery Service.

  4. The Email Delivery Service generates and sends a subscription email to the Oracle Business Operations Team containing:

    • OCI tenancy ID

    • Selected bundle/package

    • Your administrator details

  5. The Oracle Business Operations Team receives the notification and begins downstream operational and fulfillment activities.

Purchasing Cloudflare @ OCI from the OCI Console

Use the following steps to purchase a Cloudflare @ OCI bundle from the Oracle Cloud Infrastructure (OCI) Console. From the OCI Console navigation menu , select Identity & Security.

  1. Access the OCI Console.

  2. From the bundle list, select the bundle that you want to provision.

  3. On the Cloudflare @ OCI page, review the available bundle options and their descriptions.

  4. To review the details of a bundle, select the Provision button.

The bundle details page displays information such as:

  • Monthly base fee

  • Included services

  • Included traffic

  • Request limits

  • Edge rules

  • Additional features

Note

The information that displays depends on the bundle chosen.

  1. After you review the bundle details, return to the bundle selection list.

  2. From the bundle list, the bundle that you want to provision.

  3. Enter an Account name and an Account administrator email.

  4. Select Request provisioning and in the confirmation dialog box, review the confirmation message.

  5. Select Yes and review the purchase confirmation message.

The confirmation message indicates:

  • The bundle purchase succeeded.

  • An activation email is sent within the stated number of hours.

  • A support email address is available if you don't receive the activation email.

Activating Cloudflare @ OCI

After you purchase a Cloudflare bundle, you'll receive an account activation email from Cloudflare. Follow the activation instructions in the Cloudflare email.

Canceling Renewals, Upgrading Bundles, and Requesting SLA Credits

For the following requests, contact cloudflare-oci_us_grp@oracle.com and include the Request ID from the email. The Request ID is required.

  • Canceling bundle renewals: Customers can cancel subscriptions only if Cloudflare breaches the service-level agreement (SLA). Customers must provide written notice to Oracle within 5 business days after the SLA breach. Oracle deprovisions the account.

  • Upgrading bundles: You can upgrade to a higher-priced bundle during the subscription term. The pricing adjustment takes effect during the calendar month in which the upgrade occurs. You can't downgrade to a lower-priced bundle.

  • Canceling subscriptions. If Cloudflare doesn't meet the SLA, you can cancel a subscription.

  • Requesting service credits. If Cloudflare doesn't meet the SLA, you can request service. If you have issues accessing your services or haven't received confirmation from Cloudflare within 4 business days (USA), contact oci_orders@cloudflare.com by using the Billing support tile. Include the content of this request notification in your email.
