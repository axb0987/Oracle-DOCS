# Finding Details for IAM Resources

The new Oracle Cloud Console experience uses tabs to organize the information on the details page for each resource in the Identity and Access Management (IAM) service.
The following sections describe what information is displayed on the tabs for the resources in IAM. Depending on the resource type, you might see some or all the tabs listed here.
