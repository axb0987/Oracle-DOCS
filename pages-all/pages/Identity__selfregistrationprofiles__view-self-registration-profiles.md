# Viewing Self-Registration Profiles

Create self-registration profiles in IAM to manage self-registration for different sets of users, approval policies, and applications.
On the Self registration list page, select the name of the profile you want to view. If you need help finding the list page, see[Listing Self-Registration Profiles](https://docs.oracle.com/en-us/iaas/Content/Identity/selfregistrationprofiles/list-self-registration-profiles.htm)
