# Initializing an HSM Cluster

Learn how to initialize an HSM cluster.

When an HSM cluster is in the "Initialization Required" state, you must complete the following steps to initialize the cluster. After you complete the following steps, the cluster state changes from "Initialization Required" to "Initializing."

- [Download the Certificate Signed Request (CSR)](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/dedicated_kms_download_cert.htm).
- [Sign the Certificate Signed Request (CSR)](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/dedicated_kms_signing_cert.htm).
- [Upload the CSR certificates](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/tasks_dedicated_kms_uploading_cert.htm)
