# Creating a New File

This topic describes how to create a new file with Code Editor.
To create a new file:
- In the menu at the top left of the Code Editor window, click File .
- Select New File . This displays a dialog box requesting a name for the new file.
- Type the name of the new file and then click OK .
- Edit the file.
