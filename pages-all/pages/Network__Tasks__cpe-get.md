On the Customer-premises equipment list page, select the CPE that you want to work with. If you need help finding the list page or the CPE, see[Listing CPEs](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/cpe-list.htm).

The details page opens and displays information about the CPE object. Access the various resources associated with the CPE by selecting their links or tabs.
