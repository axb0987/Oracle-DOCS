# Editing a Sign-On Rule

Edit a sign-on rule for an identity provider.

- On the Sign-on policies list page, select the sign-on policy that you want to edit details. If you need help finding the list page, see[Listing Sign-On Policies](https://docs.oracle.com/en-us/iaas/Content/Identity/signonpolicies/list-signon-policy.htm).
- On the sign-on policy details page, find the rule you want to edit.
- Select the Actions menu for the sign-on rule and select Edit sign-on rule .
- Update the policy details. For more a full description of all the fields, see[Adding a Rule to a Sign-On Policy](https://docs.oracle.com/en-us/iaas/Content/Identity/signonpolicies/add-more-rules-policy.htm)
