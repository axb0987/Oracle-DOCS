## Cloud Guard

Oracle Cloud Guard enables you to monitor, identify, achieve, and maintain a strong security posture on Oracle Cloud. Use the service to examine your Oracle Cloud Infrastructure resources for security weaknesses related to configuration and your operators and users for risky activities. Cloud Guard can suggest, assist, or take corrective actions based on your configuration upon detection.
