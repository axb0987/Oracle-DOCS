## Solution Playbooks

Solution playbooks are targeted, cross-product explanations and architectures showing how to handle or implement a specific scenario on Oracle Cloud Infrastructure. They are available from the[Oracle Cloud Infrastructure Architecture Center](https://www.oracle.com/cloud/architecture-center/).

### Extend SaaS Applications with a Cloud Native Approach

The[Extend SaaS Applications with a Cloud Native Approach](https://docs.oracle.com/en/solutions/extend-saas-cloud-native/index.html#GUID-B1C4064D-C47E-4277-93F0-C004F6CF1C00)solution playbook shows how to design a SaaS extension for Oracle Fusion Applications Cloud Service using a Cloud Native approach.

In this high-level design, OCI Functions serves as the back-end implementation of a REST API, secured by Oracle Identity Cloud Service. Authentication is handled by Oracle Cloud Infrastructure API Gateway.
