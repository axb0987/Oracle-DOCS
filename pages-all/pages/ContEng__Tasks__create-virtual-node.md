# Creating a Virtual Node

Find out how to create a virtual node using Kubernetes Engine (OKE).

You create virtual nodes by creating a virtual node pool. You can only create virtual nodes in enhanced clusters. For more information, see[Creating Virtual Nodes and Virtual Node Pools in a New Cluster](https://docs.oracle.com/en-us/iaas/Content/ContEng/Tasks/contengcreatingvirtualnodes_topic.htm)
