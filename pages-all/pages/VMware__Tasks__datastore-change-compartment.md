# Moving a VMware Solution Datastore Between Compartments

Move a VMware Solution datastore to a different compartment in your Oracle Cloud Infrastructure tenancy.

## Using the Console

- Open the navigation menu and select Hybrid . Under VMware Solution , select Datastore .
The Datastores list opens. All datastores are displayed in a table.
- Select the datastore you want to work with.
The datastore's details page opens.
- From the Actions menu for the datastore that you want to move to a different compartment, select Move resource .
- In the Move resource panel, select the destination compartment from the list.
