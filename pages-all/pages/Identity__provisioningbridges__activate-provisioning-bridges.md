# Activating Provisioning Bridges

You can activate a single provisioning bridge, or you can activate multiple provisioning bridges simultaneously.

- On the Provisioning bridges list page, select the checkbox for each provisioning bridge that you want to activate. If you need help finding the list page or the recipe, see[Listing Provisioning Bridges](https://docs.oracle.com/en-us/iaas/Content/Identity/provisioningbridges/list-provisioning-bridges.htm).
- From the Actions menu (three dots) select Activate .
- When prompted, confirm the activation.
