# To change an IAM Database User Name

Use the Console to change a database user name.

To change your IAM database user name:
- Log in to the OCI IAM console.
- Select Identity&amp; Security .
- Under Identity , select Users .
- In the table of database users, locate your database user name and left select it.

The page for your user name is displayed.
- Select Edit User .
