# Managing Export Sets

Learn how to manage File Storage export sets.

An export set is a collection exports that control what file systems the mount target exports using NFSv3 protocol and how those file systems are found using the NFS mount protocol. Each mount target has an export set. Each file system associated with the mount target has at least one export in the export set.

There are some use cases for working directly with export sets, but most often, you[work with exports and their options](https://docs.oracle.com/en-us/iaas/Content/File/Tasks/exportoptions.htm).
