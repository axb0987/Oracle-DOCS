# Reserved IPv4 Addresses

Use reserved IPv4 addresses to statically allocate IPv4 addresses to resources within a subnet.
The following management actions are available for IPv4 addresses of all resources in a subnet:
- [Listing the IPv4 Addresses of All Resources in a Subnet](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv4-viewing.htm)
- [Adding a Reserved IPv4 Address](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv4-adding.htm)
- [Editing an Existing Reserved IPv4 Address](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv4-editing.htm)
- [Reserving an Existing IPv4 Address](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv4-reserving-existing-ipv4-address.htm)
- [Removing an IPv4 Address Reservation](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv4-removing-reservation.htm)
- [Reserving Existing IPv4 Addresses in Bulk](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv4-reserving-in-bulk.htm)
- [Removing IPv4 Address Reservations in bulk](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv4-removing-reservations-in-bulk.htm)
