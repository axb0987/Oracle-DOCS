## Application Performance Monitoring Synthetics

You can use Synthetic monitoring to monitor your application or API endpoint and detect potential availability and performance issues before the end-user experiences it. Synthetic monitoring enables proactive monitoring that helps developers and operators prevent problems before users are impacted. It provides the ability to run scheduled monitors to ensure application availability.
