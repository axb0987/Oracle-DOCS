# Deleting a Boot Volume Backup

Delete a backup of a boot volume in the Block Volume service.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Block/Tasks/delete-boot-volume-backup.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Block/Tasks/delete-boot-volume-backup.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Block/Tasks/delete-boot-volume-backup.htm#)
- 

- On the Boot Volume Backups list page, select the boot volume backup that you want. If you need help finding the list page or the boot volumes, see[Listing Boot Volume Backups](https://docs.oracle.com/en-us/iaas/Content/Block/Tasks/../Tasks/list-bv-boot-volume-backup.htm).
- From the Actions menu (three dots) for the boot volume backup, select Terminate .
- Select Terminate and confirm the selection when prompted.
