# Deleting an App Gateway

Delete an app gateway from IAM.

- On the App gateways list page, select the app gateway you want to delete. If you need help finding the app gateways page, see[Listing App Gateways](https://docs.oracle.com/en-us/iaas/Content/Identity/appgateways/list-app-gateways.htm).
- From the Actions menu (three dots) select Delete .
