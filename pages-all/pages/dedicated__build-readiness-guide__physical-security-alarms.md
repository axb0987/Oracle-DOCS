# Physical Security Alarms

Use the following requirements for physical security alarms.

Requirement Area Requirement Details
Alarm readiness Commission all physical security alarms before the space is handed over for service. Alarms must be active and monitored 24x7x365 by security staff.
Door alarms Alarm on doors held open and doors forced open for Oracle data center space, storage rooms, and suite entrances. Customer security must be alerted immediately when alarm conditions occur.
Held-open threshold Trigger an audible alarm if an entrance remains open too long. The audible threshold is 30 seconds.
Alarm log retention Retain alarm logs so events can be reviewed later. Keep at least 90 days of alarm logs and make copies available on request.
Emergency exits Fit emergency exits with crash bars and route activations into security monitoring. Activation must generate a local audible alarm and notify security.
Response expectation Define and staff a response process for alarms that affect Oracle space. Target a 15-minute physical response and preliminary email notification within 30 minutes of security learning of the event.
