# Editing a user's capabilities

Use the Console to edit a user's capabilities.

- On the Users list page, select the user whose capabilities you want to edit. If you need help finding the list page, see[Listing Provisioned Federated Users in the Console](https://docs.oracle.com/en-us/iaas/Content/Identity/userfed/viewing-provisioned-federated-users.htm).
- Select Edit user capabilities .
- Select or clear the checkbox next to a capability to add or remove the capability. See[Working with User Credentials](https://docs.oracle.com/en-us/iaas/Content/Identity/userfed/../usercred/usercredentials.htm)for details of each option.
