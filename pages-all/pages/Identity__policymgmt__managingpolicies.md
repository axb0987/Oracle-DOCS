# Overview of Working with Policies

This topic describes how to create, edit, and delete policies.

## Required IAM Policy

If you're in the Administrators group, then you have the required access for managing policies.

If you're new to policies, see[IAM Policies Overview](https://docs.oracle.com/en-us/iaas/Content/Identity/policymgmt/../policieshow/Policy_Basics.htm).

## Tagging

If you have permissions to create a resource, then you also have permissions to apply free-form tags to that resource. To apply a defined tag, you must have permissions to use the tag namespace . For more information about tagging, see[Resource Tags](https://docs.oracle.com/iaas/Content/General/Concepts/resourcetags.htm)
