- On the Software-Defined Data Centers list page, select the SDDC that contains the ESXi host that you want to work with. If you need help finding the list page or the SDDC, see[Listing SDDCs](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/../Tasks/sddc-list.htm).
- On the SDDC's details page, select vSphere clusters .
- Select the cluster that contains the ESXi host that you want to work with.
- On the cluster's details page, select ESXi hosts .
- Select the ESXi host that you want to work with.
