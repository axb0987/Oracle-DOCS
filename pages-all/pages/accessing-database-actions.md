# Accessing Database Actions

To access Database Actions:
- 

Open the navigation menu and select Developer Services .
- 

In the Database Tools section, select Database Actions . You can also access Database Actions from the Connection Details page of a specific database connection.
- 

Select a database connection. Use the Connection menu to select a database connection. Optionally, change the compartment to select a database connection in a different compartment. If there are no connections available, you can select the Create Connection option in the Connection menu to create a database connection. See[Using the Oracle Cloud Infrastructure Console](https://docs.oracle.com/iaas/database-tools/doc/using-oracle-cloud-infrastructure-console.html#GUID-8F5F7A3E-461F-4FF5-A487-C0F724EC7B4F)for more information.

After the connection is selected, the Launchpad (landing page) appears.
- 

To navigate to a feature such as Data Modeler, do either of the following:
- From the Launchpad page, select the Development tab and then select Data Modeler .
- From the sidebar, select the Development Menu icon and then select Data Modeler .
