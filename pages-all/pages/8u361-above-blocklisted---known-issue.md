# Lifecycle Management Installation Fails For JDK 8u361 and Later Releases

Lifecycle Management (LCM) standard installation of JDK 8u361 and later releases of JDK 8 will fail with a "Java runtime is blocklisted" error because of a known issue with Oracle JDK 8 installers. See[JDK 8u381 release notes](https://www.oracle.com/java/technologies/javase/8u381-relnotes.html#JDK-8310932)for more information.
