# Editing a Roving Edge Ultra Node

Edit a Roving Edge Ultra node in Oracle Cloud Infrastructure.

You cannot edit a Roving Edge Ultra node if you have already submitted it for approval.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Rover/Ultra/update_ultra.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Rover/Ultra/update_ultra.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Rover/Ultra/update_ultra.htm#)
- 

- 

In the Oracle Cloud Console, open the navigation menu, select Hybrid , then select Nodes .
- 

If needed, change the compartment to find the resource you want.
- 

(Optional) Select a State from the list under Tag filters to limit the device nodes displayed to that state.
- 

Select the Roving Edge Ultra node that you want to edit. The Roving Edge Ultra node's Details page appears.
- 

From the Actions menu at the top of the table, select Edit . The Edit Node dialog box is displayed.
- 

Make your edits. See[Creating an Ultra Node](https://docs.oracle.com/en-us/iaas/Content/Rover/Ultra/create_ultra.htm#top)for descriptions of the settings.
- 

Select Save changes .
