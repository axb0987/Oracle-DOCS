# Listing the Work Requests for Object Storage Private Endpoints

View a list of the Object Storage private endpoint work requests in a Oracle Cloud Infrastructure compartment.

When you create a new private endpoint or perform a task on an existing private endpoint, a work request is generated. You can view status of the work request and view its details.

## Using the Console

- On the Private endpoints list page, select the Object Storage private endpoint that you want to work with. If you need help finding the list page or the Object Storage private endpoint, see[Listing Private Endpoints in Object Storage](https://docs.oracle.com/iaas/Content/Object/Tasks/list-private-endpoint.htm).
The details page shows information about the private endpoint, both general information and links to its resources.
- Select Work requests .
The Work requests tab opens. Here you can view the work requests for the private endpoint. All private endpoint work requests in the selected compartment are displayed in a table.
- Select View details from the Actions menu .
The Work request details panel for the work request opens.
