# User Credentials for Roving Edge Infrastructure

Describes how to manage user credential tasks on your Roving Edge Infrastructure devices.

See[Managing User Credentials](https://docs.oracle.com/iaas/Content/Identity/Tasks/managingcredentials.htm)in the Oracle Cloud Infrastructure documentation for more information on this feature.

This section describes the following user credential types:
- 

[Auth Tokens](https://docs.oracle.com/en-us/iaas/Content/Rover/IAM/User_Credentials/Auth_Token/auth_token_management.htm#AuthTokenManagement)
- 

[API Signing Keys](https://docs.oracle.com/en-us/iaas/Content/Rover/IAM/User_Credentials/API_Key/api-key_management.htm#APISigningKeyManagement)
- 

[OAuth 2.0 Client Credentials](https://docs.oracle.com/en-us/iaas/Content/Rover/IAM/User_Credentials/OAuth_2.0/oauth2-credential_management.htm#SecretKeyManagement)
- 

[Customer Secret Keys](https://docs.oracle.com/en-us/iaas/Content/Rover/IAM/User_Credentials/Secret_Keys/customer-secret-key_management.htm#SecretKeyManagement)
