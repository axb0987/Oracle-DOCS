# Performing Bulk Resource Actions

Whether working with the results of a search, query, or resource collection, you can perform bulk actions on resources instead of repeating the same actions on individual resources.
Search supports the following tasks when working with resources in bulk:
- [Viewing Work Requests](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/view-work-requests.htm)
- [Managing Tags](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/manage-tags.htm)
- [Moving Resources](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/move-resources.htm)
- [Deleting Resources](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/delete-resources.htm)
