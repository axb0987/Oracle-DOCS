## Application Performance Monitoring Control Plane

Application Performance Monitoring provides a comprehensive set of features to monitor applications and diagnose performance issues. It also provides a set of APIs for tenants to perform operations like create, update, delete, and list Application Performance Monitoring domains and work request APIs to monitor the progress of these operations.
