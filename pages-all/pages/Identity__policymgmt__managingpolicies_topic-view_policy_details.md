# Getting a Policy's Details

Get details for an IAM policy.

On the Policies list page, select a policy to view its details page. If you need help finding the list page, see[Listing Polices](https://docs.oracle.com/en-us/iaas/Content/Identity/policymgmt/managingpolicies_topic-To_get_a_list_of_your_policies.htm#console).
