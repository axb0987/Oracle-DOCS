# Running Roving Edge Infrastructure Device Diagnostic Commands

Learn how to use diagnostic commands to run pre-defined commands on your Roving Edge Infrastructure devices for quick troubleshooting.
Note  
  

Currently, only VNIC Packet Capture is supported by these diagnostic commands.

You can perform the following device diagnostic command tasks:
- 

[Creating a diagnostic command](https://docs.oracle.com/en-us/iaas/Content/Rover/Device_Software/create-diagnostic-commands.htm#top)
- 

[Listing diagnostic commands](https://docs.oracle.com/en-us/iaas/Content/Rover/Device_Software/list-diagnostic-commands.htm#top)
- 

[Getting a diagnostic command's details](https://docs.oracle.com/en-us/iaas/Content/Rover/Device_Software/get-diagnostic-commands.htm#untitled1)
- 

[Downloading a diagnostic command](https://docs.oracle.com/en-us/iaas/Content/Rover/Device_Software/download-diagnostic-commands.htm#console)
- 

[Canceling a diagnostic command in progress](https://docs.oracle.com/en-us/iaas/Content/Rover/Device_Software/canceling-diagnostic-commands.htm#top)
