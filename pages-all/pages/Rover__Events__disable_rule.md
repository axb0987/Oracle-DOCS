# Disabling an Events Rule for a Roving Edge Infrastructure Device

Describes how to disable an events rule on your Roving Edge Infrastructure device.

## Using the Device Console

- Open the navigation menu and select Events &gt; Rules . The Rules page appears. All events rules are listed in tabular form.
- Select the events rule that you want to edit. The events rule's Details page appears.
- Select Disable .
- Confirm the disabling of the events rule.
