# Updating a Self-Registration Profile

Edit options in self-registration profiles in IAM. For example, you can assign the profile to new groups or change the allowed email domains.

- On the Self registration list page, select the profile you want to edit. If you need help finding the list page, see[Listing Self-Registration Profiles](https://docs.oracle.com/en-us/iaas/Content/Identity/selfregistrationprofiles/list-self-registration-profiles.htm).
- From the the Actions menu (three dots) for the profile you want to edit, select Edit .
- On the Edit self-registration profile page, make the changes.
