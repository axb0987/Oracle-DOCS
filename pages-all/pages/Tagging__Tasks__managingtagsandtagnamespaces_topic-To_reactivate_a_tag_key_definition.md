# Reactivating a Tag Key Definition

Reactivate a retired tag key definition.

- On the Tag namespaces list page, select the namespace that you want to work with. If you need help finding the list page, see[Listing Tag Namespaces](https://docs.oracle.com/en-us/iaas/Content/Tagging/Tasks/../Common/../Concepts/list-tagnamespace.htm).
- On the Tag namespace details page, in the Tag key definitions section, select the tag key definitions you want to reactivate.
- From the Actions menu, select Reactivate .
- In the Reactivate selected tag key definitions dialog box, select Reactivate .
Or, use the Actions menu (three dots) to reactivate a single tag key definition.
