# Analyze

Provides information on the built-in tools that allow you to explore your data with reports, analytics, and visualization.
- 

[Build Reports and Dashboards Using Oracle Analytics](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-reports.html#GUID-BAD56847-C3E6-44D3-9711-DA088B3A9BA2)

You can use Oracle Analytics Cloud and Oracle Analytics Desktop with Autonomous AI Database.
- 

[Creating Dashboards, Reports, and Notebooks with Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/create-dashboards.html#GUID-56831078-BBF0-4418-81BB-D03D221B17E9)

Autonomous AI Database includes support for building dashboards, reports, and notebooks for data analysis using Oracle Analytics Desktop and Oracle Machine Learning (OML) Notebooks.
- 

[Use Oracle Spatial with Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/spatial-autonomous-database.html#GUID-2090A775-E049-4695-B371-E583313A5F8C)Oracle Spatial Database is included in Autonomous AI Database, allowing developers and analysts to get started easily with location intelligence analytics and mapping services.
- 

[The Data Analysis Tool](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/data-analysis-tool.html#GUID-9D4C60B4-F35F-4654-AAFD-4A81ED9C877A)The Data Analysis tool enables you to create Analytic Views with multidimensional metadata.
- 

[The Catalog Tool](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/catalog-entities.html#GUID-A15016CD-03EF-4DB8-926C-7DB0A87708B7)

The Catalog Tool allows you browse, search and discover data in, and connected to, the Oracle Autonomous AI Database.
- 

[The Jobs Feature](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/jobs-feature.html#GUID-8F037C07-40A9-4711-915C-499FA1CD160D)The Jobs feature automates the tasks run by the Data Studio suite of tools. It can be scheduled to run at specific intervals or triggered by certain events.
- 

[The Data Insights Page](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/data-insights.html#GUID-14C63B48-F055-422D-B39F-A66F6D1206F2)

The Data Insights page displays information about patterns and anomalies in the data of entities in your Oracle Autonomous AI Database.
- 

[Use Oracle OLAP with Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-olap.html#GUID-6C7B7649-6F66-4D66-B735-CFF73B59E698)

Oracle OLAP is available on Autonomous AI Database. Oracle OLAP supports uses such as planning, forecasting, budgeting, and analysis.
