# DevOps Plugin for Jenkins

This topic provides information about installing, configuring, and using the Oracle Cloud Infrastructure (OCI) DevOps plugin for Jenkins.

You can use the[DevOps](https://docs.oracle.com/iaas/Content/devops/using/devops_overview.htm)plugin to upload artifacts, and run deployments on OCI from Jenkins. A Jenkins controller instance with the DevOps plugin can upload artifacts to the Artifacts Registry repository and trigger the deployment pipeline for deploying those artifacts.
