# Rolling Back the Roving Edge Infrastructure Device Software to the Previous Version

Learn how to roll back the Roving Edge Infrastructure device's software to the previously-installed version.

You can only roll back a device's system software once per software version. If you have already rolled back your system software from what had been your current version, you can't roll the system software back a subsequent time to revert to an even earlier software version.
- 

Sign in to the Device Console of the Roving Edge device you plan to roll back.
- 

In the navigation menu, select Node Management &gt; Nodes .

The Nodes page is displayed.
- 

Select the Actions menu ( ) and select Rollback .
- 

Confirm the rollback.

Your Roving Edge Infrastructure device's software is rolled back to the previous version.
- 

Select the System Status icon ( ) in the upper right corner of the Device Console.
