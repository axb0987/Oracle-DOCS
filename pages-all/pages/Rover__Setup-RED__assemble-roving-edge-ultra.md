# Assemble Roving Edge Ultra

- 

Remove the components from the transportation case.
Note  
  

The case is for transportation purposes only. When Ultra is operational, it must be removed from the case.
- 

Secure the battery pack to the rear of the Ultra using the captive screws.

Item Description
A Ultra device
B Battery pack
C Power adapter
- 

Secure the power adapter to the battery pack using the captive screws.
