# Can't Add an Hourly Schedule to a Snapshot Policy

When adding a schedule to a snapshot policy, a "More than one hourly schedule present" error occurs.

A snapshot policy can't have more than one schedule set to create snapshots hourly. For more information, see[Schedule Types and Timing](https://docs.oracle.com/en-us/iaas/Content/File/Troubleshooting/../Tasks/snapshot-policies-and-schedules.htm#snapshot-policies-and-schedules__schedule-types).
