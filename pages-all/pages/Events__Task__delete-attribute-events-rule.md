# Removing an Attribute from an Events Rule

Remove an attribute from a rule.

See[Matching Events with Filters](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Concepts/filterevents.htm)for more information on using event types in a rule.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Events/Task/delete-attribute-events-rule.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Events/Task/delete-attribute-events-rule.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Events/Task/delete-attribute-events-rule.htm#)
- 

- Navigate to the events list page. If you need help finding the list page, see[Listing Events Rules](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Task/list-events-rule.htm).
- Select a rule and then select Conditions .
- Under Attributes , select the checkbox next to the attribute you want to remove.
Tip  
  
To select the entire list, select the checkbox in the header row.
- Select Remove .
- Confirm when prompted.
- 

See[Matching Events with Filters](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Concepts/filterevents.htm)for information on how to use attributes.
