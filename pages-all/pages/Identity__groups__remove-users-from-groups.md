# Removing Users from a Group

Remove users from an identity domain group.

- On the Domains list page, select the domain from which to remove users. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/groups/../domains/to-view-identity-domains.htm).
- On the domain details page, perform one of the following actions depending on the option that you see:

- Select the User management tab.
- Under Identity domain on the left side of the page, select Groups .
- Find the Groups table listing and select the group from which to remove users.
- On the group details page, perform one of the following actions depending on the option that you see:

- Select the Users tab.
- Under Resources , select Users .
- Select the Actions menu (three dots) for the group to delete, and then select Remove user from group .

Tip  
  
To search for a user, enter all or part of the beginning of the user name, first name, or last name of the user and then press Enter .
