# Getting Started

Configure Oracle Cloud Infrastructure Email Delivery to use the functionalities of the Email Delivery service. You can configure using the Console, REST API, SDKs, CLI, or Terraform.

To get started with Email Delivery using the Console, complete the following steps:
- [Creating a Group and User](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-create-group.htm)
- [Create user permissions](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-create-policy.htm)
- [Set up HTTPS email submission](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/../Concepts/email-submission-using-https.htm)or[Create SMTP credentials](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-create-smtp-credentials.htm)
- [Create email domain](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-create-email-domain.htm)
- [Enable logs for troubleshooting](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/../Tasks/enablelogs_using-the-console.htm)
- [Configure SPF](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/../Tasks/configurespf.htm)
- [Configure DKIM](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/../Tasks/configure-dkim-using-the-console.htm)
- [Create an approved sender](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-Create_an_approved_sender.htm)
- [Configure SMTP connection](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-Configure_the_SMTP_connection.htm)
- [Send an email](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-Begin_sending_email.htm)
- [Validate email delivery](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-Validate_email.htm)
