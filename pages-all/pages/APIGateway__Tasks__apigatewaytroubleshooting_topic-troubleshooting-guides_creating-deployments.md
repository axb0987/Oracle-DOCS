# Troubleshooting Guides for Creating API Deployments

Use these troubleshooting guides to diagnose and resolve issues related to API deployment creation.

These API Gateway troubleshooting guides provide in-depth information about specific issues related to API deployment creation, including symptoms, possible causes, and likely resolutions:
- [Header transformations do not work as expected](https://docs.oracle.com/en-us/iaas/Content/APIGateway/Tasks/apigatewaytroubleshooting_topic-header_transformations_do_not_work.htm)
- [Response cache TLS handshake fails](https://docs.oracle.com/en-us/iaas/Content/APIGateway/Tasks/apigatewaytroubleshooting_topic-response_cache_tls_handshake_fails.htm)
- [HTTPS backend TLS handshake fails](https://docs.oracle.com/en-us/iaas/Content/APIGateway/Tasks/apigatewaytroubleshooting_topic-https_backend_tls_handshake_fails.htm)
- [Dynamic authentication selector configuration is invalid, or a multi-auth deployment later fails to match requests to an authentication server](https://docs.oracle.com/en-us/iaas/Content/APIGateway/Tasks/apigatewaytroubleshooting_topic-dynamic_authentication_selector_configuration_is_invalid.htm)
