# Listing the FQDNs for an Object StoragePrivate Endpoint

View a list of the fully-qualified domain names (FQDNs) for an Object Storage private endpoint.

## Using the Console

You can view and copy the FQDNs of a Object Storage private endpoint.

- On the Private endpoints list page, select the Object Storage private endpoint that you want to work with. If you need help finding the list page or the Object Storage private endpoint, see[Listing Private Endpoints in Object Storage](https://docs.oracle.com/iaas/Content/Object/Tasks/list-private-endpoint.htm).
The details page shows information about the private endpoint, both general information and links to its resources.
- Select FQDN .

The FQDNs tab opens. Here you can view the fully qualified domain names for the private endpoint.
- (Optional) Select one of the following commands from the Actions menu to copy the FQDN you want:

- Copy v2 fqdn : Copy the fully qualified domain name prefix for the Object Storage API.
- Copy swift fqdn : Copy the fully qualified domain name prefix for the AWS S3 Compatibility API.
