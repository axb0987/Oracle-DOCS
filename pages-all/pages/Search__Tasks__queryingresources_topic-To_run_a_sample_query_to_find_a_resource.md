# Running a Sample Query

Sample queries demonstrate the structured query language syntax and let you change or replace example values to find resources in the tenancy.
- 

In the top navigation bar, select Search for resources, services, documentation, and Marketplace , and then select Advanced resource query .
- 

In the resource explorer, either select Sample advanced resource query or select Select Sample Query , depending on the option available, and then select one of the listed sample queries. For an explanation of sample queries, see[Sample Queries](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/../Concepts/samplequeries.htm).
- 

Verify that the query language in the query text box satisfies your needs. Change all example values. Add, delete, or change clauses and their contents, as appropriate, and then select Search .
- 

If needed, change what regions to search: next to Applied filters , select Region name , select the checkbox next to up to three regions that you want to include, and then select Apply filter .
- 

To filter results further, change the language of the query. For more information about syntax for resource queries, see[Search Language Syntax](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/../Concepts/querysyntax.htm).
Note  
  
In advanced query mode, while you can filter and sort results by changing the query language, you can't filter or sort results through the results list displayed in the Console. Also, if you switch to advanced query mode from basic search mode, by default, results are sorted by the time the resource was created. You can change to sorting results by best match by removing the`sorted by`clause in the query language.
