# To change an IAM Database Password

Use the Console to change a database password.

To change your IAM database password, delete your current password and then create a new one. See[To Delete an IAM Database Password](https://docs.oracle.com/en-us/iaas/Content/Identity/Tasks/managingcredentials.htm#delete_iam_db_password)and[To create an IAM Database Password](https://docs.oracle.com/en-us/iaas/Content/Identity/Tasks/managingcredentials_topic-to_create_an_iam_database_password.htm)
