# Objects for Roving Edge Infrastructure

Describes how to manage the object storage object tasks, including creating, updating, and deleting objects, on your Roving Edge Infrastructure.

Stored objects can be as small as 0 bytes or as large as 10 TiB.

You can perform the following object management tasks:
- 

[Listing Objects](https://docs.oracle.com/en-us/iaas/Content/Rover/Object_Storage/Object/list_object.htm#top)
- 

[Getting an Object's Details](https://docs.oracle.com/en-us/iaas/Content/Rover/Object_Storage/Object/head_object.htm#HeadObject)
- 

[Uploading an Object](https://docs.oracle.com/en-us/iaas/Content/Rover/Object_Storage/Object/put_object.htm#top)
- 

[Downloading an Object](https://docs.oracle.com/en-us/iaas/Content/Rover/Object_Storage/Object/get_object.htm#top)
- 

[Deleting an Object](https://docs.oracle.com/en-us/iaas/Content/Rover/Object_Storage/Object/delete_object.htm#top)
- 

[Bulk Object Management](https://docs.oracle.com/en-us/iaas/Content/Rover/Object_Storage/Object/bulk_object_management.htm#top)
- 

[Multipart Upload Tasks](https://docs.oracle.com/en-us/iaas/Content/Rover/Object_Storage/Object/Multipart_Upload/multipart_uploads.htm#MultipartUploadTasks)

See[Managing Objects](https://docs.oracle.com/iaas/Content/Object/Tasks/managingobjects.htm)
