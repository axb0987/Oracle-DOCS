# Change Management

Use this section to understand how Dedicated Region changes are communicated, approved, and coordinated with customer operations.

Dedicated Region uses the tested OCI change management practices that other Oracle Cloud regions use. Changes can include software updates, new services, infrastructure maintenance, security updates, capacity expansion, and other operational activities.

Oracle provides 15-day advance notification for known disruptive changes that can make a service or system unavailable, even briefly.

Disruptive change notices are communicated through Oracle customer notification channels.

Non-disruptive changes are communicated through the OCI Announcements service in the OCI Console.

Customers can subscribe to announcements through email, SMS, and other supported delivery protocols.

Customer change boards must track Oracle notices, firewall or allowlist changes, capacity expansion work, application failover windows, and rollback criteria.
