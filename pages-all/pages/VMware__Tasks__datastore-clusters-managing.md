# Managing VMware Solution Datastore Clusters

Use the VMware Solution Datastore Management feature to organize and manage datastore clusters.

A datastore cluster groups multiple datastores together, allowing you to add existing datastores or create new ones and attach them to the cluster. When you attach a datastore, the underlying block volumes are automatically associated with the Compute instances in the datastore cluster, streamlining infrastructure setup and management.

You can also detach a datastore cluster, and the process automatically detaches the associated block volumes from the Compute instances in the SDDC Cluster.
