# Listing All Object Storage Logs in a Compartment

Access and manage the logs for all Object Storage buckets in a compartment.

You can view all the Object Storage Read Access Events and Read Access Events logs in a compartment through the View or manage logs panel in the Console. Here you can monitor the total number of enabled logs and those available for being enabled. You can also access and view logs associated for a particular bucket and enable or disable the Read Access Events and Read Access Events logs. See[Enabling an Object Storage Bucket Log](https://docs.oracle.com/en-us/iaas/Content/Object/Tasks/create-log.htm)for more information.

## Using the Console

- Open the navigation menu and select Storage . Under Object Storage &amp; Archive Storage , select Buckets .
The Buckets list page opens. All buckets in the selected compartment are displayed in a table.
- To view the logs in a different compartment, use the Compartment filter to switch compartments.
You must have permission to work in a compartment to see the resources in it. If you're not sure which compartment to use, contact an administrator. For more information, see[Understanding Compartments](https://docs.oracle.com/iaas/Content/GSG/Concepts/settinguptenancy.htm#Understa).
- Select View or manage logs .
The View or manage logs panel opens.
The View or manage logs panel displays information regarding the Object Storage bucket logs in the compartment, such as which are active and the total number of available logs. You can also enter a specific log to perform tasks on it, such as enabling or disabling it.
