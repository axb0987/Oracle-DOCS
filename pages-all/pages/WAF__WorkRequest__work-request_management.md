# Work Requests for Web Application Firewall

Learn how to manage work requests web application firewall policies.

Work requests are associated with all WAF top-level resources: policies, firewalls, and network address lists. A single work request is associated with one of these resources, either a policy, a firewall or a network address list. All changes to these resources are asynchronous and return a work request.

Access the following work request information using the CLI or API.
