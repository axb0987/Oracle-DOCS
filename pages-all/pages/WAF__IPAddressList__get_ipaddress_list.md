# Getting an Edge Policy IP Address List's Details

Describes how to get the details of an IP address list for an edge policy.

- [Console](https://docs.oracle.com/en-us/iaas/Content/WAF/IPAddressList/get_ipaddress_list.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/WAF/IPAddressList/get_ipaddress_list.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/WAF/IPAddressList/get_ipaddress_list.htm#)
- 

- Open the navigation menu and select Identity &amp; Security . Under Web Application Firewall , select Edge Policy Resources .
The Policies list opens. All edge policies are listed in a table.
- Select the Compartment from the list.
- Select IP Address Lists under Resources .

The IP Address Lists page appears.
- Select the IP address list whose details which you want to get.

The IP Address Lists Details dialog box appears.

The Details page contains information about the IP address list, both general information and links to its resources. Some items in the page are read-only, while other items allow you to edit and update the IP address list configuration.
