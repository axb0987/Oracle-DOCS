# Deleting a Group

Delete groups from an identity domain in IAM.

- On the Domains list page, select the domain that contains the group to delete. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/groups/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the User management tab.
- Under Identity domain on the left side of the page, select Groups .
- Select the Actions menu (three dots) for the group to delete, and then select Delete .
