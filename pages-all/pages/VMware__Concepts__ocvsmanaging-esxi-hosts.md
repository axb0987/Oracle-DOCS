# VMware Solution SDDC ESXi Hosts

Learn how to create and manage ESXi hosts for an SDDC using Oracle Cloud Infrastructure VMware Solution.

Note  
  
To create and manage VMs on the ESXi hosts, use VMware's vCenter utility

To use Oracle Cloud Infrastructure, an administrator must be a member of a group granted security access in a policy by a tenancy administrator. This access is required whether you're using the Console or the REST API with an SDK, CLI, or other tool. If you get a message that you don't have permission or are unauthorized, verify with the tenancy administrator what type of access you have and which compartment your access works in.

For more information and examples of OCI IAM policies you can use to create, modify, and delete VMware Solution resources, see[VMware Solution Identity and Access Management (IAM) Policies](https://docs.oracle.com/en-us/iaas/Content/VMware/Concepts/../Reference/iam-policy-reference.htm).
