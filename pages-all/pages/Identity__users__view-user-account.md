# Viewing User Details

View the details of a user account in an OCI IAM identity domain including name, OCID, contact information, and other capabilties.

- On the Domains list page, select the domain in which you want to work. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/users/../domains/to-view-identity-domains.htm).
- On the domain details page, perform one of the following actions depending on the option that you see:

- Select the User management tab, and then go to the User section of the tab.
- Under Identity domain on the left side of the page, select Users .
