# Roles and Responsibilities

The shared responsibility model for operating the Dedicated Region inside a customer data center.

Dedicated Region operations are shared between Oracle and the customer. Oracle manages the cloud stack and Oracle-owned equipment. The customer manages the data center facility, environmental services, physical access program, and certain connectivity responsibilities. Use the following responsible, accountable, consulted, and informed (RACI) summary for implementation planning.

Component or Activity Customer Role Oracle Role
Oracle-managed cloud racks Informed Responsible, accountable, consulted
Access for Oracle operations personnel for setup and hardware support Consulted, informed Responsible, accountable
Customer data center power and cooling Responsible, accountable Consulted, informed
Customer floor space Responsible, accountable Consulted, informed
Physical security of data center facilities Responsible, accountable Consulted, informed
Physically secure, upgrade, and patch Oracle racks Consulted, informed Responsible, accountable
Dedicated Region IaaS and PaaS networking gear Consulted, informed Responsible, accountable
Network physical connectivity to FastConnect Responsible, accountable Consulted, informed
Hardware maintenance and upgrade Informed Responsible, accountable
Security and functionality updates Consulted, informed Responsible, accountable
Capacity management Responsible, accountable, consulted, informed Responsible, accountable, consulted, informed

Oracle and the customer conduct periodic capacity planning. The customer communicates capacity needs, and Oracle is responsible for delivering the service through approved expansion processes.
