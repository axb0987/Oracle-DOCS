# Managing Work Requests

List Resource Manager work requests and get their details, error messages, log entries, and log content.

Resource Manager uses work requests for asynchronous operations in stacks and private endpoints.

Use work request details to monitor an operation. If an operation fails, review its error messages and, if available, its log entries or raw log content for diagnostic information.

Detailed execution logs are available for supported operations, including drift detection and creating a stack from an existing compartment.

You can perform the following tasks with work requests:
- [Listing Work Requests](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/../Tasks/list-work-request.htm)
- [Getting a Work Request's Details](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/../Tasks/get-work-request.htm)
- [Listing Error Messages for a Work Request](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/../Tasks/list-work-request-errors.htm)
- [Getting Logs for a Work Request](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/../Tasks/list-work-request-logs.htm)
- [Getting Log Content for a Work Request](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/../Tasks/get-work-request-log-entries-content.htm)
