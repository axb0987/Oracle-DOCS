# Adding a Filter Tag to an Events Rule

Add a filter tag to a rule to select events and route them for delivery to action resources.

See[Matching Events with Filters](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Concepts/filterevents.htm)for more information on using filter tags in an events rule.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Events/Task/create-filter-tag-events-rule.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Events/Task/create-filter-tag-events-rule.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Events/Task/create-filter-tag-events-rule.htm#)
- 

- Navigate to the events list page. If you need help finding the list page, see[Listing Events Rules](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Task/list-events-rule.htm).
- Select a rule and then select Conditions .
- Under Filter Tags , select Add filter tag .
- In the Add filter tag panel, enter or select the following values:
- Tag namespace : Select a namespace to add a defined tag as a filter. To add a free-form tag as a filter, select None (add a free-form tag).
- Tag key : Select the tag key for the defined tag or enter the tag key for the free-form tag.
- (Optional) Tag value : The value of the tag.
- Select Add filter tag .
- 

See[Matching Events with Filters](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Concepts/filterevents.htm)for information on how to use filter tags.
