# Logging for Object Storage Buckets

Manage read access events and write access events logging using the Oracle Cloud Infrastructure Console.

The Object Storage service uses the Oracle Cloud Infrastructure Logging service to manage the following categories of logs:
- Read access events : Includes log entries for write events.
- Write access events : Includes log entries for read events.

See[Details for Object Storage](https://docs.oracle.com/iaas/Content/Logging/Reference/details_for_object_storage.htm)for information on how to understand Object Storage bucket log entries.

See[Logging Overview](https://docs.oracle.com/iaas/Content/Logging/Concepts/loggingoverview.htm)for general information on logging, including how to name log files and create log groups.

No other policies are required to enable logging. You need to have permission to configure the Object Storage bucket.
Note  
  
Logging is an option in the Object Storage service. Standard limits, restrictions, and rates apply when enabling the logging features. See[Oracle Cloud Infrastructure Logging](https://www.oracle.com/devops/logging/)for more information.

[Display the logs in a bucket](https://docs.oracle.com/en-us/iaas/Content/Object/Tasks/list-log.htm).

[Enable a log in a bucket](https://docs.oracle.com/en-us/iaas/Content/Object/Tasks/create-log.htm).

[View a log's details](https://docs.oracle.com/en-us/iaas/Content/Object/Tasks/get-log.htm).

[Update a log's settings](https://docs.oracle.com/en-us/iaas/Content/Object/Tasks/edit-log.htm).

[Delete a log from the bucket](https://docs.oracle.com/en-us/iaas/Content/Object/Tasks/delete-log.htm).

[Disable or re-enable a bucket's log](https://docs.oracle.com/en-us/iaas/Content/Object/Tasks/disable-log.htm)
