# Request Access - For Self and Others

As an Oracle Access Governance`WORKFORCE`user, you can request access to resources and roles for yourself or others. Your request may be granted automatically if no approval is required, or it may go through an approval process.

Depending on your configuration, the list of access bundles or roles you see may vary. For example, you can view only those that are specific to your or selected organization.

## Request Access to Resources through Access Bundles

Use Access Bundles to request access to resources. Based on the configuration, you may view a list of access bundles that are available to everyone and/or organization-specific access bundles.

### Navigate to Request Access
- In your browser, navigate to the Oracle Access Governance Console.
- Click the Navigation icon, and select My Stuff → Request Access to navigate to the Request Access page.
- Select Start on the Request access bundle tile to request access to resources, such as applications, and cloud service. The Request access bundle step workflow initiates.
- On the Select access page, select or search for the resources you want to get access to, and click Next .
- The next step of the workflow is Add details . The details requested will depend on the resource selected, but will typically be something like a justification for granting the access requested. Enter any details required and click Next .
- From the Review and submit page, select Submit request if you are happy with your selections.

### Select Who: Self or Others

Select if the request you are creating is for yourself or for another identity.
- If you are the beneficiary of this request, then select Yes , and click Next .
- If the request is for another identity, then select No .
- Select the organization the request if for : Filter and select the organization name to narrow down the specific identity for whom you want to raise the request.
- Search and select one or more identities for which you want to request the access. You can select up to 100 identities.
- Once you have selected your identities click Next , to navigate to the next step of the workflow.

### Select Access Bundles
- Search and select one or more access bundles. You can select up to 50 access bundles. You can check the Access Bundles icon to view access bundle details and the included permissions.
Note  
  
Based on the access bundle configuration, your list of available access bundles may differ. For example, this includes access bundles available to everyone and organization-specific bundles.
- Click Next .

### Select Time Limits
For each access bundle, set for how long you need the access by setting an expiration period.
Note  
  
The available time limit options depend on the access bundle's configuration. For example, if the access bundle is set to a specific number of hours, users will only see hours and specific time range to set the expiration period.
- How long should access be granted? : Select one of the following:
- Indefinitely : Allows permanent access with no time limits. Access is revoked only if manually revoked or the account is disabled.
- Maximum number of days [1-365] : Enter the maximum number of days to grant access. Access will be revoked after this period.
- Maximum number of hours [1-24] : Enter the maximum number of hours to grant access. Access will be revoked after the specified hours.
- Specific date and time range : Select access start time and access end time to grant access.
- How many days/hours : Based on your selection of days or hours for access, enter the number of days or hours you need the access.

### Select Add details

Enter justification in the Add details task.

### Review and submit

The Review and submit task displays the information you have added in the previous tasks. If everything looks correct, then click Submit request to request access.

## Request Access to a Role

You can create a role request using the Oracle Access Governance Console. Depending on your configuration, the list of roles you see may vary. This includes roles available to everyone and organization-specific roles.

### Navigate to Request Access
- In your browser, navigate to the Oracle Access Governance Console.
- Click the Navigation icon, and select My Stuff , and then select the Request Access page.
- On the Request role tile, select Start . The Request role workflow initiates.

### Select Who: Self or Others

Select if the request you are creating is for yourself or for another identity.
- If you are the beneficiary of this request, then select Yes , and click Next , to navigate to the next step of the workflow.
- If the request is for another identity, then select No .
- Select the organization the request is for : Filter and select the organization name to narrow down the specific identity for whom you want to raise the request.
- Search and select one or more identities for which you want to request the access. You can select up to 100 identities.
- After identities selection, click Next .

### Select Roles
- Search and select one or more roles. You can select up to 50 roles.
Note  
  
Based on the role configuration, your list of available roles may differ. This includes roles available to everyone and organization-specific roles.
- Click Next .

### Select Add details

Enter justification in the Add details task.
