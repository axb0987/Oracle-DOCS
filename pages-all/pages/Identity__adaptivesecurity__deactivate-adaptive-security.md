# Deactivating Adaptive Security

Deactivate adaptive security for an identity domain in IAM to stop performing contextual and threat event analysis, and stop obtaining user risk scores from third-party risk providers.
On the Adaptive security list page, perform one of the following actions depending on what you see. If you need help finding the list page, see[Listing Risk Providers.](https://docs.oracle.com/en-us/iaas/Content/Identity/adaptivesecurity/list-risk-provider.htm#console)
- Select Edit adaptive security and clear Adaptive intelligence , then select Save changes .
