# Editing Data Sync Tasks for Roving Edge Infrastructure

Describes how to edit a data sync task for your Roving Edge Infrastructure devices.
- 

Open the navigation menu and select Data Sync . The Data Sync Tasks page appears. All data sync tasks are listed in tabular form.
- 

(optional) Select a Status from the list to limit the data sync tasks displayed to that status.
- 

Select the Actions menu ( ) for the data sync task that you want to edit and select Edit . The Edit Task dialog box appears.
- 

Make your edits. See[Creating a Data Sync Task](https://docs.oracle.com/en-us/iaas/Content/Rover/Data_Sync/create_datasynctask.htm#CreateDataSyncTask)for descriptions of the settings.
- 

Select Save .
