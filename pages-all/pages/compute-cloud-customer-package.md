## Compute Cloud@Customer

Oracle Compute Cloud@Customer is a fully managed, rack-scale distributed cloud platform that lets you use OCI Compute anywhere. Gain the benefits of cloud automation and economics in your data center by running OCI Compute with storage and networking services on Compute Cloud@Customer. It’s the simplest way for you to run applications on cloud infrastructure while meeting your needs for data residency, security, and low-latency connections to existing resources and real-time operations.
