# Unlocking a User

Unlock a user account in an OCI IAM identity domain.

After a consecutive number of unsuccessful sign-in attempts, a user account is locked. The user receives a notification with a link that they can use to reset their password and unlock their account. An administrator can unlock accounts without requiring a password reset using the Unlock User option on the user details page. If you don't have administrative rights, the Unlock User option isn't available.

- On the Domains list page, select the domain from which you want to unlock a user. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/users/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the User management tab, and then go to the User section of the tab.
- Under Identity domain on the left side of the page, select Users .
- Select a person's username to see their details.
- Select Actions in the upper right.
- Select More actions , and then select Unlock User .
- In the Confirmation window, select OK .
