# Getting a VMware Solution Datastore's Details

View the details of a VMware Solution datastore.

## Using the Console

- Open the navigation menu and select Hybrid . Under VMware Solution , select Datastore .
The Datastores list opens. All datastores are displayed in a table.
- Select the datastore you want to work with.
