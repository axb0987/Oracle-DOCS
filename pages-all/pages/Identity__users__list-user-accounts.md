# Listing Users

List user accounts in an OCI IAM identity domain.

- On the Domains list page, select the domain for which you want to list users. If you need help finding the list page, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/users/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the User management tab, and then go to the Users section on the tab.
- o Under Identity domain on the left side of the page, select Users .

All users in the identity domain are displayed in a table.

## Exporting User Lists

Export selected users to a CSV file.

- Select the users you want to export from the user list.
- Expand More actions and select Export users , or select Export all users to export the complete list.
- Select Export .
The user list export begins.
- Select Jobs in the side menu.
A list of jobs in the domain is displayed.
- Find the job. Use the options to filter by user export type and search within a date range. When found, verify the job has succeeded and select Go to details .
- Select Download exported file .
