# Deleting an Events Rule

Remove a rule from a compartment.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Events/Task/delete-events-rule.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Events/Task/delete-events-rule.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Events/Task/delete-events-rule.htm#)
- 

- Navigate to the events list page. If you need help finding the list page, see[Listing Events Rules](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Task/list-events-rule.htm).
- 

Select the events rule you want to delete.

The Events Rule Details page appears.
- From Actions , select Delete .
- Confirm the deletion when prompted.
- Select Delete .

The events rule page reappears without the deleted rule.
