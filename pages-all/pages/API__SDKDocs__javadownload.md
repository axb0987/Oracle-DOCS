# Toolkit for Java Download

The Toolkit for Java Download provides a set of features that help developers download Oracle Java releases associated with both LTS (Long Term Support) and non-LTS versions to Oracle Cloud Shell.

This includes all publicly available Oracle Java releases from the last 2 years, even those belonging to unsupported Java versions. This toolkit builds on the[Java Download](https://docs.oracle.com/iaas/jms/doc/java-download.html)feature of[Java Management Service](https://docs.oracle.com/iaas/jms/index.html)(JMS), offering a streamlined way to install Oracle Java distributions in Cloud Shell.

## Requirements

To use the Toolkit for Java Download, you must have the following:
- An Oracle Cloud Infrastructure account
- A user created in that account, in a group with a policy that grants the desired permissions. This can be a user for yourself or another person/system who needs to call the API. For an example of how to set up a new user, group, compartment, and policy, see[Adding Users](https://docs.oracle.com/iaas/Content/GSG/Tasks/addingusers.htm). For a list of typical policies you may want to use, see[Java Download Policy Statements](https://docs.oracle.com/iaas/jms/doc/java-dowload-policy-statements.html#AJSUG-GUID-72D174AA-5645-4463-9BF7-9148C572838B).
