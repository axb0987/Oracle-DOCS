# Listing Resources in a Default Metric Chart

List the names and OCIDs of represented resources in a default metric chart. Default metric charts are available on the Service Metrics page and resource details pages in the Console.

- View default metric charts in one of the following ways:
- [Open](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/view-chart-namespace.htm)the Service Metrics page.
- [Go to the Metrics area on the details page for a resource.
- Select the metric chart that you want.
A larger view of the chart appears, with the query under Query .
- In the chart, select the arrow next to Query .
- To copy the OCID for a resource, select Copy next to the resource OCID.

For query troubleshooting, see[Troubleshooting Queries](https://docs.oracle.com/iaas/Content/Monitoring/troubleshooting-queries.htm)
