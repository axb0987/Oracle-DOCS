# Web Application Firewall Policies

Learn how to create and manage web application firewall policies, including their subordinate resources.

Note  
  
The first-generation web application firewall policies are now known as edge policies. See[Edge Policies](https://docs.oracle.com/en-us/iaas/Content/WAF/Policies/../EdgePolicyResources/legacy_waf.htm#legacy_waf)for more information.
