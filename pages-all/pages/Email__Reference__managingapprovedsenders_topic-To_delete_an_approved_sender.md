# Deleting an Approved Sender

Delete an approved sender.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/managingapprovedsenders_topic-To_delete_an_approved_sender.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/managingapprovedsenders_topic-To_delete_an_approved_sender.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/managingapprovedsenders_topic-To_delete_an_approved_sender.htm#)
- 

- On the Approved Senders list page, click the email address that you want to delete. If you need help finding the list page, see[Listing Approved Senders](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/list-approved-senders.htm).
- From Actions menu for the approved sender, select Delete .
- When prompted, confirm the deletion.
The email address is removed from the approved senders list.
-
