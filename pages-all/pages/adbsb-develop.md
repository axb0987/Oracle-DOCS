# Develop

Describes developer tasks and procedures on Autonomous AI Database.
- 

[Create Applications with Oracle APEX in Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/apex-autonomous-database.html#GUID-6B304741-9B26-4B8E-9D6D-193AFF6679DA)You can create applications with Oracle APEX on Autonomous AI Database.
- 

[Using JSON Documents with Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/document-database.html#GUID-78AA9D61-7370-44D3-BB58-D236FEB19CFB)Autonomous AI Database has full support for data represented as JSON documents. In Autonomous AI Databases, JSON documents can coexist with relational data.
- 

[Developing RESTful Services in Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/ords-autonomous-database.html#GUID-E2E921FF-2D80-4E32-9660-28506D10BADB)You can develop and deploy RESTful Services with native Oracle REST Data Services (ORDS) support on Autonomous AI Databases. Simple Oracle Document Access (SODA) for REST lets you use a database as a simple JSON document store.
- 

[Using Oracle AI Database API for MongoDB](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/mongo-using-oracle-database-api-mongodb.html#GUID-8321D7A6-9DBD-44F8-8C16-1B1FBE66AC56)

Oracle AI Database API for MongoDB makes it possible to connect to Oracle Autonomous AI Database using MongoDB language drivers and tools.
- 

[Use Autonomous AI Database API for DynamoDB](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/using-oracle-database-api-dynamodb.html#GUID-68DC4C08-603D-411F-BA77-7DC100CD3D18)

Autonomous AI Database API for DynamoDB make it possible to store, manage and retrieve data in an Autonomous AI Database using a key-value format.
- 

[SharePoint Support in Autonomous AI Database Using DBMS_CLOUD](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/sharepoint-support.html#GUID-CE0B1EDD-1D87-41B0-9CDB-D6F4E0732C24)

With SharePoint support, you can access files stored in Microsoft SharePoint using`DBMS_CLOUD`and`DBMS_CLOUD_PIPELINE`packages with provider-specific URIs and credential objects.
- 

[Send Email and Notifications on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/send-mail-slack.html#GUID-B9F25DFE-0B15-4F98-895D-1DE92E06120B)There are a number of options for sending email on Autonomous AI Database. You can also send notifications to a Slack channel, to MSTeams, or to an OCI Notifications topic.
- 

[User Defined Notification Handler for Scheduler Jobs](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/user-defined-notification-handler.html#GUID-2E54F425-35B0-4F67-8E31-AA52468B8CC7)

Database Scheduler provides an email notification mechanism to track the status of periodically running or automated jobs. In addition to this, the Database Scheduler also supports user-defined PL/SQL Scheduler job notification handler procedure.
- 

[Oracle Extensions for IDEs](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/develop-with-ide-extensions.html#GUID-35F30F17-26D6-4897-A587-6AB14BB5B68A)Oracle extensions let developers connect to, browse, and manage Autonomous AI Databases directly from common IDEs.
- 

[Use Oracle Java on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-oracle-java.html#GUID-2516EE33-B38D-4270-BE52-30A4F9014E8B)Autonomous AI Database supports Oracle JVM. Oracle JVM is a standard, Java-compatible environment that runs any pure Java application.
- 

[Test Workloads with Oracle Real Application Testing](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-real-application-testing.html#GUID-EB8F065E-5FBB-480D-BAF6-5A0446740073)

Oracle Real Application Testing is an extremely cost-effective and easy-to-use proactive performance management solution that enables you to fully assess the outcome of a system change in test or production.
- 

[Manage and Store Files in a Cloud Code Repository with Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/cloud-code-repository.html#GUID-1789720F-62F6-4312-A2D1-A0F9339D8721)

Autonomous AI Database provides routines to manage and store files in Cloud Code (Git) Repositories. The supported Cloud Code Repositories are: GitHub, AWS CodeCommit, and Azure Repos.
- 

[Invoke User Defined Functions](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/user-defined-functions-autonomous.html#GUID-8E002919-CA8A-418D-B66D-0F5B8B719D3A)You can invoke external functions such as OCI, AWS Lambda, Google Cloud Run functions and Azure remote functions in your Autonomous AI Database as SQL functions.
- 

[Make External Calls Using a Customer-Managed Wallet](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/external-calls-with-customer-managed-wallet.html#GUID-89B2A9C2-7567-451B-9150-04D3852C0DCB)When your Autonomous AI Database instance is on a private endpoint you can use a customer-managed wallet with procedures in`UTL_HTTP`,`DBMS_LDAP`,`UTL_SMTP`, or`UTL_TCP`. You can also use a customer-managed wallet when the scheduler sends SMTP email notifications for various events related to scheduler jobs.
- 

[Use Cloud Tables to Store Logging and Diagnostic Information](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/cloud-tables-object-storage.html#GUID-81F369CC-5E50-4B9B-811A-2EFD2508AD8B)You can create Cloud Tables where table data resides on Oracle managed Cloud Storage and the table data does not consume database storage.
