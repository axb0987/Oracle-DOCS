# Listing Load Balancer Health Status Summaries

View a list of the health status summaries for the load balancers in a compartment.

See[Health Status Indicators for Load Balancers](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/editinghealthcheck_topic-Health_Status.htm)for descriptions of the load balancer health indicators.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/list_load_balancer_health.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/list_load_balancer_health.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/list_load_balancer_health.htm#)
- 

- On the Load balancers list page, select the load balancer that you want to work with. If you need help finding the list page or the load balancer, see[Listing Load Balancers](https://docs.oracle.com/iaas/Content/Balance/Tasks/list_load_balancer.htm).
- On the list page, review the Overall health column in the list for a summary of each load balancer. See[Health Status Indicators for Load Balancers](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/editinghealthcheck_topic-Health_Status.htm)for descriptions of the load balancer health indicators.
