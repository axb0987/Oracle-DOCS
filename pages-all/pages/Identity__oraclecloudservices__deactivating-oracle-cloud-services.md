# Deactivating Oracle Cloud Services

Deactivate an Oracle Cloud Service.

- On the Oracle cloud services list page, select the name of Oracle Cloud Service to open its details page, where you can deactivate the service. If you need help finding the list page, see[Listing Oracle Cloud Services](https://docs.oracle.com/en-us/iaas/Content/Identity/oraclecloudservices/list-cloud-service.htm).

Note  
  

Some Oracle Cloud Services are required by Oracle and can't be deactivated. For Oracle Cloud Services that can't be deactivated, their checkbox isn't selectable.
- In the details page, select Deactivate from the Actions menu.
