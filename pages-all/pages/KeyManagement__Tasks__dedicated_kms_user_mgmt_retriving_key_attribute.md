# Getting Key Attribute

Command to get key attribute.

The`getAttribute`command retrieves the value for a key. For more information, see[List Key Attribute](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/dedicated_kms_user_mgmt_display_key_attribute.htm).

In the OCI HSM User Management utility, open a command prompt and run`getAttribute`command to retrieve the value for a key.

Parameter Description

`AttributeID`Space delimited list attribute IDs to retrieve.
`OutputFile`Path to the file in which to dump the data.
