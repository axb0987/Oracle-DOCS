# Error "Related resource not authorized or not found" When Updating a Mount Target

When updating a mount target to use LDAP or Kerberos, a "Related resource not authorized or not found" error occurs.

Cause : The required IAM policies aren't configured.

Solution : Ensure that the[Required IAM Policy](https://docs.oracle.com/en-us/iaas/Content/File/Troubleshooting/../Tasks/kerberos.htm#kerberos-permissions)
