# Customizing Y-Axis Labels in a Custom Metric Chart

Enter custom labels for the y-axis in the metric chart on the Metrics Explorer page in the Console.

Custom labels and ranges aren't persisted in shared queries (MQL).

- [Create a basic query](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/metrics-explorer-basic-query.htm)on the Metrics Explorer page.
- Provide values for the following fields:

- Y-Axis Label : Custom label for the y-axis of the metric chart.
- Y-Axis Min value : Custom minimum value for the y-axis of the metric chart. Use numeric characters.
