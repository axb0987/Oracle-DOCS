# Accessing the Cloud Shell Home Directory

This topic describes how to access the Cloud Shell home directory.
You can access files in the Cloud Shell home directory:
- Click on the Explorer icon in the Code Editor Tool Bar. This will load a hierarchical view of the files in the Cloud Shell home directory.
- Click on a directory to expand that node and display the files in that directory.
