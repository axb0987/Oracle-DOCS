# Switching Table and Graph Views for a Custom Metric Chart

View the metric chart on the Metrics Explorer page in the Console as a table, or switch back to the graph (chart) view.

This page describes how to switch table and graph views for a metric chart on the Metrics Explorer page. To switch views for a default chart, see[Switching Table and Chart Views for a Default Metric Chart](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/view-chart-toggle-view.htm).

- [Create a basic query](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/metrics-explorer-basic-query.htm)on the Metrics Explorer page.
- Select Show Data Table .
The metric data is now presented as a table. Example excerpt:

Timestamp Percent
Oct 1, 2022, 01:29:00 UTC 81.158842305151567
Oct 1, 2022, 01:30:00 UTC 85.689932345683178
Oct 1, 2022, 01:31:00 UTC 79.925088231917334
- To switch back to a chart view, select Show Graph .
