# Error: The Replication state is: SERVICE_ERROR

The state of the replication resource appears as SERVICE_ERROR if it has encountered an unrecoverable error.

If you are using your own keys for encryption, make sure that they are enabled on both the source and target regions. If the keys are enabled and the replication is still running into the SERVICE_ERROR state,[contact support](https://www.oracle.com/support/cloud.html#infrastructure-tab)
