# Edge Policies

Describes the features and functions of the legacy edge policies associated with the Web Application Firewall service.
Note  
  

Edge policies are the renamed WAF policies associated with the Web Application Firewall Service.

If you're looking for the current-generation web application firewall policies documentation, see[Web Application Firewall Policies](https://docs.oracle.com/en-us/iaas/Content/WAF/EdgePolicyResources/../Policies/waf-policy_management.htm#WAFPolicyManagement).
