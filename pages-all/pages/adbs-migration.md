# Migrate to Autonomous AI Database

Database migration is the process of migrating your database from a source database to a target database.

To migrate your database to an Autonomous AI Database, Oracle provides different migration options.
- 

[Migrate Oracle AI Databases to Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/migration-autonomous-database.html#GUID-F2471136-3BBA-462C-9E5B-12A144AD7D56)

Learn about the options available to migrate your Oracle AI Database to Autonomous AI Database.
- 

[Migrate Non-Oracle Databases to Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/migrate-autonomous-database.html)

Learn about the options available to migrate non-Oracle databases to Autonomous AI Database
- 

[Migrate Applications from Non-Oracle SQL to Oracle SQL](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/application-migration-overview.html#GUID-3E12E936-FAAA-45CC-84A2-B5ED14F35145)

Application migration involves moving an application from one environment to another. The migration process includes a variety of tasks, including migrating SQL statements from a non-Oracle database to Oracle SQL.
- 

[Migrate Data Using Transportable Tablespaces](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/using-transportable-tablespaces.html#GUID-F40065A9-3EF1-4709-AB02-95728DCDE996)

Transportable Tablespaces enable efficient migration of large volumes of data by moving tablespaces, including their data and metadata, from a source database to a target database without requiring full data export and import.
- 

[Migrate Data with DBMS_CLOUD_IMPORT](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/migrate-data-with-dbms-cloud-import.html#GUID-3C5D3CEE-2C74-47BE-B3DA-157B31C1E2BB)

`DBMS_CLOUD_IMPORT`enables you to import data from Oracle and non-Oracle databases into Oracle Autonomous AI Database using a simple, consistent approach.
