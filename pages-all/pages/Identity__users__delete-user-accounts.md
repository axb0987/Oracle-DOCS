# Deleting a User

Delete one or more user accounts in an OCI IAM identity domain for users who no longer need access to the service.

Note  
  
When you delete a user, the audit data of the user remains in the system. You can't delete your own user account.

You can't delete a user who is the last administrator granted the identity domain administrator role. See[Removing an Identity Domain Administrator](https://docs.oracle.com/en-us/iaas/Content/Identity/users/../securing/iam-identity-removeadmin.htm).

- On the Domains list page, select the domain from which you want to delete a user. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/users/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the User management tab, and then go to the User section of the tab.
- Under Identity domain on the left side of the page, select Users .
- Select the Actions menu (three dots) for the user to delete, and then select Delete .
