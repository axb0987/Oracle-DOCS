# DevOps Tools and Plug-ins

This section covers the DevOps tools and plug-ins available for working with Oracle Cloud Infrastructure services.

Oracle Cloud Infrastructure provides many DevOps tools and plug-ins for working with Oracle Cloud Infrastructure services. These can simplify provisioning and managing infrastructure or enable automated testing and continuous delivery.
Terraform Provider - Manage "infrastructure as code" with this component that connects Terraform to a given Oracle Cloud Infrastructure service.
- Documentation :[Terraform Provider](https://docs.oracle.com/iaas/Content/dev/terraform/home.htm)
- Download :[GitHub](https://github.com/oracle/terraform-provider-oci)

OCI Modules for PowerShell - A set of cmdlet modules that can be used with PowerShell Core to manage Oracle Cloud Infrastructure resources, such as Compute, Load Balancer, and Database services.
- Documentation :[OCI Modules for PowerShell](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/../SDKDocs/powershell.htm)
- Download :[GitHub](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/../SDKDocs/powershellgettingstarted.htm)or[PowerShell Gallery](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/../SDKDocs/powershellgettingstarted.htm)

Ansible Collection - Automate provisioning and configuring of Oracle Cloud Infrastructure resources, such as Compute, Load Balancer, and Database services.
- Documentation :[Ansible Collection](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/../SDKDocs/ansible.htm)
- Download :[GitHub](https://github.com/oracle/oci-ansible-collection)

Compute Jenkins Plug-in - Bring up and down services or nodes as required to serve Jenkins Build Jobs and dynamically allocate Oracle Cloud Infrastructure resources for continuous integration tasks.
- Documentation :[Compute Jenkins Plug-in](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/../SDKDocs/jenkinsplugin.htm)
- Download :[GitHub](https://github.com/jenkinsci/oracle-cloud-infrastructure-compute-plugin)

OCI DevOps Plugin for Jenkins - Upload artifacts, and run deployments on Oracle Cloud Infrastructure from Jenkins. A Jenkins master instance with the DevOps plugin can upload artifacts to the Artifacts Registry repository, and trigger the deployment pipeline for deploying those artifacts.
- Documentation :[OCI DevOps Plugin for Jenkins](https://plugins.jenkins.io/oracle-cloud-infrastructure-devops/)
- Download :[GitHub](https://github.com/jenkinsci/oracle-cloud-infrastructure-devops-plugin)

Chef Knife Plug-in - Manage Oracle Cloud Infrastructure resources with Chef Knife, a command line tool that provides an interface between a local chef-repo and the Chef server.
- Documentation :[Chef Knife Plug-in](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/../SDKDocs/knifeplugin.htm)
- Download :[GitHub](https://github.com/oracle/knife-oci)

Grafana Plug-in - Visualize metrics from the Monitoring service in your Grafana instance.
- Documentation :[Grafana Plug-in](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/../SDKDocs/grafana.htm)
- Download :[GitHub](https://github.com/oracle/oci-grafana-plugin)

Terraform Kubernetes Installer - Provision and configure the resources needed to run a highly available and configurable Kubernetes cluster.
- Download :[GitHub](https://github.com/oracle/terraform-kubernetes-installer)

Kubernetes Volume Provisioner - Enable dynamic provisioning of storage resources when running Kubernetes on Oracle Cloud Infrastructure.
- Download :[GitHub](https://github.com/oracle/oci-volume-provisioner)

OCI Provider for Pulumi - The Oracle Cloud Infrastructure (OCI) provider for Pulumi can be used to provision any of the resources available in the Oracle Cloud Infrastructure.
- Documentation :[OCI Provider for Pulumi](https://www.pulumi.com/registry/packages/oci/)
- Download :[GitHub](https://github.com/pulumi/pulumi-oci)

## DevOps Integrations

- [Jenkins X Integration](https://jenkins-x.io/): Create a new Kubernetes cluster on Oracle Cloud Infrastructure Kubernetes Engine.
- [Packer Integration](https://www.packer.io/docs/builders/oracle-oci.html): Create reusable custom images.

### Other Services and Features for DevOps

Oracle Cloud Infrastructure provides other services and features relevant to DevOps professionals.
- [Kubernetes Engine (OKE)](https://docs.oracle.com/iaas/Content/ContEng/Concepts/contengoverview.htm): Reliably build, deploy, and manage cloud-native containerized applications. You specify the compute resources that your applications require, and Kubernetes Engine provisions them on Oracle Cloud Infrastructure in an existing tenancy.
- [Oracle Cloud Infrastructure Registry](https://docs.oracle.com/iaas/Content/Registry/Concepts/registryoverview.htm): Store, share, and manage development artifacts like Docker images. As Oracle Cloud Infrastructure Registry is managed by Oracle, your applications are deployed reliably and you don't have to deal with operational issues.
- [Solutions for Self-Managed Kubernetes](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/../SDKDocs/solutions-kubernetes.htm)
