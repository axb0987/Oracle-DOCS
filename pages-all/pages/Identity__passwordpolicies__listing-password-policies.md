# Listing Password Policies

Retrieve a list of password policies.

- On the Domains list page, select the name of the identity domain that you want to work in. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/passwordpolicies/../domains/to-view-identity-domains.htm).
- Perform one of the following actions depending on the options that you see:
- On the Domain policies tab, scroll to view the password policies.
- Select Settings and then select Password policy .
