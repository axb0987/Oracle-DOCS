# Viewing Replicated Keys

Learn how to view replicated keys using the OCI Console.

The keys in a replicated vault are the same as the keys in the source vault. To view the keys in the replicated vault, use the the Region menu in the Console to switch to the region that contains the replicated vault, then follow the instructions the[Listing Keys](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/managingkeys_topic-To_view_a_list_of_keys.htm)
