# Access Database Management Overview

On obtaining the required permissions and completing the prerequisite tasks, you can use the Database Management Overview page as a launch pad to get started with Database Management Diagnostics &amp; Management for Oracle Databases.

To access the Overview page:
- Sign in to the Oracle Cloud Infrastructure console.
- Open the navigation menu, click Observability &amp; Management . Under Database Management , click Overview .
- Ensure that the compartment that contains the Oracle Databases for which Diagnostics &amp; Management is enabled is selected in the Compartment applied filter.

On the Overview page, you can perform the following tasks for Oracle Databases:
- In the Database Management section, click the Pricing and Documentation links for information on Diagnostics &amp; Management pricing and features.
- In the Get started section:
- Click Add policies to automatically generate and add policies to grant permissions to user groups to enable and use Diagnostics &amp; Management features. For information, see[Automatically Grant Permissions to User Groups](https://docs.oracle.com/iaas/database-management/doc/automatically-grant-permissions-user-groups.html#GUID-943F54D1-B781-4B98-883F-4A43F38AC4B6).
- Click Enable demo mode to explore Diagnostics &amp; Management features using curated demo data. For information, see[Explore Database Management Using Demo Mode](https://docs.oracle.com/iaas/database-management/doc/explore-database-management-using-demo-mode.html#GUID-1D35754C-3BF8-4E73-8430-7FD4EE670661).
- Click the available links to go to the Managed databases page where you can enable Diagnostics &amp; Management. For information, see[Enable Diagnostics &amp; Management](https://docs.oracle.com/iaas/database-management/doc/enable-database-management.html#GUID-3A45ADBE-63DE-472E-BE72-0F251E854939).
- On the Oracle databases tile, view the total number of Oracle Databases in the compartment and the number of Oracle Databases for which Diagnostics &amp; Management and other Database Management features are enabled. Note that to view the database information, you must have the required Database Management and other Oracle Cloud Infrastructure service permissions. For information, see[Permissions Required to Use Diagnostics &amp; Management](https://docs.oracle.com/iaas/database-management/doc/permissions-required-use-database-management.html#GUID-3B177EA8-194E-4CB5-9B45-ED46883FF78C).
- On the Related services tile, click the links to go to the Oracle Cloud Infrastructure Ops Insights service and use its features. For information, see[About Oracle Cloud Infrastructure Ops Insights](https://docs.oracle.com/iaas/operations-insights/doc/operations-insights.html).
- In the left pane, click Diagnostics &amp; Management to view and use the various Diagnostics &amp; Management features, such as fleet summary and dashboards.
