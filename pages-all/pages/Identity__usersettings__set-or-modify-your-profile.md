# Editing Your Profile Details

If you're signing in to an identity domain IAM for the first time, then set up your profile information. If you already set up your profile, then you can modify this information. For example, you can change the time zone and language that displays for your account.

- Open your profile console page. If you need help finding your profile console page, see[Getting Your Profile Details](https://docs.oracle.com/en-us/iaas/Content/Identity/usersettings/get-details-my-profile.htm).
- Select Edit my profile .
- (Optional) If you have a multi valued attribute for your profile, then a Values link appears to the right of the attribute. To populate this attribute with values:
- Select the Values link.
- In the pop-up window that appears, select Add .
- In the text box that appears, enter a value for the attribute.
- Repeat steps b and c to add other values for the attribute.

Tip  
  
To remove an existing value from the attribute, select the X button to the right of the value.
- Select OK . The counter to the right of the Values link changes to reflect the updated number of values for the attribute.
