# Network Address Lists for Web Application Firewall

Learn how to create and manage network address lists for web application firewall policies.

Network address lists are collections of individual public IP addresses and CIDR IP ranges or private IP addresses used by WAF policies.

You can perform the following network address list management tasks:
- [List the network address lists in a compartment](https://docs.oracle.com/en-us/iaas/Content/WAF/NetworkAddressLists/list_network-address-list.htm#top).
- [Create a network address list](https://docs.oracle.com/en-us/iaas/Content/WAF/NetworkAddressLists/create_network-address-list.htm#top).
- [Create a VCN network address list](https://docs.oracle.com/en-us/iaas/Content/WAF/NetworkAddressLists/create_vcn-network-address-list.htm#top).
- [View the details of a network address list](https://docs.oracle.com/en-us/iaas/Content/WAF/NetworkAddressLists/get_network-address-list.htm#top).
- [Update the settings of a network address list](https://docs.oracle.com/en-us/iaas/Content/WAF/NetworkAddressLists/update_network-address-list.htm#top).
- [Update the settings of a VCN network address list](https://docs.oracle.com/en-us/iaas/Content/WAF/NetworkAddressLists/update_vcn-network-address-list.htm#top).
- [Move a network address list to a different compartment](https://docs.oracle.com/en-us/iaas/Content/WAF/NetworkAddressLists/change-compartment_network-address-list.htm#top).
- [Delete a network address list from the compartment](https://docs.oracle.com/en-us/iaas/Content/WAF/NetworkAddressLists/delete_network-address-list.htm#top)
