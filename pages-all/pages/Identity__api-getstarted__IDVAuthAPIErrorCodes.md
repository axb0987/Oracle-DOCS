# Authentication and Identity Verification Error Codes

The authentication APIs for identity domains in IAM are REST compliant and use error codes to indicate failure.

This table describes the different error codes that the Authentication APIs respond with when errors occur.

Error Code Error Reason Message
`AUTH-5001`

Claims Mismatch

Your identity could not be verified due to a mismatch in your information. Contact your system administrator.
`AUTH-5002`

Identity Verification Failure

Your identity could not be verified. Contact your system administrator.
`AUTH-5003`

Photo Mismatch
