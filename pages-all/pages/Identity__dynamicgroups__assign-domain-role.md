# Assigning a Domain Role

By default, every dynamic group is associated with the OCI IAM application. You can assign a domain role to that application to allow members of the dynamic group to perform certain actions with the identity domain.

- On the Domains list page, select the domain in which you want to make changes. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/dynamicgroups/../domains/to-view-identity-domains.htm).
- On the domain details page, select Dynamic Groups . A list of dynamic groups in the domain is displayed.
- Select the dynamic group to edit.
- Select Domain roles .
- Select the Actions menu (three dots) for the OCI IAM dynamic group, and then select Manage roles .
- Select the checkbox for all the predefined domain roles that you want to assign to members of the dynamic group.
