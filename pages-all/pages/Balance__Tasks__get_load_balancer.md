On the Load balancers list page, select the load balancer that you want to work with. If you need help finding the list page or the load balancer, see[Listing Load Balancers](https://docs.oracle.com/iaas/Content/Balance/Tasks/list_load_balancer.htm).

The load balancer's details page opens and displays information about the load balancer. Some items on the page are read-only, and other items enable you to edit and update the load balancer's configuration. Access the various resources associated with the load balancer by selecting their links or tabs.
