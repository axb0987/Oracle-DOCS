# Rate Limiting for Web Application Firewall

Learn about how to add and manage rate limiting rules for web application firewall policies.

Rate limiting allows inspection of HTTP request properties and limits the frequency of requests for each unique client IP address.

You can perform the following rate limiting management tasks:

[List the rate limiting rules in a compartment](https://docs.oracle.com/en-us/iaas/Content/WAF/RateLimiting/list_rate_limiting_rule.htm#top).

[Add a rate limiting rule to a policy](https://docs.oracle.com/en-us/iaas/Content/WAF/RateLimiting/create_rate_limiting_rule.htm#top).

[View a rate limiting rule's details](https://docs.oracle.com/en-us/iaas/Content/WAF/RateLimiting/get_rate_limiting_rule.htm#top).

[Update a rate limiting rule's settings](https://docs.oracle.com/en-us/iaas/Content/WAF/RateLimiting/update_rate_limiting_rule.htm#top).

[Change a rate limiting rule's actions](https://docs.oracle.com/en-us/iaas/Content/WAF/RateLimiting/change_action_rate_limiting.htm#top).

[Delete a rate limiting rule from the compartment](https://docs.oracle.com/en-us/iaas/Content/WAF/RateLimiting/delete_rate_limiting_rule.htm#top)
