# Testing and Verifying the Network

On a Roving Edge device, you can use the serial console to test and verify network settings as described in the following sections:
- Run ping and traceroute operations to help diagnose network connectivity issues. See[Testing Network Connectivity](https://docs.oracle.com/en-us/iaas/Content/Rover/Getting_Started/testing-network-connectivity.htm#testing-network-connectivity).
- Verify and manage advanced network settings. You can view MACsec, gateway, and VNIC information. See[Managing Advanced Network Settings](https://docs.oracle.com/en-us/iaas/Content/Rover/Getting_Started/network_management.htm#ManageNetwork)
