# Features
- 

[Autonomous AI Database MCP Server](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/mcp-server.html#GUID-535029AF-BE55-4869-8DF3-6183E0873916)

Oracle Autonomous AI Database MCP Server enables AI applications to interact with Autonomous AI Database using the MCP standard, eliminating the need for custom integration.
- 

[Lakehouse](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/lake-lakehouse.html)

Learn the benefits of using Lakehouse with Autonomous AI Database.
- 

[The Data Studio Overview Page](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/adp-data-studio-overview-page.html)

The Data Studio comprises of the Data Load, the Data Analysis, the Data Insights, the Catalog tool, the Table AI Assist tool, the Data Marketplace tool, Jobs feature and the Data Share tool.
- 

[High Availability](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/adbsb-high-availability.html)

You can configure and manage Autonomous Data Guard and maintain continuous availability using disaster recovery.
- 

[Security](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/security-top-autonomous.html#GUID-DFCC2932-AB47-41E1-ADB6-4BD1F992CF48)

Autonomous AI Database stores all data with inbuilt security. Only authenticated users and applications can access the data when they connect to the database.
- 

[Performance Monitor and Management](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/adbsb-high-performance.html#GUID-56C7727D-D2DB-4086-BEFD-1F21D26D7419)

Oracle Autonomous AI Database Serverless includes several features that automatically monitor, analyze and optimize the performance of your Autonomous AI Database.
- 

[Using Oracle Graph with Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/graph-autonomous-database.html#GUID-767C764B-F652-4114-B5BE-9849CE6F09B1)

Oracle Graph with Autonomous AI Database enables you to create graphs from data in your Autonomous AI Database. With graphs you can analyze your data based on connections and relationships between data entities.
- 

[Use Oracle Machine Learning (OML) with Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-oml.html#GUID-63F2D68B-6D44-48A0-AE51-C6AAE4635212)

OML components are integrated into Autonomous AI Database.
- 

[Creating Analytic Views](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/adp-creating-analytic-views.html)

You can create Analytic Views and view information about them. You can also edit and perform other actions on them.
- 

[Use Select AI for Natural Language Interaction with your Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/select-ai.html#GUID-9CE75F94-7455-4C09-A3F3-118C08E82B7E)

Select AI enables SQL access to generative AI using Large Language Models (LLMs) and embedding models. This includes support for natural language to SQL query generation and retrieval augmented generation, among other features.
- 

[Select AI Agent](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/select-ai-agent1.html)

Select AI Agent (autonomous agent framework) enables you to build interactive and autonomous agents inside Autonomous AI Database, combining planning, tool use, reflection, and memory to deliver multi-turn workflows.
- 

[JSON Document Stores](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/adbsb-json-document-stores.html)

Autonomous AI Database has full support for data represented as JSON documents. In Autonomous AI Database, JSON documents can coexist with relational data.
- 

[Cache Messages with Singleton Pipes and Using Pipes for Persistent Messaging](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-persistent-singleton.html#GUID-F83C3F77-394C-47FF-8F84-89E26B7DAB3B)

On Autonomous AI Database the`DBMS_PIPE`package includes support for Singleton Pipes and Persistent Messaging Pipes.
- 

[Full-Text Search Queries](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/query-oracle-text-index.html#GUID-3B61BC34-A571-4DB5-9C79-1E5013E83C50)

The PL/SQL package`DBMS_CLOUD`enables you to build a text index on the object store files, which allows you to search the text and use wildcards with your search. You can use`JSON_TEXTCONTAINS`to do full-text JSON search on files stored in Object Storage.
- 

[Use Oracle Workspace Manager on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/workspace-manager-autonomous-database.html#GUID-768B5A70-054A-4B2D-AF06-0223C5014B28)

Workspace Manager provides an infrastructure that enables applications to create workspaces and group different versions of table row values in different workspaces.
- 

[Optimize Costs with Elastic Pools on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/elastic-resource-pools-autonomous.html)

Use an elastic pool to logically group your Autonomous AI Database instances, in terms of their allocation of compute resources, and to provide up to 87% cost savings.
- 

[Use Database In-Memory with Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-in-memory.html#GUID-62CD10FD-8757-4227-AEE7-11775B9516AE)

The Database In-Memory feature available on Autonomous AI Database can significantly improve performance for real-time analytics and mixed workloads.
