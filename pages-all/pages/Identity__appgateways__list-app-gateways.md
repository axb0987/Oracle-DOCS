# Listing App Gateways

List app gateway in IAM.

You must be assigned to either the Identity Domain Administrator role or the Security Administrator role.

- On the Domains list page, select the domain you want to use. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/appgateways/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the App gateways tab, and then go to the Domain settings section on the tab.
- On the left side of the page, select Security , then select App gateways .
- Under App gateways , use filters to limit the jobs in the list.

## Filtering List Results

Use filters to limit the app gateways in the list. Perform one of the following actions depending on the options that you see:

- From the Search and Filter box above the list table, select one or more filters and specify the values that you want to use to narrow the list. In general, the filters correspond to the columns shown in the list table, although some filters represent attributes that aren't shown in the table. The Compartment filter is always displayed next to Applied filters .
- On the left side of the list page, select a value from one of the available filters, such as compartment, state, or tags.

Change the order of the items in the list table by using the sort icons next to the column names.

For information about searching for resources and managing the columns in the list table, if those features are available, see[Listing Resources](https://docs.oracle.com/iaas/Content/GSG/Concepts/new-console.htm#new_console_list).

## Actions

In the list table, select the name of an app gateway to open its details page, where you can view its status and perform other tasks.

To perform an action on an app gateway directly from the list table, select any of the following options from the Actions menu (three dots) in the row for that app gateway:
- Activate :[Activating an App Gateway](https://docs.oracle.com/en-us/iaas/Content/Identity/appgateways/activate-app-gateways.htm)
- Deactivate :[Deactivating an App Gateway](https://docs.oracle.com/en-us/iaas/Content/Identity/appgateways/deactivate-app-gateways.htm)
- Delete :[Deleting an App Gateway](https://docs.oracle.com/en-us/iaas/Content/Identity/appgateways/remove-app-gateways.htm).
- Open support request : Open the Support Request panel, in which you can access support options. See[Support Requests](https://docs.oracle.com/iaas/Content/GSG/Tasks/contactingsupport.htm).

To create an app gateway, select[Creating an App Gateway](https://docs.oracle.com/en-us/iaas/Content/Identity/appgateways/register-app-gateway.htm).
