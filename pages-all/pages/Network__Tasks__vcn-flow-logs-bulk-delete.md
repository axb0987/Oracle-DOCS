# Bulk Deleting Flow Logs

Delete many VCN flow logs at one time.

## Using the Console

- On the Flow log configurations list page, select the box on the left side of the flow logs that you want to delete. If you need help finding the list page, see[Listing and Viewing Flow Logs](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vcn-flow-logs-view.htm#vcn-flow-logs-view).
- Select the Delete button.
