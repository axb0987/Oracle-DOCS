# Allowing Oracle Services Onboarding

Identity domain administrators can control whether Oracle Services can be onboarded to an identity domain. To onboard Oracle Services, turn on Oracle Services Onboarding. Oracle Services Onboarding is turned on by default.

- On the Domain settings page, find the setting you want to change. If you need help finding the domain settings page, see[Listing Domain Settings](https://docs.oracle.com/en-us/iaas/Content/Identity/defaultsettings/list-domain-settings.htm).
- Under Settings, find Allow Oracle Service onboarding .

- When turned on, Oracle Services can be onboarded.
