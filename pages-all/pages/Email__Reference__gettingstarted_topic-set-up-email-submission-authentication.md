# Setting up Email Submission Authentication

Set up email submission authentication to send emails using HTTPS submissions or SMTP submissions.

HTTPS uses all OCI Native Auth mechanisms. For more information, see[OCI SDK Authentication Methods](https://docs.oracle.com/iaas/Content/API/Concepts/sdk_authentication_methods.htm)and[Using HTTPS for Email Submissions](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/../Concepts/email-submission-using-https.htm).

To set up authentication for using SMTP submission, create[SMTP credentials](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-Configure_the_SMTP_connection.htm#smtp)and[set up email SMTP submissions](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/../Concepts/email-submission-using-smtp.htm)
