# Updating a Tag Key Definition

Update the description and tag value type of a tag key definition.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Tagging/Tasks/Update_tag_key_definition.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Tagging/Tasks/Update_tag_key_definition.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Tagging/Tasks/Update_tag_key_definition.htm#)
- 

- On the Tag namespaces list page, select the namespace that you want to work with. If you need help finding the list page, see[Listing Tag Namespaces](https://docs.oracle.com/en-us/iaas/Content/Tagging/Tasks/../Common/../Concepts/list-tagnamespace.htm).
- On the Tag namespace details page, in the Tag key definitions section, select the tag key definition you want to update.
- On the Tag definition details page, select Edit tag definition .
- In the Edit tag key definition panel, update the following information:

- The description. Avoid entering confidential information.
- The tag value type.
- Select Update .
