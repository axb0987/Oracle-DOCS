# Configuring Username Only Sign In

Configure the sign in requirements so the user uses just their username, and sign in is verified by the authentication factor.

- Open the navigation menu and select Identity &amp; Security . Under Identity , select Domains .
- Click the name of the identity domain that you want to work in. You might need to change the compartment to find the domain that you want. Then, click Settings and then Session settings .
- Select Enable username first flow .
- Select Save changes .
