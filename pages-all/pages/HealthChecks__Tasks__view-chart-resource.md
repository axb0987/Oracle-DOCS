# Viewing Default Metric Charts for a Single Health Check

Go to the health check's details page in the Console to view metric charts that use predefined service queries. The charts show metric data in`oci_healthchecks`for the selected health check.

This page describes how to access health check-specific[metric charts](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/viewingcharts.htm)from a health check's detail page.

To access health check-specific metric charts from other pages in the Console (including the Service Metrics page), select a resource-specific dimension. See[Selecting Dimensions on the Service Metrics Page](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/view-chart-dimensions.htm).

For information about directly editing MQL expressions and changing queries by using the CLI or API in this context, see[Selecting a Resource for a Query](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/query-metric-resource.htm).

For more information about these metrics, see[Health Checks Metrics Reference](https://docs.oracle.com/en-us/iaas/Content/HealthChecks/Tasks/../Reference/metricsalarms-reference.htm#top).

- On the Health checks list page, select the health check that you want to work with. If you need help finding the list page or the health check, see[Listing HTTP Monitors](https://docs.oracle.com/en-us/iaas/Content/HealthChecks/Tasks/list-http-monitor.htm#top)or[Listing Ping Monitors](https://docs.oracle.com/en-us/iaas/Content/HealthChecks/Tasks/list-ping-monitor.htm#top).
- On the health check's details page, under Resources , select Metrics .
The page displays default charts (graphs) for the selected health check.

For query troubleshooting, see[Troubleshooting Queries](https://docs.oracle.com/iaas/Content/Monitoring/troubleshooting-queries.htm)
