# Request Access Rules for a Web Application Firewall Policy

Create and manage the request access rules for a web application firewall policy.

The request access rules manage the inspection of HTTP request properties and the return a defined HTTP response. Manage the request control through the Access Control resource of the web application firewall policy.

You can perform the following request control management tasks:

[List the request access rules in a compartment](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/list_request_control.htm#top).

[Add a request access rule to a policy](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/create_access_rule_request_control.htm#top).

[View a request access rule's details](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/get_access_rule_request_control.htm#top).

[Update a request access rule's settings](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/update_access_rule_request_control.htm#top).

[Change a request access rule's actions](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/change_action_request_control.htm#top).

[Reorder the request access rules for a policy](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/reorder_action_request_control.htm#top).

[Delete a request access rule from the compartment](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/delete_access_rule_request_control.htm#top)
