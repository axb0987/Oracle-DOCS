# Listing Resource Collections

Get a list of resource collections.

## Using the Console

- In the top navigation bar, select Search for resources, services, documentation, and Marketplace , and then select Advanced resource query .
- Depending on the options available, perform one of the following actions:
- Under Resource Explorer , select Resource collections .
- Under Categories , select Resource collections .
