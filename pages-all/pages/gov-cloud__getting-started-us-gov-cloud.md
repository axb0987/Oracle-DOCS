# Troubleshooting Your First Sign-in to Oracle US Government Cloud or Oracle US Defense Cloud

If you have a new Oracle US Government Cloud or Oracle US Defense Cloud account and have been waiting for the "Getting Started" email for more than 24 hours, check your junk and spam folders. If you can't find your "Getting Started" email, you can sign in to your new Oracle US Government Cloud tenancy with the same username and password that you use for an existing Oracle Cloud account.

Oracle US Government Cloud users can sign in at[oc2.cloud.oracle.com](http://oc2.cloud.oracle.com/)or using the[Oracle US Government Cloud Console Sign-in URLs](https://docs.oracle.com/en-us/iaas/Content/gov-cloud/govfedramp.htm#Console_Signin_URLs).

US Defense Cloud users can sign in using the[Oracle US Defense Cloud Console Sign-in URLs](https://docs.oracle.com/en-us/iaas/Content/gov-cloud/govfeddod.htm#US_Federal_Cloud_with_DISA_Impact_Level_5_Authorization_Console_Signin_URLs).

If you don't remember the name of your existing Oracle Cloud account, you can request the list of accounts associated with an email address.
Note  
  
Don't sign in to[https://cloud.oracle.com/](https://cloud.oracle.com/), which is the URL of the Oracle Cloud Infrastructure commercial cloud.

If you're still having trouble signing in to your tenancy, open a service request. For detailed information, see[Engaging Customer Support for Oracle US Government Cloud or Oracle US Defense Cloud](https://docs.oracle.com/en-us/iaas/Content/gov-cloud/contactingsupportforusgov.htm)
