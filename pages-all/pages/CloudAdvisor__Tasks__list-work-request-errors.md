# Listing Work Request Error Messages

List the error messages for a Cloud Advisor work request.

- [CLI](https://docs.oracle.com/en-us/iaas/Content/CloudAdvisor/Tasks/list-work-request-errors.htm#)

- Navigate to the Cloud Advisor Work Requests page. If you need help finding the Work Requests page, see[Listing Work Requests](https://docs.oracle.com/en-us/iaas/Content/CloudAdvisor/Tasks/../Tasks/list-work-requests.htm#list-work-requests-console).
- Select a work request.
The details page for the selected work request opens. The page shows log messages, error messages, and associated resources.
- Select Error messages .
The text, error code, and timestamp are listed for each error message.
- 

Use the[oci optimizer work-request-error list](https://docs.oracle.com/iaas/tools/oci-cli/latest/oci_cli_docs/cmdref/optimizer/work-request-error/list.html)command to list errors for a work request.
