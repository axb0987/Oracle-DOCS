# Adding a terms of use statement

The statement in a terms of use document provides the text that users must agree to when they first open any apps assigned to the terms of use. If you want, you can add multiple terms of use statements, for example, if you need them in different languages.

- On the Terms of use documents list page, select the terms of use document that you want to add a statement to. If you need help finding the list page, see[Listing Terms of Use Documents](https://docs.oracle.com/en-us/iaas/Content/Identity/termsofuse/list-terms-of-use.htm#console).
- On the terms of use details page, perform one of the following actions depending on the option that you see:
- On the Terms of use statements tab, select Add terms of use statement .
- Select Add terms of use statement .
- On the Add terms of use statement panel, do the following:
- Language : Select the language in which you want to create the statement for the terms of use.
- Statement : Enter or paste the statement content.
- Select Add terms of use statement .
