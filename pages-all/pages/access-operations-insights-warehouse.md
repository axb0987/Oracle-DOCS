# Access the Ops Insights Warehouse

In order to access the Ops Insights Warehouse, which is an Autonomous AI Database, a wallet is needed.
- From the Ops Insights menu, select Administration and then Warehouse . The Warehouse screen displays.
- Click DB Connection . The Database Connection region displays.
- Click Download Wallet . Enter and confirm a password for this wallet.
Note  
  
Some database clients will require that you provide both the wallet and password to connect to your database, while other clients will auto-login using the wallet without a password.
- Click Download . The OPSIWarehouseWallet.zip file is downloaded to your machine.
- Connect to the Ops Insights Warehouse using the downloaded cloud wallet.
