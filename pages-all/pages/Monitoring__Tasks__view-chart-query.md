# Viewing the Query for a Default Metric Chart

View the predefined service query used to generate a default metric chart. The query is shown as a Monitoring Query Language (MQL) expression. Default metric charts are available on the Service Metrics page and resource details pages in the Console.

This page describes how to view predefined service queries for default metric charts. To view user-defined queries for the metric chart on the Metrics Explorer page, see[Viewing Queries for a Custom Metric Chart](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/metrics-explorer-view-queries.htm).

- View default metric charts in one of the following ways:
- [Open](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/view-chart-namespace.htm)the Service Metrics page.
- [Go to the Metrics area on the details page for a resource.
- Select the metric chart that you want.
A larger view of the chart appears, with the query under Query .

For information about directly editing MQL expressions or changing queries by using the CLI or API, see[Editing the MQL Expression for a Query](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/query-metric-mql.htm)
