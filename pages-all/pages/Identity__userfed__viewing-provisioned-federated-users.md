# Listing Provisioned Federated Users in the Console

List the provisioned federated users in the Console.

- On the Domains list page, select the domain for which you want to list federate users. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/userfed/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the User management tab.
- On the left side of the page, select Users .
- Under Users , use filters to limit the jobs in the list.

## Filtering List Results

Use filters to limit the users in the list. Perform one of the following actions depending on the options that you see:

- From the Search and Filter box above the list table, select one or more filters and specify the values that you want to use to narrow the list. In general, the filters correspond to the columns shown in the list table, although some filters represent attributes that aren't shown in the table. The Compartment filter is always displayed next to Applied filters .
- On the left side of the list page, select a value from one of the available filters, such as compartment, state, or tags.

Change the order of the items in the list table by using the sort icons next to the column names.

For information about searching for resources and managing the columns in the list table, if those features are available, see[Listing Resources](https://docs.oracle.com/iaas/Content/GSG/Concepts/new-console.htm#new_console_list).

## Actions

In the list table, select the name of a user to open its details page, where you can view its status and perform other tasks.

To perform an action on a user directly from the list table, select any of the following options from the Actions menu (three dots) in the row for that user:
- View details : Open the details page for the user.
- Reset password :[Reset the user password](https://docs.oracle.com/en-us/iaas/Content/Identity/userfed/../users/reset-passwords-user-accounts.htm).
- Manage tags : Add one or more tags to the user. See[Resource Tags](https://docs.oracle.com/iaas/Content/General/Concepts/resourcetags.htm).
- Open support request : Open the Support Request panel, in which you can access support options. See[Support Requests](https://docs.oracle.com/iaas/Content/GSG/Tasks/contactingsupport.htm)
