# Listing Image Shape Compatibility Entries for a Roving Edge Infrastructure Device

Describes how to list the image shape compatibility entries for the image on your Roving Edge Infrastructure device.

- [CLI](https://docs.oracle.com/en-us/iaas/Content/Rover/Compute/Image/list_image-shape-compatibility-entry.htm#)

- 

Open the navigation menu and select Compute &gt; Images . The Custom Images page appears. All custom images are listed in tabular form.
- 

Select a State from the list to limit the images displayed to that state.
- 

Select the image whose details you want to get. The image's Details page appears.
- 

Select Edit Details . The list of compatible shapes for the image is displayed.
-
