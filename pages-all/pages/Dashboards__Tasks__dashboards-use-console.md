# Using Dashboards

After you create dashboards for an OCI tenancy, you can search, switch between, refresh, and duplicate them.

## Switching to or Searching for Another Dashboard
- Open the navigation menu. Under Home , select Dashboards .

The default dashboard opens.
- Select Change dashboard .
- In the Change dashboard panel, select Search dashboards or View by compartment and dashboard group .
- 

If you chose Search Dashboards , in the search box, enter the name of the dashboard that you want. The results include matching dashboards in all compartments and dashboard groups. Select a dashboard from the list.
- 

If you chose View by compartment and dashboard group , select a compartment and a dashboard group, and then select a dashboard from the list.

## Refreshing Dashboard Data
- Open the navigation menu. Under Home , select Dashboards .

The default dashboard opens. If needed,[switch dashboards](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/dashboards-use-console.htm#top__switch).
- To refresh the dashboard data manually, select the Refresh dashboard icon.
- To set the dashboard data to refresh automatically, in the Auto refresh menu, select Auto refresh every 5 min .

## Duplicating a Dashboard
- Open the navigation menu. Under Home , select Dashboards .

The default dashboard opens. If needed,[switch dashboards](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/dashboards-use-console.htm#top__switch).
- Select Dashboard actions and select Duplicate .

A duplicate dashboard is created.
- Optionally,[rename the dashboard](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/edit-dashboard.htm#top)
