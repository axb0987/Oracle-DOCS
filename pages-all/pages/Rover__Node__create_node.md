# Creating a Roving Edge Device 1 Node (Deprecated)

Oracle is no longer shipping Roving Edge first generation devices that are based on the RED.GPU.1.RX1.40 shape, so there's no need to create a node for these devices.

Instead, see[Creating and Submitting a Node for Compute, GPU, and Storage Devices](https://docs.oracle.com/en-us/iaas/Content/Rover/Node/../Node2/create_node2.htm#top).

For information about Roving Edge models and shapes, see[Roving Edge Infrastructure Device Specifications](https://docs.oracle.com/en-us/iaas/Content/Rover/Node/../device_specifications.htm#DeviceSpecifications)
