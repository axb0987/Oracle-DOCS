# Getting a Snapshot Policy's Details

Get details about a File Storage snapshot policy.

- [Console](https://docs.oracle.com/en-us/iaas/Content/File/Tasks/snapshot-policy-get.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/File/Tasks/snapshot-policy-get.htm#)

- 

On the Snapshot Policies list page, select the snapshot policy that you want to work with. If you need help finding the list page or the snapshot policy, see[Listing Snapshot Policies](https://docs.oracle.com/en-us/iaas/Content/File/Tasks/../Tasks/snapshot-policy-list.htm).

The details page opens and displays information about the snapshot policy. Some items on the page are read-only, and other items enable you to edit and update the snapshot policy's configuration. Access the various resources associated with the snapshot policy by selecting their links or tabs.
