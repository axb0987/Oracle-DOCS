# Adding a User to a Group

Add a user in an OCI IAM identity domain to a group.

Note  
  
To add multiple users in a group, you can import them from a csv file. See[Importing Groups](https://docs.oracle.com/en-us/iaas/Content/Identity/users/../datatransfer/import-groups.htm)

- On the Domains list page, select the domain in which you want to make changes. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/users/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the User management tab, and then go to the User section of the tab.
- Under Identity domain on the left side of the page, select Users .
- Select a person's username to see their details.
- Select the Groups tab.
- Select Assign user to groups . To search for groups to assign to the user account, in the search field, enter all or part of the beginning of the group names or descriptions that you want to find.
- In the Assign user to groups window, select the checkbox for each group that you want to assign to the user account.
