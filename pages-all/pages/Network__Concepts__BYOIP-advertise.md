# Advertising BYOIP CIDR Block or Prefix

Advertise a BYOIP CIDR block or prefix using your Autonomous System Number (ASN).

## Using the Console

- Open the navigation menu and select Networking . Under IP management , select BYOIP .
- On the BYOIP page, select the Actions menu (three dots) for the BYOIP IPv4 CIDR block or IPv6 prefix that you want to associate your ASN with and select Advertise .
- Confirm the advertisement.

## Using the API

Run the[AdvertiseByoipRange](https://docs.oracle.com/iaas/api/#/en/iaas/latest/ByoipRange/AdvertiseByoipRange)
