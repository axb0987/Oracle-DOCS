# Examples

This topic contains a list of OCI PowerShell Cmdlet usage examples.

Examples of OCI PowerShell Cmdlet usage can be found on[GitHub](https://github.com/oracle/oci-powershell-modules/blob/master/Examples), including:
- [Creating an instance using waiters](https://github.com/oracle/oci-powershell-modules/blob/master/Examples/Waiter_Core.ps1)
- [Accessing OCI cmdlet history store](https://github.com/oracle/oci-powershell-modules/blob/master/Examples/HistoryStore_Identity.ps1)
- [Using OCI cmdlet common parameters](https://github.com/oracle/oci-powershell-modules/blob/master/Examples/CommonParameters_Audit.ps1)
- [Downloading an object from Object Storage](https://github.com/oracle/oci-powershell-modules/blob/master/Examples/Streams_ObjectStorage.ps1)
- [Setting preferred region and profile per session](https://github.com/oracle/oci-powershell-modules/blob/master/Examples/SessionPreferences_Limits.ps1)
- [List all available Compute Images](https://github.com/oracle/oci-powershell-modules/blob/master/Examples/Pagination_Core.ps1)
- [Searching resources using polymorphic objects](https://github.com/oracle/oci-powershell-modules/blob/master/Examples/PipelineCleanup_ResourceSearch.ps1)

If you'd like to see another example not already covered, file a[GitHub issue](https://github.com/oracle/oci-powershell-modules/issues).
