# Migrating Databases to the Cloud

Learn about how you can migrate your Oracle Databases to OCI.

Oracle Cloud Infrastructure offers the Database Migration service and the Zero Downtime Migration tool for migrating Oracle database workloads from on-premises and Oracle Cloud Infrastructure Classic to a variety of Oracle Database Cloud services.

The[Database Migration Service](https://docs.oracle.com/en/cloud/paas/database-migration/)is an OCI-managed service based on the ZDM tool. Database Migration provides you with a user interface to move Oracle databases to Oracle Cloud.

[Zero Downtime Migration](https://docs.oracle.com/en/database/oracle/zero-downtime-migration/)(ZDM) is an installable tool which provides you with a simplified and automated migration experience, providing zero to negligible downtime for the production system.
Tip  
  

In most cases, the OCI Database Migration service and the ZDM tool are the best options for migrating databases to OCI. Oracle does provide other methods that might be appropriate for specific scenarios. The[OCI Migration Methods Advisor](https://apexadb.oracle.com/ords/r/dbexpert/migration-methods/home)will help you choose the best approach for your database migration.
