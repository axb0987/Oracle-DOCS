# Listing Edge Policy Access Rules

Use Web Application Firewall to list the access rules for an edge policy.

- [Console](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessRules/list_access_rule.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessRules/list_access_rule.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessRules/list_access_rule.htm#)
- 

- Open the navigation menu and select Identity &amp; Security . Under Web Application Firewall , select Edge Policy Resources .

The Policies list opens. All edge policies are listed in a table.
- (Optional) Filter the listed policies by name, status, policy type ( Edge policy ), or creation date.
- Select the name of the edge policy you want to list.
- On the policy details page, select Access control .
- Select the Access rules tab.

All the access rules for the edge policy are listed.
