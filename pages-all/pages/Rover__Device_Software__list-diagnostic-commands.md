# Listing Diagnostic Command for a Roving Edge Infrastructure Device

Describes how to list the diagnostic commands for a Roving Edge Infrastructure device.

## Using the Device Console

- Open the navigation menu and select Node Management &gt; Diagnostic Commands . The Diagnostic Commands page appears.
- Select a Command Type from the list to limit the diagnostic commands displayed to that type.
