# Listing Data Sync Tasks for Roving Edge Infrastructure

Describes how to list the data sync tasks for your Roving Edge Infrastructure devices.

## Using the Device Console

- 

Open the navigation menu and select Data Sync .

The Data Sync Tasks page appears. All data synchronization tasks are listed in tabular form.
