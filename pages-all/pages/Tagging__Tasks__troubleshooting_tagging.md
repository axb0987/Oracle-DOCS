# Troubleshooting

This topic provides troubleshooting solutions for problems you might encounter using Tagging.

## "Can't enable definition &lt;tag definition&gt; in retired namespace &lt;namespace name&gt;"? error occurs while deleting a Tag Key Definition

You cannot delete a tag key definition in a retired namespace. Reactivate the tag namespace and then retire the tag. For more information, see[Tags and Tag Namespace Concepts](https://docs.oracle.com/en-us/iaas/Content/Tagging/Tasks/managingtagsandtagnamespaces.htm)
