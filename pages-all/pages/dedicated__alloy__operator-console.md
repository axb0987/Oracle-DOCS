# Operator and Fusion Consoles

Oracle Alloy partners primarily use two interfaces to manage the environment:
- 

Operator Console: Use the Operator Console for customer lifecycle actions, subscription pricing rules, business reporting dashboards, branding, content, notifications, security access points, and customer console verification.
- 

Fusion Console: Use the Fusion Console for Oracle-facing support administration, Fusion security administration, order entry, invoicing, baseline price list and rate card maintenance, alternate-currency enablement, spreadsheet-based bulk price updates, and discounting attachments.

The Operator Console home page provides direct entry points to the Security Dashboard, Fusion Support, Fusion Orders, Fusion Invoicing, and the customer console. These paths support common operator tasks while keeping customer-facing administration and Oracle-facing workflows separated.

Operator readiness is supported through digital onboarding, Oracle PartnerNetwork training, hands-on labs, and assigned onboarding support through region activation.
