# Filtering Service Search Results

Apply filters to narrow down a list of search results related to services according to the service group name.
Understanding the following information can help you filter service search results to better find what you need:
- By default, if you have more than one string with spaces between them in a free text search or in basic search mode, the Console finds resources containing any of the search strings. Search doesn't try to find resources containing all the search strings. For more information about free text searches, see[Free Text Search](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/../Concepts/freetextsearch.htm).
- You can use the in-page search box when working with a list of search results to apply filters to the results. If available, you can also use the filters in column headings.
- You can clear filters. For more information, see[Clearing Service Search Filters](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/searchingservices_topic-Clearing_Filters.htm).
- You can change filters.
- You can sort results. For more information, see[Sorting Service Search Results](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/searchingservices_topic-Sorting_Results.htm).

## Using the Console

These steps assume that you already performed a free text search and selected the Services category of results according to the instructions in[Performing a Free Text Search](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-To_perform_a_free_text_search.htm).

- Depending on the options available, perform one of the following actions:
- On the Service search results page, in the search box, select the Service group filter.
- On the Services page, in the search box, select the Service group filter.
- In the list of filters shown, select the checkbox next to one or more service groups to include in the filtered search results. (Available service groups depend on the results in the results list.) If needed, enter text to find service groups.
