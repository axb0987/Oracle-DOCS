# Adding Applications to a Sign-on Policy

Add applications to a sign-on policy.

- On the sign-on policy details page, select Applications tab. The list of applications already added to the policy is displayed.
- Select Add app .
- In the Add app window, select the applications that you want to add to the policy. If you don't see the app you're looking for, you might need to scroll and select the page arrow (&gt;) to scroll to another page.
- Select Add app .

Note  
  
For more information on applications, see[Managing Applications](https://docs.oracle.com/en-us/iaas/Content/Identity/signonpolicies/../applications/overview.htm)
