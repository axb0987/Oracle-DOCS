On the VTAPs list page, select the VTAP that you want to work with. If you need help finding the list page or the VTAP, see[Listing VTAPs](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vtap-list.htm#top).

The details page opens and displays information about the VTAP. Some items on the page are read-only, and other items enable you to edit and update the VTAP's configuration. Access the various resources associated with the VTAP by selecting their links or tabs.
