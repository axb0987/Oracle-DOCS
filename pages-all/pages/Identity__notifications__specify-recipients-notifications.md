# Testing Notifications

Send notifications from an identity domain in IAM to selected recipients to test and verify your changes.

- Open the navigation menu and select Identity &amp; Security . Under Identity , select Domains .
- Click the name of the identity domain that you want to work in. You might need to change the compartment to find the domain that you want.
- Select Notifications .
- Select the Recipients tab.
- To turn on testing of notifications, select the Limited recipients list checkbox.
- In the Test recipient email addresses text box, and enter the email addresses to send the test notifications to.
- Select Save changes .
- In the confirmation window, select Save changes .
- Verify that notifications are working correctly.
- Clear the Limited recipients list checkbox to begin sending the customized notifications to all users.
- Select Save changes .
