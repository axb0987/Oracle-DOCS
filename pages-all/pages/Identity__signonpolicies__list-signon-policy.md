# Listing Sign-On Policies

List the sign-on policies for the domain.

- Open the navigation menu and select Identity &amp; Security . Under Identity , select Domains .
- On the Domains page, select the domain for which you want to list the sign-on policies. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/signonpolicies/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the Domain policies tab, and then go to the Sign-on policies section on the tab
- Select Security and then select Sign-on policies .
