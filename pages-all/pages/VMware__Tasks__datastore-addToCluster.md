# Adding a Datastore to a Datastore cluster

Add a VMware Solution datastore to a datastore cluster.

## Using the Console

Note  
  
This task documents the steps to add a datastore to a datastore cluster using the Oracle Cloud Console. To use the API, see`AddDatastoreToDatastoreCluster`in the[API reference](https://docs.oracle.com/iaas/api/#/en/vmware/). To use the CLI, see`add-datastore`in the[command line reference](https://docs.oracle.com/iaas/tools/oci-cli/latest/oci_cli_docs/cmdref/ocvs.html).

- Open the navigation menu and select Hybrid . Under VMware Solution , select Datastore .
The Datastores list opens. All datastores are displayed in a table.
- Select the datastore you want to work with.
- Select Add to Datastore Cluster
- In the Add to Datastore Cluster panel, select the datastore cluster to which you want to add this datastore.
