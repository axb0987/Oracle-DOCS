# Synchronizing a User

Command to synchronize a user.

The`syncUser`command enables you to manually synchronize crypto users (CU) or cypto officers (CO) across HSM instances within a cluster. This command is supported only on Server mode.

In the User Management utility, open a command prompt and run`syncUser`command.
