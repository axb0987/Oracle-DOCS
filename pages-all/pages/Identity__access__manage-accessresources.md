# Managing Access to Resources

Control access to Oracle Cloud Infrastructure resources.

You can write policies to control access to all services within Oracle Cloud Infrastructure. You can also grant access to tasks and resources in an identity domain by assigning users to administrator roles.
- [Understanding Administrator Roles](https://docs.oracle.com/en-us/iaas/Content/Identity/access/../roles/understand-administrator-roles.htm): Learn about administrator roles and the privileges associated with each role.
- [IAM Policies Overview](https://docs.oracle.com/en-us/iaas/Content/Identity/access/../policieshow/Policy_Basics.htm)Understand how policies work.
- [Managing Policies](https://docs.oracle.com/en-us/iaas/Content/Identity/access/managing-user-credentials.htm): Create, edit, and delete policies.
- [Managing User Credentials](https://docs.oracle.com/en-us/iaas/Content/Identity/access/../networksources/managingnetworksources.htm): Find out how to work with IAM user credentials.
- [Managing Network Sources](https://docs.oracle.com/en-us/iaas/Content/Identity/access/../networksources/managingnetworksources.htm): Learn how to work with network sources.
