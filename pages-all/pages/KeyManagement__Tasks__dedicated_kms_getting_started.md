# Getting Started

Get started with Dedicated KMS functionality.
To get started with Dedicated KMS, you must first provision an HSM cluster. After you provision, you must install the client components and then use the PCKS#11 libraries to perform cryptographic operations.
- [Provisioning an HSM cluster](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/dedicatedkms_provisioning_hsm_cluster.htm)
- [Installing client components](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/dedicated_kms_installing_client_components.htm)
- [Using PKCS #11](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/dedicated_kms_pkcs_library.htm)
