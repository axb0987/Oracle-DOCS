# Viewing Default Metric Charts for Topics

View metric charts that use predefined service queries for messages sent to topics in Notifications. Default metric charts are available on the Service Metrics page and resource details pages in the Console.

The following pages describe tasks you can perform with default metric charts for messages sent to topics:
- [Viewing Default Metric Charts for All Topics](https://docs.oracle.com/en-us/iaas/Content/Notification/Tasks/view-chart-namespace.htm)
- [Viewing Default Metric Charts for a Single Topic](https://docs.oracle.com/en-us/iaas/Content/Notification/Tasks/view-chart-resource.htm)
