# Performance Monitor and Management

Oracle Autonomous AI Database Serverless includes several features that automatically monitor, analyze and optimize the performance of your Autonomous AI Database.
- 

[Use OCI Ops Insights on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-operations-insights.html#GUID-FA8C943F-A535-4260-B8CB-A96A45CFBF14)

OCI Ops Insights is a cloud-native service that enables users to make informed, data-driven, Autonomous AI Database resource and performance management decisions.
- 

[Manage Optimizer Statistics on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/manage-optimizer-stats.html#GUID-69906542-4DF6-4759-ABC1-1817D77BDB02)

Describes Autonomous AI Database commands to run when you need to gather optimizer statistics or enable optimizer hints.
- 

[Manage Automatic Indexing on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-auto-index.html#GUID-D51A4F85-3AE5-4B7D-9B27-32CEDE8DBD79)

Automatic indexing automates the index management tasks in Autonomous AI Database. Auto Indexing is disabled by default in Autonomous AI Database.
- 

[Manage Automatic Partitioning on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/mdw-managing-automatic-partitioning-autonomous-database.html#GUID-03973BB7-BD09-4E5E-B47F-430D7CC949D6)

Automatic partitioning analyzes and automates partition creation for tables and indexes of a specified schema to improve performance and manageability in Autonomous AI Database.
