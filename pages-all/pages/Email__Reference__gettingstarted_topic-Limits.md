# Limits

The Oracle Cloud Infrastructure Email Delivery has service limits for enterprise and individual accounts. Administrators can use compartment quotas to set compartment-specific limits.

See[Email Delivery Service Capabilities and Limits](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/../Concepts/overview.htm#Service)
