# Downloading a Diagnostic Command's Output for a Roving Edge Infrastructure Device

Describes how to download a diagnostic command output for a Roving Edge Infrastructure device.

## Using the Device Console

- Open the navigation menu and select Node Management &gt; Diagnostic Commands . The Diagnostic Commands page appears. All the diagnostic commands are listed in tabular form.
- Select a Command Type from the list to limit the diagnostic commands displayed to that type.
- Select the diagnostic command whose output you want to download. The diagnostic command's Details page appears.
- Select Command Output under Resources . The VNIC Packet Capture page appears.
- Wait until the diagnostic command is in a Completed state, then proceed to the next step.
- Select the the Actions menu ( ) to the right of the diagnostic command and select Download Command Output . The Download Command Output dialog box appears.
- Select Download . The diagnostic command output is downloaded to your local computer as a`tar.gz`
