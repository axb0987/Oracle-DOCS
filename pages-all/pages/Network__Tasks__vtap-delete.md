# Deleting a VTAP

Delete a Virtual Test Access Point (VTAP).

For more information and a feature overview, see[Virtual Test Access Points (VTAPs)](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vtap.htm).

- [Console](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vtap-delete.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vtap-delete.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vtap-delete.htm#)
- 

- On the VTAPs list page, find the VTAP that you want to work with. If you need help finding the list page or the VTAP, see[Listing VTAPs](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vtap-list.htm#top).
- From the Actions menu (three dots) for the VTAP you want to delete, select Delete .
- When prompted, confirm the deletion.
