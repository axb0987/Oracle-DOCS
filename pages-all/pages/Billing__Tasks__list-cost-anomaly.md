# Listing Cost Anomalies

Get a list of cost anomalies in Billing and Cost Management. The cost anomaly detection algorithm is evaluated daily for each cost monitor. When a cost anomaly is detected it's added to the list of cost anomalies.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/list-cost-anomaly.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/list-cost-anomaly.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/list-cost-anomaly.htm#)
- 

- Open the navigation menu and select Billing &amp; Cost Management . Under Cost Management , select Cost Anomaly Detection .

The Cost anomaly page opens. All cost anomalies are displayed in a table.
- Select Cost Anomalies .

The Cost anomalies list page opens. All cost anomalies are displayed in a table. The table sorts anomalies by date, from newest to oldest, for a default range of the last 14 days.
- Select Summary stats to view the average cost impact and variance for the filtered list of anomalies.
- Select the Manage columns icon on top-right of the column to hide or rearrange the columns. The following columns are shown by default:

Column Name Description Default Visibility
Anomaly date Date the cost anomaly was detected. Visible
Name

Identifier generated by OCI with the following syntax: Cost Monitor Name: YYYY-MM-DD .

Default Cost Monitors appear as &lt;Service: YYYY-MM-DD&gt; Visible

Expected cost The forecasted daily cost for the cost monitor. Visible

Cost impact The difference between the forecast and the actual daily cost. Visible
Cost variance The difference between the forecast and the actual daily cost as a percentage. Visible
