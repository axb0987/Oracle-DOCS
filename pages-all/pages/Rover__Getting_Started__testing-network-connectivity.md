# Testing Network Connectivity

On a Roving Edge device, you can use serial console commands to test network connectivity. The following tests are available:
- Ping : Tests network connectivity by sending an echo request data packet to a target device and measures the time it takes for the reply to return.
- Traceroute : Traces the path that internet packets take from the device to a destination across an IP network.
Tip  
  
These commands can help you diagnose connectivity issues.
- Connect to the serial console. See[Operating the Serial Console](https://docs.oracle.com/en-us/iaas/Content/Rover/Getting_Started/setting_up_devices.htm#OperatingSerialConsole).
- In the Roving Edge Device main menu, select Advanced Menu .
- Select Network Management .
- Select Diagnostic Commands .
- 

Select any of the following diagnostic operations to test connectivity to a destination:
- Ping : When prompted, enter the destination hostname or IP address. After collecting the responses, press ENTER to stop the pings.
