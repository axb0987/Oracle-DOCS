# Listing the Dashboards in a Dashboard Group

View all the Console dashboards within a dashboard group in a tenancy.
- [Console](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/listing-dashboards.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/listing-dashboards.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/listing-dashboards.htm#)
- 

- Open the navigation menu. Under Home , select Dashboards .
- In the dashboard banner, select Manage dashboards . Then select Dashboard groups .
- If needed, under List Scope , change the compartment.
- Select the name of the dashboard group that contains the dashboards that you want to see.
The dashboards in the group are displayed on the dashboard group details page.
