# Response Control for a Web Application Firewall Policy

Create and manage response control access rules for a web application firewall policy.

The response control manages the inspection of HTTP response properties and the return a defined HTTP response. Manage the response control through the Access Control resource of the web application firewall policy.

You can perform the following response control management tasks:

[List the response control rules in a compartment](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/list_response_control.htm#top).

[Add a response control rule to a policy](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/create_access_rule_response_control.htm#top).

[View a response control rule's details](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/get_access_rule_response_control.htm#top).

[Update a response control rule's settings](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/update_access_rule_response_control.htm#top).

[Change a response control rule's actions](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/change_action_response_control.htm#top).

[Reorder the response control rules for a policy](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/reorder_action_response_control.htm#top).

[Delete a response control rule from the compartment](https://docs.oracle.com/en-us/iaas/Content/WAF/AccessControl/delete_access_rule_response_control.htm#top)
