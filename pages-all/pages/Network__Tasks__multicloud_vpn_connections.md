# Multicloud VPN Connections

Use Site-to-Site VPN and Libreswan to connect Oracle networks to other cloud providers.

You can use[Libreswan](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/../Reference/libreswanCPE.htm)to establish multicloud connections from OCI to other cloud service providers. For details see one of the following articles:
- [VPN Connection to AWS](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vpn_to_aws.htm)
- [VPN Connection to Azure](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vpn_to_azure.htm)
- [VPN Connection to Google](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vpn_to_gcp.htm)
