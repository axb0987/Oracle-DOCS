# Tagging an Events Rule

Add metadata to a rule, which enables you to define keys and values and associate it with resources.

You can apply tags to your events rules to help you organize them according to your business needs. Apply tags at the time you create an events rule, or update the events rule with tags later. For more information about applying tags, see[Overview of Tagging](https://docs.oracle.com/iaas/Content/Tagging/Concepts/taggingoverview.htm).

The following sections describe how you can apply tagging to an events rule:
