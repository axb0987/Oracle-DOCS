# Getting Key Information

Learn how to retrieve details on keys stored in the HSM using the Key Management Utility.

The`getKeyInfo`command retrieves the HSM user IDs of users who can use the key, and Crypto Users (CU) with whom the key is shared.

Open a command prompt and run`getKeyInfo`command to retrieve the value for a key.


Parameter Description

`-k`Specifies the private key handle of the private key to be exported.
