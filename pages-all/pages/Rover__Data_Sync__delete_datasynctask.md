# Deleting a Data Sync Task for Roving Edge Infrastructure

Describes how to delete a data sync task from your Roving Edge Infrastructure devices.
- 

Open the navigation menu and select Data Sync . The Data Sync Tasks page appears. All data sync tasks are listed in tabular form.
- 

(optional) Select a Status from the list to limit the data sync tasks displayed to that status.
- 

Check the data sync tasks that you want to delete.
- 

Select the Actions menu ( ) for the data sync task you checked and select Delete .
