# Managing Widgets

Add widgets to your Console dashboards, and then edit, refresh, duplicate, delete, and adjust the positioning of the widgets as needed.

For information about configuring specific widgets, see[Configuring Widgets](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/widgetmanagement.htm#top).

## Adding Widgets to a Dashboard
- Open the navigation menu. Under Home , select Dashboards .

The default dashboard opens. If needed,[switch dashboards](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/dashboards-use-console.htm#top__switch).
- Select + Add widget .
- In the Add new widget panel, select a widget, and if applicable, select Configure . For configuration instructions for each widget, see[Types of Console Dashboards Widgets](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/widgetmanagement.htm#types).
- Add more widgets as needed.
- When you're done adding widgets, select Save .

## Editing a Widget
- Open the navigation menu. Under Home , select Dashboards .

The default dashboard opens. If needed,[switch dashboards](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/dashboards-use-console.htm#top__switch).
- For the widget that you want to edit, select the Actions menu ( ) , and select View and edit settings .
- Change the configuration for the widget as needed. For widget configuration details, see[Configuring Widgets](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/widgetmanagement.htm#top).
- Select Save changes .

## Refreshing Widget Data
- Open the navigation menu. Under Home , select Dashboards .

The default dashboard opens. If needed,[switch dashboards](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/dashboards-use-console.htm#top__switch).
- For the widget that you want to refresh, select the Actions menu ( ) and select Refresh chart .

## Duplicating a Widget
- Open the navigation menu. Under Home , select Dashboards .

The default dashboard opens. If needed,[switch dashboards](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/dashboards-use-console.htm#top__switch).
- For the widget that you want to duplicate, select the Actions menu ( ) and select Duplicate widget .

A copy of the widget is added to the dashboard.
- Select Save .

## Deleting a Widget
- Open the navigation menu. Under Home , select Dashboards .

The default dashboard opens. If needed,[switch dashboards](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/dashboards-use-console.htm#top__switch).
- For the widget that you want to delete, select the Actions menu ( ) and select Delete .

The widget is removed from the dashboard.
- Select Save .

## Changing a Dashboard's Layout
- Open the navigation menu. Under Home , select Dashboards .

The default dashboard opens. If needed,[switch dashboards](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/dashboards-use-console.htm#top__switch).
- To change the layout, select Edit layout .
