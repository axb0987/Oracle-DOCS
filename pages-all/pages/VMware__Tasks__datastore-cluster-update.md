# Renaming a VMware Solution Datastore Cluster

Change the name of a VMware Solution datastore cluster.

## Using the Console

- Open the navigation menu and select Hybrid . Under VMware Solution , select Datastore clusters .
The Datastores clusters list opens. All datastore clusters are displayed in a table.
- Select the datastore cluster you want to work with.
The datastore's details page opens.
- Select Rename from the Actions menu .
The Rename datastore panel opens.
- Enter the new name of the datastore.
