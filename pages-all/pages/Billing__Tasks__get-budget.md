# Getting a Budget's Details

Get the details of a budget in Billing and Cost Management.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/get-budget.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/get-budget.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/get-budget.htm#)
- 

On the Budgets list page, select the budget that you want to work with. If you need help finding the list page or the budget, see[Listing Budgets](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/../Tasks/list-budget.htm).

The details page opens and displays information about the budget. Some items in the page are read-only, and other items enable you to[edit and update the budget's configuration](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/update-budget.htm). Access the various resources associated with the budget by selecting their tabs.
