# Moving an Events Rule Between Compartments

Move a rule to a different compartment.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Events/Task/change-compartment-events-rule.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Events/Task/change-compartment-events-rule.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Events/Task/change-compartment-events-rule.htm#)
- 

- Navigate to the events list page. If you need help finding the list page, see[Listing Events Rules](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Task/list-events-rule.htm).
- Select a rule you want to move to a different compartment.
- Select Actions .
- Select Move Resource .

The Move resource dialog box appears.
- Select the destination compartment.
- Select Move resource .

The events rule is moved to the new compartment.
- 

Use the`[](https://docs.oracle.com/iaas/tools/oci-cli/latest/oci_cli_docs/cmdref/events/rule/change-compartment.html)oci events rule change-compartment`command and required parameters to move an events rule between compartments
