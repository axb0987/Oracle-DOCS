# Non-commercial Realms

Learn about DNS configuration in non-commercial realms.

In the following government realms, add the DKIM Text Record Value to the DNS instead of adding the CNAME and CNAME Record Value . The Text Record Value is available using the[Console](https://docs.oracle.com/en-us/iaas/Content/Email/Tasks/managing_dkim-create_dkim_record.htm#console)or[API](https://docs.oracle.com/en-us/iaas/Content/Email/Tasks/managing_dkim-create_dkim_record.htm#api).
- Oracle Cloud Infrastructure US Government Cloud with FedRAMP High Joint Authorization Board (OC2)
- Oracle Cloud Infrastructure US Federal Cloud with DISA Impact Level 5 authorization (OC3)
