# Tagging Governance Rules

Describes how to add tagging metadata to a governance rule. You can define keys and values, and associate them with resources.

You can apply tags to a governance rule to help you organize them according to your business needs. Apply tags at the time you create a governance rule, or update the governance rule with tags later. For more information about tagging, see[Resource Tags](https://docs.oracle.com/iaas/Content/General/Concepts/resourcetags.htm)
