# Deactivating a Self-Registration Profile

Deactivate a self-registration profile in IAM when you no longer need it.

- On the Self registration list page, select the profile you want to deactivate. If you need help finding the list page, see[Listing Self-Registration Profiles](https://docs.oracle.com/en-us/iaas/Content/Identity/selfregistrationprofiles/list-self-registration-profiles.htm).
- From the Actions menu (three dots) for the profile you want to deactivate, select Deactivate .
