# Viewing Queries for a Custom Metric Chart

View queries used to generate the metric chart on the Metrics Explorer page in the Console. Each query is shown as a Monitoring Query Language (MQL) expression. You can copy and paste the query to share it with others.

This page describes how to view user-defined queries on the Metrics Explorer page. To view the predefined service query for a default metric chart, see[Viewing the Query for a Default Metric Chart](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/view-chart-query.htm).

- [Create a basic query](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/metrics-explorer-basic-query.htm)on the Metrics Explorer page.
You can optionally use multiple queries.
- If the query isn't open, open it by selecting Edit queries .

Under each query label ("Query" followed by a number) is the corresponding query, shown as a Monitoring Query Language (MQL) expression.

For an example, see[Example Query and Metric Chart](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/query-metric-landing.htm#example). For information about directly editing MQL expressions or changing queries by using the CLI or API, see[Editing the MQL Expression for a Query](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/query-metric-mql.htm)
