# Editing a Terms of Use Document

Update a terms of use document for an identity domain in IAM.

- On the Terms of use documents list page, find and select the name of the terms of use document to edit. If you need help finding the list page, see[Listing Terms of Use Documents](https://docs.oracle.com/en-us/iaas/Content/Identity/termsofuse/list-terms-of-use.htm#console).
- Select Edit terms of use document .
- Update the name, description, and expiration values as needed.

Note  
  
You can't change the name of the default terms of use.
