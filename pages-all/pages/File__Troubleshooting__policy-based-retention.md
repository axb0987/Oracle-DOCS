# Can't Set Retention Duration in a Schedule

When adding or updating a snapshot schedule, a "Retention duration is too long" or "Retention duration is too short" error occurs.

Each schedule within a snapshot policy has its own retention duration, and each type of schedule has a maximum retention duration. For more information, see[Snapshot Retention Duration](https://docs.oracle.com/en-us/iaas/Content/File/Troubleshooting/../Tasks/snapshot-policies-and-schedules.htm#snapshot-policies-and-schedules__retention).
