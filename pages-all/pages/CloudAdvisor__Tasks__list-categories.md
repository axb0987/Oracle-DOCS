# Listing Categories

Use the Console , CLI , or API to list categories.

- [CLI](https://docs.oracle.com/en-us/iaas/Content/CloudAdvisor/Tasks/list-categories.htm#)

- 

- Open the navigation menu and select Governance &amp; Administration . Under Cloud Advisor , select Recommendations .
- On the Recommendations page, from the Search and Filter box above the list table, select Category .
The list of available categories displays:
- Cost management
- Performance
- High availability
-
