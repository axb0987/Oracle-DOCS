# Changing an IAM database password

Managed your own IAM database password.

You can manage your own IAM database password with the Console, including creating, changing and deleting it. To change an existing password, delete the existing password and add the new password. See[To change an IAM Database Password](https://docs.oracle.com/en-us/iaas/Content/Identity/Concepts/../Tasks/managingcredentials_topic-to_change_an_iam_database_password.htm)
