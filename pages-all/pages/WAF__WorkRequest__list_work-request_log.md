# Listing Web Application Firewall Work Request Logs

View a list of the work request logs for a web application firewall policy.

- [Console](https://docs.oracle.com/en-us/iaas/Content/WAF/WorkRequest/list_work-request_log.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/WAF/WorkRequest/list_work-request_log.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/WAF/WorkRequest/list_work-request_log.htm#)

This task can't be performed using the Console.
- 

Use the[oci waf work-request-log list](https://docs.oracle.com/iaas/tools/oci-cli/latest/oci_cli_docs/cmdref/waf/work-request-log/list.html)command and required parameters to list work request logs for a web application firewall policy:

For a complete list of parameters and values for CLI commands, see the[CLI Command Reference](https://docs.oracle.com/iaas/tools/oci-cli/latest/oci_cli_docs/).
-
