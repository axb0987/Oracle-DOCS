# Searching Marketplace Listings

You can use Search to find listings in Oracle Cloud Infrastructure Marketplace.
Search supports the following tasks for finding Marketplace listings:
- [Performing a Free Text Search](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-To_perform_a_free_text_search.htm)
- [Reusing Recent Search Terms](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-To_reuse_recent_search_terms.htm)

For more information about working with listings in Marketplace, see[Working with Listings](https://docs.oracle.com/iaas/Content/Marketplace/Tasks/workingwithlistings.htm)
