# Tagging a Recipient Invitation

Describes how to add tagging metadata to a recipient invitation. You can define keys and values, and associate them with resources.

You can apply tags to a recipient invitation's resources to help you organize them according to your business needs. Apply tags when updating an invitation. For more information about tagging, see[Resource Tags](https://docs.oracle.com/iaas/Content/General/Concepts/resourcetags.htm)
