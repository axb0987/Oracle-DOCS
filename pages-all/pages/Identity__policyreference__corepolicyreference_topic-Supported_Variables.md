# Supported Variables

Core services supported variables.

The Core Services support all the general variables, plus the ones listed here. For more information about general variables supported by Oracle Cloud Infrastructure services, see[General Variables](https://docs.oracle.com/en-us/iaas/Content/Identity/policyreference/policyreference_topic-General_Variables_for_All_Requests.htm).

Variable Variable Type Comments
`target.boot-volume.kms-key.id`String Use this variable to control whether compute instances can be launched with boot volumes that were created without a Vault service master encryption key.
