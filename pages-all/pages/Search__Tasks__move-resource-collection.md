# Moving a Resource Collection

Move a resource collection from one compartment to another compartment.

You can move a resource collection that's already published to a compartment from its current compartment to another compartment. To migrate a personal collection to a compartment instead, see[Migrating a Resource Collection](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/migrate-resource-collection.htm).

Changing the compartment of a resource collection can affect who has access to it. If needed, update permissions to avoid disruptions.

## Using the Console

- On the Resource collections list page, select the name of the resource collection that you want to move. If you need help finding the list page, see[Listing Resource Collections](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/list-resource-collections.htm).
- On the details page, perform one of the following actions, depending on the option available:
- Select Actions , and then select Move .
- Select Move .
- Select Destination compartment , and then select the compartment to which you want to move the resource collection.
