# Block Volume Metrics

View metric charts, create queries, and review details about Block Volume service metrics (the metric namespace`oci_blockstore`).

You can monitor the performance and replication status for your Block Volume resources by using metrics , alarms , and[notifications](https://docs.oracle.com/iaas/Content/Notification/home.htm).

The following pages describe tasks you can perform with Block Volume service metrics:
- [Viewing Default Metric Charts for Block Volume Resources](https://docs.oracle.com/en-us/iaas/Content/Block/References/volumemetrics-charts.htm)
- [Viewing Default Metric Charts for All Block Volume Resources](https://docs.oracle.com/en-us/iaas/Content/Block/References/volumemetrics-charts-namespace.htm)
- [Viewing Default Metric Charts for a Single Volume](https://docs.oracle.com/en-us/iaas/Content/Block/References/volumemetrics-charts-volume.htm)
- [Viewing Default Metric Charts for a Single Replica](https://docs.oracle.com/en-us/iaas/Content/Block/References/volumemetrics-charts-replica.htm)
- [Creating a Query for Block Volume Resources](https://docs.oracle.com/en-us/iaas/Content/Block/References/volumemetrics-query.htm)

For details about these metrics, see[Block Volume Metrics Reference](https://docs.oracle.com/en-us/iaas/Content/Block/References/volumemetrics-reference.htm)
