# PKCS #11 Library

Learn about using the PKCS #11 library for cryptographic operations.

PKCS #11 is a standard that specifies an API for managing keys and performing cryptographic operations in the Hardware Security Module (HSM). OCI Dedicated KMS lets you to install and implement the PKCS #11 library with PKCS #11 version 2.40.

For release history information for the Red Hat RPM package, see[Dedicated KMS Client Changelog](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/dkms_downloads.htm)
