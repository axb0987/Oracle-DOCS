# Customer Support-Related Tasks in the Customer Console

Use the Customer Console support workflow for customer-facing SR creation, updates, attachments, limit increase requests, and closure actions. Open support tasks from the Help menu, and select the request type or request list that matches the work being performed.

Task When to Use It Key Guidance
Create a technical support request Use when a customer needs to report a technical issue to the operator support organization. Open the support request from the screen where the issue was encountered. Select Technical Support, enter a clear issue summary and description, select the criticality, and select the affected service, service category, and subcategory. Technical Issue is the recommended default for most technical issues.
View and manage support requests Use when reviewing an existing technical, billing, or service-limit request. Open View support request from Help, then select Technical Support Requests, Billing Support Requests, or Service Limit Updates. Search by SR number, filter by Active or Closed state, and sort by Issue Summary, SR Number, Status, Severity, or Updated date. Common customer-visible statuses include Pending with Support, Pending with Customer, and Close Requested.
Send a message to support Use when a request is pending with the customer or when the customer must provide more information. Open the SR, select Add Comment, enter the response, and submit it. After the customer sends a message, the SR status changes to Pending with Support.
Add attachments Use when diagnostic files, screenshots, or logs are needed for a technical SR. Attachments are supported only for technical support requests. Upload one file at a time, keep each file at or below 10 MB, and do not upload unsupported file types such as.exe,.bat,.aspx, or.com. Mark the attachment as private when it contains personal information or protected health information. SR-specific attachments are deleted 7 days after the SR is closed or resolved, even if they still appear in operator tools.
Request a service limit increase Use when a customer needs additional service capacity. Open Request service limit increase from Help, select the service category and resource, and enter the reason for the request. Limit requests are not immediate. Most requests are resolved within 1 business day, but larger or resource-constrained requests can take longer. Include urgency and business context in the reason field when timing matters.
Close a support request Use when support has requested closure and the issue is sufficiently addressed. Open the SR in Close Requested status, review the final support message, and select Close Ticket only when no further work is required. A closed SR cannot be reopened.
