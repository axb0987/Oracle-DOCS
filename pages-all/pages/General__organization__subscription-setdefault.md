# Setting the Default Subscription

When more than one Oracle Universal Credits subscriptions exist in a tenancy, you can specify which subscription is the default one on the subscription mapping details page. Any active Oracle Universal Credits subscription can be configured as the default. Invited or newly created child tenancies are automatically mapped to an organization's default subscription.

Setting the default subscription is only possible from a parent tenancy with one or more Oracle Universal Credits subscriptions.

To set the default subscription:

- On the parent tenancy Subscription Mapping list page, select the subscription that you want to set as the default. If you need help finding the list page, see[Listing Subscriptions](https://docs.oracle.com/en-us/iaas/Content/General/organization/list-subscriptions.htm).

The details page displays the subscription details, along with tenancies that are assigned to the subscription.
- On the subscription mapping details page, select Make default subscription .
- Confirm setting the default subscription.
