# Renaming a VMware Solution Datastore

Change the name of a VMware Solution datastore.

## Using the Console

- Open the navigation menu and select Hybrid . Under VMware Solution , select Datastore .
The Datastores list opens. All datastores are displayed in a table.
- Select the datastore you want to work with.
The datastore's details page opens.
- Select Rename from the Actions menu .
The Rename datastore panel opens.
- Enter the new name of the datastore.
