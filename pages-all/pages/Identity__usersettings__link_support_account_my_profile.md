# Linking a My Oracle Cloud Support Account

Link your identity domains profile to a My Oracle Cloud Support account.

- Open your profile console page. If you need help finding your profile console page, see[Getting Your Profile Details](https://docs.oracle.com/en-us/iaas/Content/Identity/usersettings/get-details-my-profile.htm).
- (Optional) If needed, the Oracle account sign-in page prompts you to enter your Oracle credentials.
- Enter the Username and Password of the Oracle support account that you want to link to.
- Select Sign in .
- From Actions , select Link support account .
