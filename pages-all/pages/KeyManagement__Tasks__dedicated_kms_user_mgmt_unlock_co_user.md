# Unlock CU User

Command to unlock CU user.

The`unlockUser`command enables you to unlock a CU account. Only a Crypto Officer can unlock a user account and you must have a signature signed by the HSM owner private key. After successful verification, an unlocked session is created.

In the User Management utility, open a command prompt and run`unlockCU`command to unlock a CU account. You must log in as an CO user to run this command and you must have a signature signed by the HSM owner private key. After successful verification, an unlocked session is created.
