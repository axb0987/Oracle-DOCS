# Securing Security Advisor

This topic provides security information and recommendations for Oracle Cloud Infrastructure Security Advisor.

Security Advisor provides a way to create resources that align with Oracle's security best practices. When you would otherwise need to choose between configuration options, Security Advisor provides only the more secure option to create resources in Compute, Block Volume, Object Storage, File Storage, and Vault.

After you use Security Advisor to create a new resource, follow the security best practices for the resource whenever you modify it:
- [Securing Compute](https://docs.oracle.com/en-us/iaas/Content/Security/Reference/compute_security.htm)
- [Securing Block Volume](https://docs.oracle.com/en-us/iaas/Content/Security/Reference/blockstorage_security.htm)
- [Securing Object Storage](https://docs.oracle.com/en-us/iaas/Content/Security/Reference/objectstorage_security.htm)
- [Securing File Storage](https://docs.oracle.com/en-us/iaas/Content/Security/Reference/filestorage_security.htm)
