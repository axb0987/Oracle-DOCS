# Defining Notifications for an Alarm

Select the topic or stream to send alarm notifications to. Group or split notifications, format messages, and choose whether to repeat notifications.

For information on suppressing notifications, see[Managing Alarm Suppressions](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/suppressions.htm).

The following pages describe ways you can define notifications for an alarm.
- [Selecting a Stream as the Notification Destination for an Alarm](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/../Tasks/create-edit-alarm-notification-stream.htm)
- [Selecting a Topic as the Notification Destination for an Alarm](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/../Tasks/create-edit-alarm-notification-topic.htm)
- [Getting Event-Based Notifications for an Alarm](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/../Tasks/update-alarm-event.htm)
- [Splitting Notifications for an Alarm](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/../Tasks/update-alarm-split-messages.htm)
- [Grouping Notifications for an Alarm](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/../Tasks/update-alarm-group-messages.htm)
- [Using Dynamic Variables in Alarm Messages](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/../Tasks/update-alarm-dynamic-variables.htm)
- [Formatting Messages for an Alarm](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/../Tasks/update-alarm-friendly-formats.htm)
- [Repeating Notifications for an Alarm](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/../Tasks/create-edit-alarm-query-repeat-notifications.htm)

For alarm troubleshooting, see[Troubleshooting Alarms](https://docs.oracle.com/iaas/Content/Monitoring/troubleshooting-alarms.htm)
