# What's New

When upgrading, check for changes in behavior in Terraform, the Oracle Cloud Infrastructure (OCI) Terraform provider, and Terraform modules. Any of these items can introduce changes or add new functionality.
- Review major Terraform releases for changes in behavior when upgrading. See[Upgrading to Terraform](https://developer.hashicorp.com/terraform/language/upgrade-guides). See also[Upgrading Configurations to Terraform v0.12](https://docs.oracle.com/iaas/Content/dev/terraform/upgrading.htm).
- Review Terraform provider releases for changes in behavior when upgrading. The OCI Terraform provider is published[on the public Oracle repository](https://github.com/oracle/terraform-provider-oci/tree/master/examples/resourcemanager)
