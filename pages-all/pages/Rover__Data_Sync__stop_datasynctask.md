# Stopping a Data Sync Task for Roving Edge Infrastructure

Describes how to stop a data sync task in progress for your Roving Edge Infrastructure devices.
- 

Open the navigation menu and select Data Sync . The Data Sync Tasks page appears. All data sync tasks are listed in tabular form.
- 

(optional) Select a Status from the list to limit the data sync tasks displayed to that status.
- 

Check the data sync task that you want to stop.
- 

Select Stop . Alternately, select the Actions menu ( ) for the data sync task that you checked and select Stop .
- 

Confirm the stop when prompted.
