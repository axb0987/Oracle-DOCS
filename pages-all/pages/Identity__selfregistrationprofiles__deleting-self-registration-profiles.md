# Deleting a Self-Registration Profile

You can delete self-registration profiles in IAM that you aren't using.

- On the Self registration list page, select the profile you want to delete. If you need help finding the list page, see[Listing Self-Registration Profiles](https://docs.oracle.com/en-us/iaas/Content/Identity/selfregistrationprofiles/list-self-registration-profiles.htm).
- Select the profile you want to delete (checkbox).
- Select Delete .
