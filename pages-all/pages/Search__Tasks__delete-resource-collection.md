# Deleting a Resource Collection

Delete a resource collection when you no longer need it.
Deleting a resource collection makes it permanently unavailable. Deleting the resource collection doesn't impact any of the resources in the resource collection's search results.
Note  
  
You can't restore a resource collection after you delete it.

## Using the Console

- On the Resource collections list page, select the name of the resource collection that you want to delete. If you need help finding the list page, see[Listing Resource Collections](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/list-resource-collections.htm).
- On the details page, perform one of the following actions, depending on the option available:
- Select Actions , and then select Delete .
- Select Delete .
