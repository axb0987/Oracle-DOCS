# Resetting Default Metric Charts

Go back to default settings for default charts. Default metric charts are available on the Service Metrics page and resource details pages in the Console.

At the top of the page, select Reset charts .

For query troubleshooting, see[Troubleshooting Queries](https://docs.oracle.com/iaas/Content/Monitoring/troubleshooting-queries.htm)
