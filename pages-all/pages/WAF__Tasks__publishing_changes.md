# Publishing Changes for an Edge Policy

Publish changes for edge policies.

## Using the Console

Updates to an edge policy appear in the list to be published under Unpublished changes . Pending changes don't persist across browser sessions. After you publish changes, the changes can't be edited until they propagate to the edge nodes.
- Open the navigation menu and select Identity &amp; Security . Under Web Application Firewall , select Edge Policy Resources .

The Policies list opens. All edge policies are listed in a table.
- Select the Compartment from the list.

All the edge policies in that compartment are listed in a table.
- (Optional) Apply one or more of the following Filters to limit the edge policies displayed:
- State
- Name
- Policy Type : Select Edge Policy .
- Select the name of the edge policy that you want to publish changes for.

The edge policy's details page opens.
- On the policy details page, under Edge policy , select Unpublished changes .
- In the Unpublished changes list, select the arrow next to an unpublished change to review the change.
- Select Publish all .
- In the Publish changes panel, select Publish all .

For more information, see[WAF Protection Rules](https://docs.oracle.com/en-us/iaas/Content/WAF/Tasks/wafprotectionrules.htm#WAF_Protection_Rules)
