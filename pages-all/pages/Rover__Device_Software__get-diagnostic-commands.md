# Getting a Diagnostic Command's Details for a Roving Edge Infrastructure Device

Describes how to get the details of a diagnostic command for a Roving Edge Infrastructure device.

## Using the Device Console

- Open the navigation menu and select Node Management &gt; Diagnostic Commands . The Diagnostic Commands page appears. All diagnostic commands are listed in tabular form.
- Select a Command Type from the list to limit the diagnostic commands displayed to that type.
- Select the diagnostic command whose details you want to get. The diagnostic command's Details page appears.
