# Deleting a Key

Configure command for deleting a Key.

The`deleteKey`command enables you to delete a key. You can identify the key by its handle.

Open a command prompt and run`deleteKey`command to delete a key. You can identify the key by its handle.
Note  
  
Only a key owner can delete a key.
