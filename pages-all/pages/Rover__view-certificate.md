# Getting a Certificate's Details for a Roving Edge Infrastructure Device

Describes how to view the details of a certificate for a Roving Edge Infrastructure device node.

## Using the Device Console

- Access the Device Console for the device node for which you are creating the certificate.
- Open the navigation menu and select Node Management &gt; Certificates . The Certificates page appears. Each Roving Edge Infrastructure device node's certificate is listed.
- Select View under the Action menu (three dots at the right of the node entry) whose certificate you want to view. The View certificate dialog box opens.
