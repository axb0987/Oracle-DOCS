# Removing a Datastore from a Datastore Cluster

Remove a VMware Solution datastore from a datastore cluster.

## Using the Console

Note  
  
This task documents the steps to remove a datastore from a datastore cluster using the Oracle Cloud Console. To use the API, see`RemoveDatastoreFromDatastoreCluster`in the[API reference](https://docs.oracle.com/iaas/api/#/en/vmware/). To use the CLI, see`remove-datastore`in the[command line reference](https://docs.oracle.com/iaas/tools/oci-cli/latest/oci_cli_docs/cmdref/ocvs.html).

- Open the navigation menu and select Hybrid . Under VMware Solution , select Datastore .
The Datastores list opens. All datastores are displayed in a table.
- Select the datastore you want to work with.
- From the Actions menu (three dots) , select Remove from Datastore Cluster .
- To confirm the deletion, enter the name of the datastore you're removing.
