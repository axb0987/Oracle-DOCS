# Getting a VMware Solution SDDC's Details

View details for an SDDC in VMware Solution.

- [Console](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/sddc-get.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/sddc-get.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/sddc-get.htm#)
- 

On the Software-Defined Data Centers list page, select the SDDC that you want to work with. If you need help finding the list page or the SDDC, see[Listing SDDCs](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/../Tasks/sddc-list.htm).
The details page contains information about the SDDC, both general information and links to its resources. Some items in the page are read-only, while other items let you edit and update the SDDC's configuration. See[Editing an VMware Solution SDDC](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/sddc-update.htm)
