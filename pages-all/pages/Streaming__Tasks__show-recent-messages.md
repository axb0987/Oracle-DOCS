# Showing Recent Messages in a Stream

Show recent messages in a stream in the Streaming service, using the Console.

Note  
  
Streams that use[private endpoints](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/../Concepts/streamsecurity.htm#private_endpoints)aren't accessible from the internet, so their messages aren't displayed in the Console.

To consume messages from a stream, see[Consuming Messages](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/consuming.htm).

- On the Streams list page, select the stream that you want to work with. If you need help finding the list page or the stream, see[Listing Streams](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/../Tasks/listing-streams.htm).
