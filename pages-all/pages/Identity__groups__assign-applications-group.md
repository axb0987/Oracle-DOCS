# Assigning Applications to a Group

Assign applications to an identity domain group in IAM.

- On the Domains list page, select the domain that contains the group to which you want to assign applications. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/groups/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the User management tab.
- Under Identity domain on the left side of the page, select Groups .
- Select the group to which to assign applications.

- To assign an application to all users, find and select the All Domain Users group.
- To assign an application a group that contains a subset of users, select the name of the group.
- On the group details page, select Integrated applications .
- Select Assign applications .
- On the Assign applications page, select the Actions menu (three dots) for the application to add and then select Assign .
