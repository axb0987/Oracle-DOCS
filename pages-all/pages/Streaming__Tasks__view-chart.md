# Viewing Default Metric Charts for Streams

View metric charts that use predefined service queries for streams in Streaming. Default metric charts are available on the Service Metrics page and resource details pages in the Console.

The following pages describe tasks you can perform with default metric charts for streams:
- [Viewing Default Metric Charts for All Streams](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/view-chart-namespace.htm)
- [Viewing Default Metric Charts for a Stream](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/view-chart-resource.htm)
