# Dedicated Cloud Build Readiness

This information describes OCI Dedicated Region and Oracle Alloy build readiness.

Use this information to assess whether a site is ready to receive, install, and operate Oracle Dedicated Cloud infrastructure. The guide summarizes the facility, operations, security, and physical networking conditions that must be in place before equipment arrives onsite.

The customer is responsible for the building environment, including space, power, cooling, physical security, carrier access, and daily facilities operations. Oracle delivers and operates the cloud platform within the prepared environment.

Planning note: The values in this guide are for early site planning and readiness reviews. Oracle confirms final rack placement, approved footprint-specific values, and approved exceptions during Oracle design review. For complete requirement details and obligations, see the Dedicated Cloud Build Requirements Document.

Oracle provides a Dedicated Cloud Build Requirements Document to customers during the pre-contract process. This document includes detailed build requirements, obligations, and customer responsibilities specific to the Dedicated Cloud engagement. It is shared directly with customers.
