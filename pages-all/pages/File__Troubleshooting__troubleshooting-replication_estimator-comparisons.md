# Replication Estimator Shows Different Estimates for File Systems with Similar Size

The replication estimator shows different estimates for file systems that are about the same size.

There are many factors that affect replication time estimates, including the number of files on the file system, the size of each file, the number of snapshots, and historical data and metadata change rates. This can result in different replication time estimates for similarly sized file systems. For more information, see[Estimating Replication Time](https://docs.oracle.com/en-us/iaas/Content/File/Troubleshooting/../Tasks/fsreplication-estimating-replication-time.htm)
