# Getting a VMware Solution SDDC's Work Request's Details

View details for an SDDC work request in VMware Solution.

Work requests are spawned by starting operations such as Create SDDC .

- [Console](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/get-work-request-details.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/get-work-request-details.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/get-work-request-details.htm#)
- 

- On the Software-Defined Data Centers list page, select the SDDC that contains the work requests that you want to work with. If you need help finding the list page or the SDDC, see[Listing SDDCs](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/../Tasks/sddc-list.htm).
- On the SDDC's details page, select Work requests.
- Select the work request that you want to work with.
The details page contains information about the work request, both general information and links to its resources.
