# Updating a Resource Collection

Update a resource collection to change its name, description, visibility, or query language.

All updates to a resource collection can be changed again later except any changes to visibility. After you change a resource collection's visibility to let others see and use it by publishing it in a compartment, you can't make it personal again. The only ways to prevent others from seeing a resource collection in a compartment are to change the permissions that provide access to it or delete the resource collection and then re-create it as a personal collection.

## Using the Console

- On the Resource collections list page, select the name of the resource collection that you want to update. If you need help finding the list page, see[Listing Resource Collections](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/list-resource-collections.htm).
- (Optional) On the details page, perform one of the following actions, depending on the option available:
- Select Actions , and then select Edit .
- Select Edit .
- (Optional) If you performed the previous step, then do one or more of the following:
- To update the resource collection display name, select Name , and then enter a new friendly name. Avoid entering confidential information.
- To update the resource collection description, select Description , and then enter a new description. Avoid entering confidential information.
- To update the resource collection's visibility, under Visibility , select In compartment . You can only update a resource collection's visibility to publish it in a compartment. You can't change a resource collection's visibility to make it personal again.
- To apply any changes from the previous step, select Save .
- (Optional) To update the resource collection's search criteria, select either Search and filter or Show advanced query mode , and then change the filters or the query language, as appropriate. For more information about using basic search mode or advanced query mode, see[Filtering Resource Search Results](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-Filtering_Results.htm),[Clearing Resource Search Filters](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-Clearing_Filters.htm),[Changing Resource Search Filters](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-Changing_Filters.htm),[Running a Custom, Free-Form Query](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-To_run_a_custom_freeform_query_to_find_a_resource.htm), and[Search Language Syntax](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/../Concepts/querysyntax.htm).
