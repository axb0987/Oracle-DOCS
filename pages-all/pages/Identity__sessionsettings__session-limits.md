# Setting Session Limits

Set the duration for which a user's session is valid IAM.

- On the Session settings page, find the setting you want to change. If you need help finding the session settings page, see[Listing Session Settings](https://docs.oracle.com/en-us/iaas/Content/Identity/sessionsettings/list-session-settings.htm).
- To set the duration for which the user's session is valid, enter a value between 1 and 32,767 in Session duration (in minutes) . The user's session times out after the session duration has been reached regardless of actual user activity or inactivity.
