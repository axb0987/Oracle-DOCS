On the Log groups list page, select the log group that you want to work with. If you need help finding the list page or the log group, see[Listing Log Groups](https://docs.oracle.com/en-us/iaas/Content/Logging/Task/../Task/list-logging-log-group.htm).

The log group's details page opens and displays information about the log group. Some items on the page are read-only, and other items enable you to edit and update the log group's configuration. Access the various resources associated with the log group by selecting their links or tabs.
