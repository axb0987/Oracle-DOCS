# Using OCI Service Mesh on Clusters created with Kubernetes Engine (OKE)

Find out about Oracle Cloud Infrastructure Service Mesh and Kubernetes Engine (OKE).

Oracle Cloud Infrastructure Service Mesh was a free, Oracle-managed service that provided a set of capabilities to enable microservices within a cloud native application to communicate with each other in a centrally managed and secure manner.

As of May 31, 2025, Oracle Cloud Infrastructure Service Mesh is end of life (EOL).
