# Hiding and Showing Queries in a Custom Metric Chart

Hide and show queries to regenerate the metric chart the Metrics Explorer page in the Console. The chart uses only the queries you show.

- [Create a basic query](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/metrics-explorer-basic-query.htm)on the Metrics Explorer page.
- If the query isn't open, open it by selecting Edit queries .
- To hide a query, select Toggle query on chart ( ).
