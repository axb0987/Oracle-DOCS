# Migrating a Resource Collection

Migrate a personal resource collection to a compartment to make it available to others.

Resource collections can either be personal or published to a compartment. A personal resource collection can only be used by whoever created it. You can make a resource collection available to others by migrating it to a compartment and granting the permissions necessary to access it.
Note  
  
After migration, you can't make a resource collection personal again.

## Using the Console

- On the Resource collections list page, select the name of the resource collection that you want to migrate. If you need help finding the list page, see[Listing Resource Collections](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/list-resource-collections.htm).
- Select Actions , and then select Migrate .
- Select Compartment , and then select the compartment to which you want to publish the resource collection.
