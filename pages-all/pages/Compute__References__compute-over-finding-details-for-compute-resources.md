# Finding Details for Compute Resources

The new Oracle Cloud Console experience uses tabs to organize the information on the details page for each resource in the Compute service.

The following sections describe what information is displayed on the tabs for the resources in Compute. Depending on the resource type, you might see some or all of the tabs listed here.
