# Creating SMTP Credentials

Learn how to create SMTP credentials.

## Using the Console

- View the user's details:

- If you're generating SMTP credentials for yourself : In the navigation menu , select the Profile menu and then select User settings .
- If you're an administrator generating SMTP credentials for another user : Open the navigation menu and select Identity &amp; Security . Under Identity
Note  
  

OCI SMTP usernames are standard-compliant, and according to the standard, the username field in SMTP AUTH PLAIN standard supports up to 255 bytes.

SMTP AUTH is the standard used for SMTP email submission. For more information, see[RFC 6409](https://datatracker.ietf.org/doc/rfc6409/)and[RFC 4616](https://datatracker.ietf.org/doc/rfc4616/).
- In the domain's details page, select User management . Under Users , find the user in the list, and then click the user's name to view the details.
- Select SMTP credentials .
- Select Generate credentials .
- Enter a Description of the SMTP credentials in the dialog box.
- Select Generate credentials . A username and password is displayed.
