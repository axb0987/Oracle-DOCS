# Listing All Compliance Documents

The Console displays all the documents available to the tenancy for the selected region.

Open the navigation menu , select Identity &amp; Security , and then select Compliance .

The Compliance Documents page displays all the documents that you have permission to view.

From this page, you can perform the following actions:
- Sort documents by name, category, service, and creation date. For more information, see[Sorting a List of Compliance Documents](https://docs.oracle.com/en-us/iaas/Content/ComplianceDocuments/Concepts/compliancedocsoverview_topic-To_sort_a_list_of_compliance_documents.htm#sortdocuments).
- Download documents to a local computer. For more information, see[Downloading a Compliance Document](https://docs.oracle.com/en-us/iaas/Content/ComplianceDocuments/Concepts/compliancedocsoverview_topic-To_download_a_compliance_document.htm#downloaddocument)
