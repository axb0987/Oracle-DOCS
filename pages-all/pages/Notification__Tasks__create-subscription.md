# Creating a Subscription

Create a subscription in Notifications to receive notifications.

You can create a subscription in the same compartment as the topic that you're adding it to. If you want the subscription to be in a different compartment from its parent topic, then you can[move the subscription](https://docs.oracle.com/en-us/iaas/Content/Notification/Tasks/change-compartment-subscription.htm)after creating it.

- [Creating an HTTPS (Custom URL) Subscription](https://docs.oracle.com/en-us/iaas/Content/Notification/Tasks/create-subscription-https.htm)
- [Creating a PagerDuty Subscription](https://docs.oracle.com/en-us/iaas/Content/Notification/Tasks/create-subscription-pagerduty.htm)

- [Creating a Slack Subscription](https://docs.oracle.com/en-us/iaas/Content/Notification/Tasks/create-subscription-slack.htm)
