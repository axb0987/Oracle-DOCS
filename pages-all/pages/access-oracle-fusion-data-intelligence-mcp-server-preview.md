# Access Oracle Fusion Data Intelligence MCP Server (Preview)

This topic describes the Model Context Protocol (MCP) server provided by Oracle Fusion Data Intelligence and how to register the server with an AI client to access your analytics data.
Note  
  
Oracle Fusion Data Intelligence provides a Model Context Protocol (MCP) server that allows AI clients direct access and interaction with Oracle Analytics data and functionality. This introduces security risks since you might inadvertently expose unintended data. The Oracle Fusion Data Intelligence MCP tools are authenticated with an OAuth 2.0 access token and run with the same permissions as the user who obtains the access token. Ensure that any users who use the MCP server only have access to data that can be shared with LLMs.
