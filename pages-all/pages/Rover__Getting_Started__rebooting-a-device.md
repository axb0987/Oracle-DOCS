# Rebooting a Device

You can reboot a Roving Edge device using the serial console.

Every time you reboot a device, it reverts to a locked state.[Unlock](https://docs.oracle.com/en-us/iaas/Content/Rover/Getting_Started/unlocking.htm#UnlockingDevice)the device after a reboot.

You must have a controlling host connected to the serial port. The host must be running terminal emulation software such as PuTTY to display the serial console menu. See[Operating the Serial Console](https://docs.oracle.com/en-us/iaas/Content/Rover/Getting_Started/setting_up_devices.htm#OperatingSerialConsole)for more information.
- If the serial console screen is locked, enter the passphrase to access the menu.
- 

In the serial console, enter the menu number for Reboot Device .

The device reboots and prompts you to enter the passphrase.
