# Installing the Secure Form Fill Admin Client

You use the Secure Form Fill Admin Client (Oracle Enterprise Single Sign-On (ESSO) Administrative Console) to create and update secure form fill configuration files for your custom secure form fill apps in IAM. Use these instructions to install the Secure Form Fill Admin Client.

- On the Domains list page, select the domain in which you want to make changes. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/applications/../domains/to-view-identity-domains.htm).
- On the details page, select Settings . You may need to scroll the tabs to find the Settings tab.
- In the Downloads section, locate the Secure Form Fill Admin Client and download it. See[Downloading SDKs and Applications](https://docs.oracle.com/en-us/iaas/Content/Identity/applications/../sdkapplications/download-sdks-and-applications.htm).

Note  
  
The ESSO Administrative Console is part of the Secure Form Fill Admin Client.
- In the download location, unzip the file.
- Double-click the installer to launch the install wizard, and then select Next .
- Choose the Complete installation option, select Next , and then select Install .
- When the installation completes, select Finish .
