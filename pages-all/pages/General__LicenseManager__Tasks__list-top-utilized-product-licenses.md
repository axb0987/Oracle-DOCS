# Listing the Top Used Product Licenses in License Manager

View a list of the of the most used product licenses in a compartment.

- [Console](https://docs.oracle.com/en-us/iaas/Content/General/LicenseManager/Tasks/list-top-utilized-product-licenses.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/General/LicenseManager/Tasks/list-top-utilized-product-licenses.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/General/LicenseManager/Tasks/list-top-utilized-product-licenses.htm#)
- 

This task can't be performed using the OCI Console.

- Open the navigation menu and select Governance &amp; Administration . Under License Manager , select Overview .
The License Manager Overview page opens.
- Find the Top Utilized Product Licenses section.
The Top Utilized Product Licenses section lists the top utilized product licenses as a table. Use the filter option to find the product licenses you want.
