# Reserved IPv6 Addresses

Use reserved IPv6 addresses to statically allocate IPv6 addresses to resources within a subnet.
The following management actions are available for IPv6 addresses of all resources in a subnet:
- [Listing IPv6 Addresses of All Resources in a Subnet](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv6-viewing.htm)
- [Adding a Reserved IPv6 Address](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv6-adding.htm)
- [Editing an Existing Reserved IPv6 Address](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv6-editing.htm)
- [Reserving an Existing IPv6 Address](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv6-reserving.htm)
- [Removing an IPv6 Address Reservation](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv6-removing-reservation.htm)
- [Reserving Existing IPv6 Addresses in Bulk](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv6-reserving-in-bulk.htm)
- [Removing IPv6 Address Reservations in Bulk](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/reserved-ipv6-removing-reservations-in-bulk.htm)
