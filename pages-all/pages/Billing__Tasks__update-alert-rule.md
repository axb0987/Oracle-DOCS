# Editing a Budget Alert Rule

Edit an alert rule for a budget in Billing and Cost Management.

- 

On the Budgets list page, select the budget that contains the budget alert rule that you want to work with. If you need help finding the list page or the budget, see[Listing Budgets](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/../Tasks/list-budget.htm).
- On the details page, select the Budget Alert Rules tab.
- 

From the Actions menu (three dots) for the alert rule, select View/Edit .
- 

In the View/Edit Budget Alert Rule panel, update the settings as needed. Avoid entering confidential information. For descriptions of the settings, see[Creating a Budget Alert Rule](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/create-alert-rule.htm).
- 

Select Save Changes .
