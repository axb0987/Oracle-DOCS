# Remote Peering Management

Learn how to mange remote peering with a Dynamic Routing Gateway (DRG) in Oracle Cloud Infrastructure.

For more about peering, read[Access to Other VCNs: Peering](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/VCNpeering.htm)and[Remote VCN Peering through an Upgraded DRG](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/scenario_e.htm).

- [Connecting Two Remote Peering Connections](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/drg-rpc-connect.htm)

- [Moving an RPC to a Different Compartment](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/drg-rpc-change-compartment.htm)
