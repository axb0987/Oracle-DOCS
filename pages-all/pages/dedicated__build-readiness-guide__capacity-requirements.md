# Capacity Requirements

Use the approved rack mix to size power, cooling, and row density. The following values are standard planning values used during early design.

Rack Profile Typical Use Power Planning Cooling Planning
Standard server and network rack Baseline server, storage, and network deployments. 15 kW per rack. 150 CFM per kW.
Specialty, dense, or high-performance rack Graphics processing unit (GPU), AI and ML, and other high-density or specialty systems. 17 kW or more per rack. 150 CFM or more per kW.

Planning note: These values are planning figures and do not guarantee the final rack mix. Some rack types, including GPU-based systems, might exceed the baseline values and are confirmed during product-specific design review.
