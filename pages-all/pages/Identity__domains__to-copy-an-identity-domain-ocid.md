# Copying an Identity Domain's OCID

Copy an identity domain's OCID so that you can, for example, paste it into the search field when searching for resources related to an OCID in a tenancy in IAM.

- On the Domains list page, select the domain that you want to work with. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/domains/to-view-identity-domains.htm).
- Perform one of the following actions depending on what you see:
- On the Details tab, next to the OCID field, select Copy .
- On the Domain information tab, next to the OCID field, select Copy .
