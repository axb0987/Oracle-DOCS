# Renaming a Block Volume for a Roving Edge Infrastructure Device

Describes how to rename a block volume on your Roving Edge Infrastructure device.
- 

Open the navigation menu and select Block Storage &gt; Block Volumes . The Block Volumes page appears. All block volumes are listed in tabular form.
- 

Select a State from the list to limit the block volumes displayed to that state.
- 

Select the block volume you want to rename. The Edit Block Volume dialog box appears.
- 

Enter the block volume's new name in the Name box.
- 

Select Save Changes .

See[Renaming a Volume](https://docs.oracle.com/iaas/Content/Block/Tasks/renamingavolume.htm)
