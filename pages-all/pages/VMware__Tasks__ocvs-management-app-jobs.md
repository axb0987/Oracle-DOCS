# Monitoring VMware Solution Management Appliance Jobs in vSphere

Monitor jobs in vSphere using VMware Solution Management Appliance.

- Sign in to the vSphere web console.
You can get the link to the vSphere web console from the[SDDC Details page](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/sddc-get.htm).
- Select OCI Integration .
- Select the Jobs tab and select a job.
You can see details about the job in Job Steps .
