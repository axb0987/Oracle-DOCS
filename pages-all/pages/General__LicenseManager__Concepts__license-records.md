# License Records in License Manager

Manage the license records contained in a product license.

License records are configurations associated with the product license. They represent your licensing entitlement for a specific software product. A product license can have many license records that address specific usage attributes, such as support end dates and count.

Each license record contains the following information:
- Record name : The unique name of the license record within the product license.
- Unique identifier : Displays the license identifier a third-party vendor provides if you're not using Oracle as the vendor.
- Quantity : The license quantity available for use based on your contractual terms, and accounting for licenses used on-premises or on other cloud platforms. The quantity is either unlimited, or count. If it's count, the quantity is specified.
- License expiration : Indicates whether the license is unlimited or expires in the specified number of days.

When you create a product license, a corresponding license record is automatically generated. You can create more license records for the product license later.
