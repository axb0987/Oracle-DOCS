# View Requests

You can view access requests and revision requests that you raised for yourself or others from the My Requests page.

You'll see two tabs on the My requests page:
- Access requests : Shows all the access requests you raised for self or beneficiary.
- Revision requests : Shows all the resource revisions you raised.
You can filter all the requests (ongoing requests, previous requests, all requests) from the drop-down button.
- My ongoing requests : In progress requests that either are pending approvals or need further information are displayed. For each request, you can view details or cancel the access request.
- My previous requests : All requests completed (approved, rejected, or cancelled) are displayed. For each request, you can view details.
- All requests : All in progress and completed requests are displayed.

## Request Status
You can see one of the following request statuses:
- Pending approvals : Pending requests that needs approval
- Info requested : Requests that need additional information before a decision can be taken by the approver.
- Preparing : Access requests display this state when preventive SOD analysis is in progress.
- Approved : Requests that are approved
- Rejected : Requests that are rejected
- Cancelled : Requests that are cancelled by the requestor before a decision is taken.

## View Requests

Follow the steps to view access or revision requests from the My Requests page, as follows:

- In your browser, navigate to the Oracle Access Governance service home page, and log in.
- On the Oracle Access Governance service home page, click on the icon, then select My Stuff → My Requests . By default, the access requests tab is displayed.
- To view all the resource revisions requested by you, select the Revision requests tab.

Access requests : Displays all the resource access or resource access extension requests raised by you. You can use suggested filters, such as Info requested , Pending approvals , and so on, to narrow the scope of search.

Revision requests : Displays all the resource revisions requested by you. You can use suggested filters, such as Info requested , Pending approvals , and so on, to narrow the scope of search.

### Cancel the Request
- On the My Requests page, for an ongoing request, click the icon and select Cancel request .
- Select Confirm in the confirmation message box. A success message is displayed.

## View Request Details

View Request Details, such as access request details and request audit trail. For revision requests, you can view differences between the previous and current revision, current details, and audit trail of the request.
Additionally, on the left pane, you can view resource details that is requested or revised.

- On the My Requests page , select an appropriate tab
- For a request, click the icon and then select View details .

## Handling Information Requested Status

During review, if approver has requested additional clarification, Info Requested , the requestor must submit the required information. The additional information can be for access requests or revision requests. This typically involves:
You can provide information for a request:

- Reviewing comments or questions from the approver.
- Adding the necessary clarifications or comments.
- Resubmitting the information to re-enter the approval workflow.

- On the My Requests page , select an appropriate tab
- Access requests : To provide information for an access request
- Revision requests : To provide information for a revision request
- (Optional) Select My ongoing requests and then the suggested filter Info requested to view all the requests requiring additional information.
- Click the icon and select Provide information .
- (Optional) Additionally, click the icon and select View details and then select the Provide information button.
- Review the requested information and provide additional clarification in the response box.
- Select Respond to submit the request.
