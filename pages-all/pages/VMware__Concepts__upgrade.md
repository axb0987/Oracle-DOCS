# Upgrading a VMware Solution SDDC's Software

Learn how to upgrade the software running on the SDDC, clusters, and ESXi hosts.

When a new version of the VMware software becomes available, VMware Solution notifies you and provides a workflow that guides you through the upgrade process step-by-step. The workflow is different depending on which version you're upgrading to.
- [Upgrading a VMware Solution SDDC From V7 to V8](https://docs.oracle.com/en-us/iaas/Content/VMware/Concepts/upgrade8.htm)
- [Upgrading a VMware Solution SDDC from V6 to V7](https://docs.oracle.com/en-us/iaas/Content/VMware/Concepts/upgrade7.htm)
- [Upgrading a VMware Solution SDDC's HCX](https://docs.oracle.com/en-us/iaas/Content/VMware/Concepts/upgrading-vmware-hcx.htm)
Important  
  
You can't upgrade an SDDC and its hosts directly from version 6 to version 8. You must first[upgrade from version 6 to version 7](https://docs.oracle.com/en-us/iaas/Content/VMware/Concepts/upgrade7.htm), then[upgrade again from version 7 to version 8](https://docs.oracle.com/en-us/iaas/Content/VMware/Concepts/upgrade8.htm)
