# Managing an Identity Domain Administrator

Assign users who can administer an identity domain in IAM.

Add users to the category of administrator, based on the security levels. An identity domain administrator has superuser privileges for a domain.

You can perform the following tasks:
- [Adding Identity Domain Administrators](https://docs.oracle.com/en-us/iaas/Content/Identity/securing/iam-identity-adding-admin.htm)
- [Removing an Identity Domain Administrator](https://docs.oracle.com/en-us/iaas/Content/Identity/securing/iam-identity-removeadmin.htm)
