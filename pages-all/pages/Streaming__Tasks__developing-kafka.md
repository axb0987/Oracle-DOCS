# Developing with Kafka and Streaming

Use applications written for Kafka with the Streaming service.

Oracle Cloud Infrastructure Streaming is compatible with most Kafka APIs, allowing you to use applications written for Kafka to send messages to and receive messages from the Streaming service without having to entirely rewrite your code. Usually, modifying configuration values is the only required update.

This section contains quickstart guides showing how to produce and consume messages using the following Kafka clients:
- [Kafka Java client](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/streaming-kafka-java-client-quickstart.htm)
- [Kafka .NET client](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/streaming-kafka-dotnet-client-quickstart.htm)
- [Kafka Python client](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/streaming-kafka-python-client-quickstart.htm)

See[Using Streaming with Apache Kafka](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/kafkacompatibility.htm)for more information. Refer to the[Overview of Streaming](https://docs.oracle.com/en-us/iaas/Content/Streaming/Tasks/../Concepts/streamingoverview.htm)
