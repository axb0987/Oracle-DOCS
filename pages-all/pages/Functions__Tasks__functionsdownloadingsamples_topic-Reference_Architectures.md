# Reference Architectures

Find out about the reference architectures that are available to help you learn how to use OCI Functions.

Reference architectures are architectures, configurations, and best practices for deploying on Oracle Cloud Infrastructure. Reference architectures are available from the[Oracle Cloud Infrastructure Architecture Center](https://www.oracle.com/cloud/architecture-center/)and the[Oracle Architecture Center](https://docs.oracle.com/solutions/?q=&cType=reference-architectures).

For the latest list of reference architectures in the Oracle Architecture Center that include OCI Functions as a component, see[Reference Architectures for Functions](https://docs.oracle.com/solutions/?q=&cType=reference-architectures&product=Functions&sort=date-desc)
