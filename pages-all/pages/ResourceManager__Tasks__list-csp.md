# Listing Configuration Source Providers

List configuration source providers in Resource Manager.

- [Console](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/list-csp.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/list-csp.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/list-csp.htm#)
- 

- Open the navigation menu and select Developer Services . Under Resource Manager , select Configuration Source Providers .
The Configuration source providers list page opens. All configuration source providers in the selected compartment are displayed in a table.
- To view the configuration source providers in a different compartment, use the Compartment filter to switch compartments.
You must have permission to work in a compartment to see the resources in it. If you're not sure which compartment to use, contact an administrator. For more information, see[Understanding Compartments](https://docs.oracle.com/iaas/Content/GSG/Concepts/settinguptenancy.htm#Understa).

## Filtering List Results

Use filters to limit the configuration source providers in the list.
- To filter the list by tag, select add next to Tag filters .

## Actions

In the list table, select the name of a configuration source provider to open its details page, where you can view its status and perform other tasks.

To perform an action on a configuration source provider directly from the list table, select any of the following options from the Actions menu (three dots) in the row for that configuration source provider:
- View configuration source provider details :[Open the details page for the configuration source provider](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/get-csp.htm).
- Create stack from configuration source provider :[Create a stack using the configuration source provider](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/create-stack-from-csp.htm).
- Delete configuration source provider :[Delete the configuration source provider](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/delete-csp.htm).

To create a configuration source provider, select Create configuration source provider .
