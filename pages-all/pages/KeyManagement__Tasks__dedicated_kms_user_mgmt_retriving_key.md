# Getting Key Info

Command to get key info.

The`getKeyInfo`command retrieves information about the key owners, users with which it is shared, and whether it is a token or session key.

In the User Management utility, open a command prompt and run`getKeyInfo`command to get information about the key owners, users with which it is shared, and whether it is a token or session key.
