## Cloud Migrations

The Oracle Cloud Migrations service automates the migration of virtual machines from on-premises environments to OCI. Using a simple managed connection with your data center, you can discover assets capable of migrating, group source workloads into migration projects, schedule data replication, and launch the migrated virtual machines to OCI.
