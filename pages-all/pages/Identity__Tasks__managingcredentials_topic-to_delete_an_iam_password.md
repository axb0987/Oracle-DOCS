# To delete an IAM database password

Use the Console to delete a database password.

You can delete your own IAM database password.
- Log in to the OCI IAM console.
- In the upper right corner of the window, select the profile icon. This takes you directly to your user profile page.
- In your user profile page, select your user name.
- Under Resources , select Database Passwords.
- Your user name is displayed in the Database Passwords section.
