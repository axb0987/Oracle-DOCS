# Listing Web Application Firewall Policy Protection Capabilities Filtering Tags

View a list of tags used to filter the list of web application firewall policy protection capabilities contained in a compartment.

- [Console](https://docs.oracle.com/en-us/iaas/Content/WAF/Protections/list_protection-capability_group-tags.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/WAF/Protections/list_protection-capability_group-tags.htm#)

- Follow the steps to add a request protection rule as described in[Adding a Protection Rule](https://docs.oracle.com/en-us/iaas/Content/WAF/Protections/create_request_control.htm#top).
The Add protection rule panel opens.
- Find the Protection capabilities section.
- From the Actions menu , select Choose protection capabilities .
The Choose protection capabilities panel opens.
- Under Search and Filter , select Tags recommended .
The Filter by Tags list opens, displaying all the tags that are available for filtering the list of protection rules.
