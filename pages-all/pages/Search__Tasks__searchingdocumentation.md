# Searching Documentation

You can use Search to find documentation related to various Oracle Cloud Infrastructure services.
Search supports the following tasks for finding documentation:
- [Performing a Free Text Search](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-To_perform_a_free_text_search.htm)
- [Reusing Recent Search Terms](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-To_reuse_recent_search_terms.htm)
- [Filtering Documentation Search Results](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/searchingdocumentation_topic-Filtering_Results.htm)
- [Clearing Documentation Search Filters](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/searchingdocumentation_topic-Clearing_Filters.htm)
