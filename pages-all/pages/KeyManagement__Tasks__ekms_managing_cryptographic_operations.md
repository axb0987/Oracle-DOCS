# Using Key References

Use key references for cryptographic operations with Thales.

In External KMS all cryptographic operations such as encrypt, decrypt and the generation of data encryption keys (DEKs)are forwarded to the third-party external key manager for processing.
Following are the topics related to performing cryptographic operations in External KMS:
- [Encrypting Data](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/ekms_create_key_references.htm)
- [Decrypting Data](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/ekms_rename_key_references.htm)
- [Generating Data Encryption Key (DEK)](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/ekms_moving_key_references.htm)
