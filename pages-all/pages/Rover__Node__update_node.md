# Editing a Roving Edge Infrastructure Device Node

Edit a Roving Edge Infrastructure device node in Oracle Cloud Infrastructure.

You cannot edit a Roving Edge Infrastructure device node if you have already submitted it for approval.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Rover/Node/update_node.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Rover/Node/update_node.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Rover/Node/update_node.htm#)
- 

- 

In the Oracle Cloud Console, open the navigation menu, select Hybrid , then select Nodes .
- 

If needed, change the compartment to find the resource you want.
- 

(Optional) Select a State from the list under Tag filters to limit the device nodes displayed to that state.
- 

Select the node that you want to edit. The node's Details page appears.
- 

From the Actions menu at the top of the table, select Edit . The Edit Node dialog box appears.
- 

Make your edits. See[Creating a Device Node](https://docs.oracle.com/en-us/iaas/Content/Rover/Node/create_node.htm#top)for descriptions of the settings.
- 

Select Save changes .
