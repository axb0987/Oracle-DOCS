# Viewing Default Metric Charts for Health Checks

View metric charts that use predefined service queries for health checks in Health Checks. Default metric charts are available on the Service Metrics page and under Metrics on resource details pages in the Console.

The following pages describe tasks you can perform with default metric charts for health checks:
- [Viewing Default Metric Charts for All Health Checks](https://docs.oracle.com/en-us/iaas/Content/HealthChecks/Tasks/view-chart-namespace.htm#top)
- [Viewing Default Metric Charts for a Single Health Check](https://docs.oracle.com/en-us/iaas/Content/HealthChecks/Tasks/view-chart-resource.htm#top)
