# Contacting Oracle Support

If you have issues or need Oracle to enable certain features on Roving Edge Device, open a Support Request.

Sometimes a Support Request is referred to as a Service Request or an SR .
Important  
  

When submitting a Support Request, always collect a System Diagnostics report, and include the report in your Support Request. Doing so helps streamline problem resolution. See[Collecting Roving Edge Device Diagnostic Information](https://docs.oracle.com/en-us/iaas/Content/Rover/Device_Software/diagnostic-bundles.htm#software_updates_0).

You can submit a support request in different ways. Use your preferred method.
- Use the OCI Cloud Console . See[Creating a Support Request](https://docs.oracle.com/iaas/Content/GSG/support/create-incident.htm#top).
- 

U se My Oracle Support (MOS) . Access this My Oracle Support note:[Service Request (SR) Creation (Doc ID 2969961.1](https://support.oracle.com/epmos/faces/DocContentDisplay?id=2969961.1). The note describes how to submit a Support Request in the Oracle Cloud Console and in[My Oracle Support (MOS)](https://support.oracle.com/signin).
