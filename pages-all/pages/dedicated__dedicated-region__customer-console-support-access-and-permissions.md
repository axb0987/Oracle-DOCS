# Customer Console Support Access and Permissions

This section defines the access prerequisites required before customers and support personnel can create, view, update, and manage support requests in the Customer Console and Fusion support tools.

Setup Area Guidance
Customer support group Customer administrators must create a support group in the Customer Console domain and add the support users who need to submit and manage support requests. Operators can use Customer Console access for reference when helping customers understand the support user experience, but customer administrators configure the customer tenancy.
Required Customer Console policies Grant the support group permission to read and manage tickets in the tenancy. Also allow cloud-incident-management-service to inspect domains in the tenancy so the support experience can validate identity-domain information.
Fusion support access Operator administrators must grant support representatives the required Fusion support role and data access before they use Fusion support functions. Use the existing Fusion user-management workflow to add a new support representative, assign roles to an existing user, copy roles from another support representative, and configure data access.
Role assignment authority Only users with the required Fusion administration roles, such as IT Security Administrator and Application Implementation Consultant, can assign these support roles to other users.
My Oracle Cloud Support access During onboarding, the Cloud Administrator receives the Subscription ID and Account Name, helps Dedicated Region operators access My Oracle Cloud Support, and approves access requests. If the Subscription ID is needed later, view it in the Customer Console under Billing &amp; Cost Management, then Subscriptions.
