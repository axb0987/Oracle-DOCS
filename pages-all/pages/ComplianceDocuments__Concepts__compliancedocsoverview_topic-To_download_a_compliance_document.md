# Downloading a Compliance Document

You can download a compliance document to access it offline.
- On the Compliance Documents list page, find the document you want to download. If you need help finding the list page, see[Listing All Compliance Documents](https://docs.oracle.com/en-us/iaas/Content/ComplianceDocuments/Concepts/compliancedocsoverview_topic-To_view_a_list_of_all_compliance_documents.htm#viewdocumentslist).
- Select the Actions menu (three dots) beside the document, and then select Download .
- Review the terms of use.
- Select the I have reviewed and accept these Terms and Conditions checkbox, and then select Download File .
Note  
  
For a PDF file, use PDF reader software (for example, Adobe Acrobat Reader) to view the file instead of viewing the file in the browser. If needed, when you open the PDF, on the Oracle Confidential page, select I Accept .
