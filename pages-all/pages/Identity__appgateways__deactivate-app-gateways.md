# Deactivating an App Gateway

Dectivate an app gateway in IAM.

- On the App gateways list page, select the app gateway you want to work with. If you need help finding the app gateways page, see[Listing App Gateways](https://docs.oracle.com/en-us/iaas/Content/Identity/appgateways/list-app-gateways.htm).
- From the Actions menu (three dots) for the app gateway that you want to activate, and select Deactivate app gateway .
- When prompted, confirm the deactivation.
