# Viewing Default Metric Charts for Block Volume Resources

View metric charts that use predefined service queries for resources in Block Volume. Default metric charts are available on the Service Metrics page and under Metrics on resource details pages in the Console.

The following pages describe tasks you can perform with default metric charts for resources in Block Volume:
