# Attaching and Detaching a Datastore Cluster

Attach a datastore cluster to an SDDC cluster or detach a datastore cluster from an SDDC cluster.
This automatically attaches or detaches all the related block volumes for the related Compute instances.

You can view the results in the OCI Compute service.

## Using the Console

- On the SDDC list page, select the SDDC that has the datastore cluster you want to attach or detach. If you need help finding the SDDC, see[Listing VMware Solution SDDCs](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/sddc-list.htm).
- On the SDDC details page, select Datastore Clusters. .
