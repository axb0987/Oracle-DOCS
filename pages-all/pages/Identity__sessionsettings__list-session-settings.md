# Listing Session Settings

Identity domain session settings in IAM include setting the session duration; the URLs for sign-in, logout, errors, and social callback; the authentication flow for accessing an identity domain, such as keeping the user signed in; and CORS settings.

- On the Domains list page, select the domain you want to use. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/sessionsettings/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the Settings tab, and then go to the Sessions settings section on the tab.
