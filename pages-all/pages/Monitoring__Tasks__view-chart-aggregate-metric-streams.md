# Aggregating Metric Streams in a Default Metric Chart

Aggregate metric streams in default metric charts on the Service Metrics page in the Console.

Metric streams can't be aggregated for default metric charts on resource details pages. To aggregate metric streams from a resource details page,[open the related query](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/view-chart-explore.htm)in the Metrics Explorer page and then[aggregate metric streams](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/query-metric-grouping.htm).

- [Open](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/view-chart-namespace.htm)the Service Metrics page.
- Select Aggregate metric streams (at the top of the page).
Each metric chart on the page updates to aggregate all metric streams.

For query troubleshooting, see[Troubleshooting Queries](https://docs.oracle.com/iaas/Content/Monitoring/troubleshooting-queries.htm)
