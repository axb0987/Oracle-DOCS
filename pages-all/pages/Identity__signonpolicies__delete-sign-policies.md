# Deleting a Sign-On Policy

Delete a sign-on policy that you no longer need from an identity domain in IAM.

- On the Sign-on policies list page, select the sign-on policy that you want to delete. If you need help finding the list page, see[Listing Sign-On Policies](https://docs.oracle.com/en-us/iaas/Content/Identity/signonpolicies/list-signon-policy.htm).

Note  
  
Before deleting a sign-on policy, remove groups, users, identity providers, and network perimeters from the policy.
- In the details page, select Delete sign-on policy from the Actions menu.
