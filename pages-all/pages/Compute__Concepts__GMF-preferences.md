# GPU Memory Fabric

GPU memory fabric is the infrastructure that enables communication between GPUs.

You can set GPU memory fabric preferences to determine firmware version and fabric recycle level:
- [GPU Memory Fabric Firmware Pinning](https://docs.oracle.com/en-us/iaas/Content/Compute/Concepts/gpu-memory-fabric-pinning.htm#top)
- [GPU Memory Fabric Recycle Level](https://docs.oracle.com/en-us/iaas/Content/Compute/Concepts/GMF-fabric-recycle-level.htm#GMF-fabric-recycle-level)

GPU memory fabric moves through a lifecycle with distinct states. You can view a memory fabric's current state using the[GetComputeGpuMemoryFabric](https://docs.oracle.com/iaas/api/#/en/iaas/latest/ComputeGpuMemoryFabric/GetComputeGpuMemoryFabric)API.
- [GPU Memory Fabric States](https://docs.oracle.com/en-us/iaas/Content/Compute/Concepts/GMF-lifecycle-states.htm#gpu-memory-fabric-states)
