# Listing Identity Provider Policies

List identity provider policies for IAM.

- On the Domains list page, select the name of the identity domain that you want to work in. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/idppolicies/../domains/to-view-identity-domains.htm).
- Perform one of the following actions depending on the options that you see:
- On the Federation tab, scroll to view the Identity provider policies .
- Under Security , select IdP policies .
