# Getting Variables for a Stack

Download the variable values used by a stack in Resource Manager as a JSON file (key-value pairs). The key-value pair format depends on the variable type. The downloaded file excludes reserved keywords, such as`tenancy`,`region`, and`compartment_ocid`.

This task can be performed in the Console only.

- On the Stacks list page, find the stack that you want to work with. If you need help finding the list page or the stack, see[Listing Stacks](https://docs.oracle.com/en-us/iaas/Content/ResourceManager/Tasks/../Tasks/list-stacks.htm).
- Select Variables .
