# Listing Groups

List groups in an identity domain in IAM

- On the Domains list page, select the domain for which you want to list groups. If you need help finding the list page, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/groups/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the User management tab, and then go to the Groups section on the tab.
- o Under Identity domain on the left side of the page, select Groups .
