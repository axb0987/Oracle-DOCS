# Terminating the VMware Solution Management Appliance

Terminate the VMware Solution Management Appliance.
Termination of the Management Appliance doesn't affect the main functionality of the SDDC. However, the operations are no longer available in the Management Appliance.

- On the Software-Defined Data Centers list page, select the SDDC that you want to work with. If you need help finding the list page or the SDDC, see[Listing SDDCs](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/../Tasks/sddc-list.htm).
- Select Management appliance .
The details page of the Management Appliance opens
