# Clearing All Keep Me Signed-In Sessions for a User

If Keep me signed-in has been set for an OCI IAM identity domain, you can delete the Keep me signed-in sessions for a user.

Keep me signed in must be enabled and the user must have active Keep me signed-in sessions.

- On the Domains list page, select the domain in which you want to make changes. If you need help finding the list page for the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/users/../domains/to-view-identity-domains.htm).
- Select the User management tab, and then go to the Users section of the tab.
- Select a person's username to see their details.
- Select Actions in the upper right and then select More actions .
- Select Clear all signed-in sessions .
