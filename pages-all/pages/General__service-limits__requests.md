# Working with Limit Increase Requests

List and get existing limit increase requests for the tenancy, create limit increase requests, withdraw items from limit increase requests, and withdraw limit increase requests.

For Multicloud limit increase requests, see[Requesting a Limit Increase for Multicloud](https://docs.oracle.com/iaas/Content/multicloud/limits-increase.htm).

You can perform the following tasks with limit increase requests:
- [Listing Limit Increase Requests](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/list-requests.htm)
- [Getting Details for a Limit Increase Request](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/get-request.htm)
- [Creating a Limit Increase Request](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/create-request.htm)
- [Adding a Comment to a Limit Increase Request](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/comment-request.htm)
- [Updating a Limit Increase Request](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/update-request.htm)
- [Withdrawing an Item from a Limit Increase Request](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/withdraw-item-request.htm)
- [Withdrawing a Limit Increase Request](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/withdraw-request.htm)
- [Deleting a Limit Increase Request](https://docs.oracle.com/en-us/iaas/Content/General/service-limits/delete-request.htm)
