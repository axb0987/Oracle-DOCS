# Editing an Object Storage Bucket Log

Update a read access events and write access events log for a bucket.

## Using the Console

- On the Buckets list page, select the Object Storage bucket that you want to work with. If you need help finding the list page or the bucket, see[Listing Buckets](https://docs.oracle.com/iaas/Content/Object/Tasks/managingbuckets_topic-To_get_a_list_of_buckets_concept.htm).
- On the bucket's details page, select Monitoring and find the Logs section.
All logs are displayed in a table.
- In the Logs section, select the link under Log name .
You're taken to the Logging service. The log's details page opens.
- Select Edit .
- Edit any of the following settings:

- Log name : Change the name of the log.
- Log retention : Select a different log retention period from the list.
