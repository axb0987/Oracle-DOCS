# Resolving Out of Host Capacity error

Capacity is dynamic and depends on the total pool size (number of hypervisors, and the available OCPUS and memory within the hypervisors) for a specific shape, in a specific Region, Availability Domain, or Fault Domain.

If you create a VM and receive an`Out of host Capacity`error, try the following:
- Change the shape.
- Change the fault domain.
- Change the Availability domain.
