# Working with Identity Domains

Manage identity domain features and settings.

Manage the following identity domain-level features and settings:
- [Managing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../domains/overview.htm): Create identity domains and manage resources within them.
- [Managing Domain Settings](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../defaultsettings/manage-default-settings.htm): Manage domain level settings.
- [Managing Session Settings](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../sessionsettings/overview.htm): Manage session-level settings.
- [Customizing Notifications](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../notifications/customizing-notifications.htm): Customize the email notifications sent by an identity domain.
- [Customizing the Interface](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../brand/brand_customizing-the-interface.htm): Use your company branding.
- [Create a Hosted Sign In Page](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../hostedsignin/what-is-hosted-sign-page.htm): Customize the look and feel of the identity domain sign-in experience by using style classes, custom HTML, and translation support.
- [Managing Users](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../users/about-managing-users.htm): Manage user accounts.
- [Managing Groups](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../groups/managinggroups.htm): Use groups to manage user access to applications and resources.
- [Managing Dynamic Groups](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../dynamicgroups/managingdynamicgroups.htm): Use dynamic groups to group compute instances and other resources and create policies for them.
- [Managing Applications](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../applications/overview.htm): Manage your cloud, Oracle, custom, and enterprise applications.
- [Integrating Custom Applications with IAM](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../scim/overview.htm): Use SCIM to integrate custom applications.
- [Creating Self-Registration Profiles](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../selfregistrationprofiles/overview.htm): Use self-registration profiles to allow uses to create their own accounts.
- [Transferring Data](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../datatransfer/overview.htm): Import and export users, groups, Oracle application roles.
- [Downloading SDKs and Applications](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../sdkapplications/overview.htm): Download SDKs, the EBS Asserter, the Secure Form Fill Client, the Linux PAM, the Provisioning Bridge Client, App Gateway, RADIUS Proxy, or the Device Fingerprint Utility from the identity domains console.
- [Managing Jobs](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../jobs/understand_jobs.htm): View jobs and job details, and export job errors to help you resolve them.
- [Running Reports](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../reports/running-reports.htm): Run operational or historical reports that capture data about users and applications.
- [Customizing Schemas](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../schemas/overview.htm): Add, edit, or remove custom schema attributes and change user permissions for out-of-the-box schema attributes.
- [Configuring OAuth Settings](https://docs.oracle.com/en-us/iaas/Content/Identity/resources/../oauth/oauth-settings.htm)
