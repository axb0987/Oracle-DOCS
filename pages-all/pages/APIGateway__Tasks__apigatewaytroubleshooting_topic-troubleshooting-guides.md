# Troubleshooting Guides for API Gateway

Use troubleshooting guides to diagnose and resolve issues when using the API Gateway service.

Each API Gateway troubleshooting guide provides in-depth information about a specific API Gateway issue, including symptoms, possible causes, and likely resolutions. The API Gateway troubleshooting guides are organized in the following broad categories:
- [Troubleshooting Guides for Creating API Gateways](https://docs.oracle.com/en-us/iaas/Content/APIGateway/Tasks/apigatewaytroubleshooting_topic-troubleshooting-guides_creating-gateways.htm)
- [Troubleshooting Guides for Creating API Deployments](https://docs.oracle.com/en-us/iaas/Content/APIGateway/Tasks/apigatewaytroubleshooting_topic-troubleshooting-guides_creating-deployments.htm)
- [Troubleshooting Guides for Calling APIs](https://docs.oracle.com/en-us/iaas/Content/APIGateway/Tasks/apigatewaytroubleshooting_topic-troubleshooting-guides_calling-apis.htm)
- [Troubleshooting Guides for API Gateway Issues](https://docs.oracle.com/en-us/iaas/Content/APIGateway/Tasks/apigatewaytroubleshooting_topic-troubleshooting-guides_gateway-issues.htm)
