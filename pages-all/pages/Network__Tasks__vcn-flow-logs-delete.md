- On the Flow log configurations list page, find the flow log that you want to delete. If you need help finding the list page or the flow log, see[Listing and Viewing Flow Logs](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/vcn-flow-logs-view.htm#vcn-flow-logs-view).
- From the the Actions menu (three dots) for the flow log you want to delete, select Delete .
- When prompted, confirm the deletion.
