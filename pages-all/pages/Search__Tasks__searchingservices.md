# Searching Services

You can use Search to find pages in the Console related to Oracle Cloud Infrastructure services.
Search supports the following tasks for finding service pages:
- [Performing a Free Text Search](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-To_perform_a_free_text_search.htm)
- [Reusing Recent Search Terms](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-To_reuse_recent_search_terms.htm)
- [Filtering Service Search Results](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/searchingservices_topic-Filtering_Results.htm)
- [Clearing Service Search Filters](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/searchingservices_topic-Clearing_Filters.htm)
