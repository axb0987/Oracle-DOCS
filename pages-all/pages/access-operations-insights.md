# Access Ops Insights

There are two ways to access the Ops Insights Console: Through the Oracle Cloud Infrastructure Console or from the Oracle Database Service details page in Oracle Cloud Infrastructure.
- [Oracle Cloud Infrastructure Console](https://docs.oracle.com/iaas/operations-insights/doc/access-operations-insights.html#GUID-3091F883-3F6E-4FCB-B175-67B1ACFCA280__SECTION_J4M_1Y1_3NB)
- [Database Service Details](https://docs.oracle.com/iaas/operations-insights/doc/access-operations-insights.html#GUID-3091F883-3F6E-4FCB-B175-67B1ACFCA280__SECTION_RRV_1Y1_3NB)

Oracle Cloud Infrastructure Console

To access Ops Insights, you can first sign in to the Oracle Cloud Infrastructure Console, and then access Ops Insights via the Oracle Cloud Infrastructure Console main menu.

Open the navigation menu, click Observability &amp; Management . Under Ops Insights , click Overview .

Database Service Details

For a database managed within OCI, you can access Ops Insights directly from the database's details page. These options vary depending on whether or not a database has been enabled for Ops Insights.
- Database is already enabled

If Ops Insights has been enabled for a database, Disable and View links appear. Click Disable to disable Ops Insights for the database directly without accessing the Console. Click View to access the Ops Insights Overview page.
- Database is not enabled

If Ops Insights is not currently enabled for the database, an Enable link appears, which allows you to enable Ops Insights for the database without having to access the Ops Insights Overview page.
