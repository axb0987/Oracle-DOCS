# Viewing and Updating the Query for a Default Metric Chart

Open the query for a default metric chart in the Metrics Explorer page. When you open the query on this page, you can update the query, and immediately see the effects of the update on the metric chart.

Default metric charts are available on the Service Metrics page and resource details pages in the Console.

For information about directly editing MQL expressions or changing queries by using the CLI or API, see[Editing the MQL Expression for a Query](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/query-metric-mql.htm).

- View default metric charts in one of the following ways:
- [Open](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/view-chart-namespace.htm)the Service Metrics page.
- [Go to the Metrics area on the details page for a resource.
- In the chart, select Options and select View query in Metrics Explorer .

For information about queries on the Metrics Explorer page, see[Creating a Basic Query](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/metrics-explorer-basic-query.htm).

For query troubleshooting, see[Troubleshooting Queries](https://docs.oracle.com/iaas/Content/Monitoring/troubleshooting-queries.htm)
