# Switching Table and Chart Views for a Default Metric Chart

View a default metric chart as a table, or switch back to the graph (chart) view. Default metric charts are available on the Service Metrics page and resource details pages in the Console.

To switch chart views from the Metrics Explorer page, see[Switching Table and Graph Views for a Custom Metric Chart](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/metrics-explorer-toggle-view.htm).

- View default metric charts in one of the following ways:
- [Open](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/view-chart-namespace.htm)the Service Metrics page.
- [Go to the Metrics area on the details page for a resource.
- Select Options and then select Table view .
The metric data is now presented as a table. Example excerpt:

Timestamp Percent

Oct 1, 2022, 01:30:00 UTC 85.689932345683178
Oct 1, 2022, 01:31:00 UTC 79.925088231917334
- To switch back to a chart view, select Options and then select Chart view .
