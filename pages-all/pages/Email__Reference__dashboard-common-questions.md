# Common Deliverability Questions

Learn about the most common deliverability related queries and the Key Performance Indicators (KPIs) that can be used to solve them.

The following table lists some most common email deliverability questions and how to answer them with the dashboard.

Question Key Performance Indicator (KPI) Calculation
How many emails were sent to OCI Email Delivery? Accepted Count of messages accepted
What is my hard bounce rate? Hard Bounces Hard bounce rate = count of hard bounces / count of messages accepted
What is my soft bounce rate? Soft Bounces Soft bounce rate = count of soft bounces / count of messages accepted
How many recipients are registering spam complaints? Complaints Complaint rate = count of recipient spam complaints / count of messages accepted
What percentage of my emails are being blocked? Emails on blocklists Block rate = soft bounces blocked for content / count of messages accepted
What percentage of mail sent to OCI Email Delivery was relayed to a recipient's mailbox provider? Relayed Relayed rate = count of relayed emails / count of messages accepted
What is the quality of my subscriber list and list hygiene process? Suppressed Suppressed rate = count of suppressed recipients / count of messages accepted
How is my bounce rate trending over time? This is best seen in the[Metrics Explorer](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/metrics-guide.htm)or[Logging Search](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/log-guide.htm)areas of the OCI web console.
When am I sending emails? This is best seen in the[Metrics Explorer](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/metrics-guide.htm)or[Logging Search](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/log-guide.htm)
