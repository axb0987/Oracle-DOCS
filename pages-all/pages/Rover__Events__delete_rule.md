# Deleting an Events Rule for a Roving Edge Infrastructure Device

Describes how to delete an events rule from your Roving Edge Infrastructure device.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Rover/Events/delete_rule.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Rover/Events/delete_rule.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Rover/Events/delete_rule.htm#)
- 

- Open the navigation menu and select Events &gt; Rules . The Rules page appears. All events rules are listed in tabular form.
- Select the events rule that you want to delete. The events rule's Details dialog box appears.
- Select Delete Rule .
- Confirm the deletion when prompted.

The list of events rules reappears without the rule you deleted.
