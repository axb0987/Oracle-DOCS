# Getting a VMware Solution SDDC VLAN's Details

View details for a VLAN associated with an SDDC in VMware Solution, such as name, compartment, and CIDR block.

- [Console](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/vlan-get.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/vlan-get.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/vlan-get.htm#)
- 

- On the Virtual Cloud Networks list page, select the VCN that contains the VLANs that you want to work with. If you need help finding the list page or the VCN, see[Listing VCNs](https://docs.oracle.com/iaas/Content/Network/Tasks/list-vcn.htm).
- Select VLANs .
- Select the VLAN that you want to work with.
The details page contains information about the VLAN, both general information and links to its resources. Some items in the page are read-only, and other items let you edit and update the VLAN's configuration. See[Editing a VMware Solution SDDC VLAN](https://docs.oracle.com/en-us/iaas/Content/VMware/Tasks/vlan-update.htm).
