# Oracle Autonomous AI Database

Autonomous AI Database provides an easy-to-use, fully autonomous Oracle AI Database that scales elastically, delivers fast query performance, and requires no database administration. An Autonomous AI Database on dedicated infrastructure provides a private database cloud in the public cloud. You get a completely dedicated compute, storage, network, and database service, providing the highest security, isolation, and governance levels.

For operational control and isolation, an Autonomous AI Database on dedicated infrastructure offers different[deployment possibilities](https://docs.oracle.com/en/cloud/paas/autonomous-database/dedicated/adbaa/index.html#GUID-681A2402-18D9-4412-82CE-7646EFD71DB6), listed below:
- Autonomous AI Database on Dedicated Exadata Infrastructure: Public cloud regions on Oracle Cloud Infrastructure.
- Dedicated Regions in Cloud@Customer: An entire OCI region as it exists in Oracle’s public cloud, but deployed inside customer's data center.
- Autonomous AI Database on Exadata Cloud@Customer: Customer private data centers on Exadata Cloud@Customer.
- [Autonomous AI Database on Oracle Database@AWS](https://docs.oracle.com/en/cloud/paas/autonomous-database/dedicated/gddei): Autonomous AI Database on Dedicated Exadata Infrastructure deployed in AWS cloud regions.

## Get Started

Use the following resources to get started with dedicated Autonomous AI Database, or jump straight to the[documentation](https://www.oracle.com/pls/topic/lookup?ctx=en/cloud/paas/autonomous-database/dedicated&id=ADBAA).

### [Autonomous AI Database on Dedicated Exadata Infrastructure](https://docs.oracle.com/en/cloud/paas/autonomous-database/dedicated/adbd-index.html)

A private cloud in public cloud choice. A completely dedicated compute, storage, network and database service for only a single tenant, providing for the highest levels of security isolation and governance.

### [Autonomous AI Database on Exadata Cloud@Customer](https://docs.oracle.com/en/cloud/paas/autonomous-database/dedicated/adbcc-index.html)

Autonomous AI Database running on on Exadata Database Machine system in your data center, together with the networking configuration that connects it to Oracle Cloud.
