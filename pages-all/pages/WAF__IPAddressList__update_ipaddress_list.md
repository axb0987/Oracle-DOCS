# Editing an Edge Policy IP Address List

Edit an IP address list for an edge policy in Web Application Firewall.

- [Console](https://docs.oracle.com/en-us/iaas/Content/WAF/IPAddressList/update_ipaddress_list.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/WAF/IPAddressList/update_ipaddress_list.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/WAF/IPAddressList/update_ipaddress_list.htm#)
- 

- Open the navigation menu and select Identity &amp; Security . Under Web Application Firewall , select Edge Policy Resources .
The Policies list opens. All edge policies are listed in a table.
- Under OCI Edge policy resources , select IP address lists .
- Select the compartment that contains the IP address list.
- Select the name of the IP address list that you want to edit.
- On the IP address lists details page, select Edit .
- In the Edit IP address list dialog box, edit the IP address list. For a description of the IP address list settings, see[Creating an Edge Policy IP Address List](https://docs.oracle.com/en-us/iaas/Content/WAF/IPAddressList/create_ipaddress_list.htm#top).
- Select Save changes .
