# Activating a Self-Registration Profile

Activate a newly created profile in IAM so that you can use it.

- On the Self registration list page, select the checkbox of the profile you want to activate. If you need help finding the list page, see[Listing Self-Registration Profiles](https://docs.oracle.com/en-us/iaas/Content/Identity/selfregistrationprofiles/list-self-registration-profiles.htm).
- From the Actions menu (three dots) for the profile you want to activate, select Activate .
