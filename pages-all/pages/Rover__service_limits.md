# Service Limits for Roving Edge Infrastructure

Review the service limits for the Roving Edge Infrastructure service and its various devices.

The Roving Edge Infrastructure service has the following limits:
- 

Roving Edge Infrastructure devices : You can request either a single Roving Edge Infrastructure device (either a Roving Edge Device (RED) or a Roving Edge Ultra (Ultra).
- 

Object size : You can request files up to 5 TB to be provisioned onto a Roving Edge Device. Files larger than 5 TB are skipped in the import process.
