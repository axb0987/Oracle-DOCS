# Listing User Attributes

List user attributes for an identity domain.

- On the Domains list page, select the domain for which you want to list user attributes. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/schemas/../domains/to-view-identity-domains.htm).
- On the details page, perform one of the following actions depending on the option that you see:

- Select the Schema management tab.
- On the left side of the page, select Settings then select Schema management .
- Select User attributes .
The User attributes list page opens. All attributes in the selected compartment are displayed in a table

## Filtering List Results

Use Filter attribute to limit the attributes in the list. Choose from:
- All: All user attributes are listed.
- Base: The OCI user attributes are listed. Occasionally, you may want to edit one or more of the base user attributes. If the attribute cannot be edited, the fields are not available to edit.
- Custom: These are the existing custom user attributes.

## Actions

In the list table, select the name of a job to open its details page, where you can view its status and perform other tasks.

To perform an action on a job directly from the list table, select any of the following options from the Actions menu (three dots) in the row for that job:
- Create a custom attribute :[Create a custom user attribute](https://docs.oracle.com/en-us/iaas/Content/Identity/schemas/add-custom-schema-attributes.htm).
- Edit a user attribute :[Edit a custom user attribute](https://docs.oracle.com/en-us/iaas/Content/Identity/schemas/edit-custom-schema-attributes.htm).
- Edit a user's permission :[Edit a user's permissions for a base schema attribute](https://docs.oracle.com/en-us/iaas/Content/Identity/schemas/change-user-permissions-base-schema-attribute.htm).
- Delete a custom attribute :[Delete a custom user attribute](https://docs.oracle.com/en-us/iaas/Content/Identity/schemas/remove-custom-schema-attribute.htm).
- Open support request : Open the Support Request panel, in which you can access support options. See[Support Requests](https://docs.oracle.com/iaas/Content/GSG/Tasks/contactingsupport.htm)
