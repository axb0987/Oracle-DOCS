An image is a template of a virtual hard drive that determines the operating system and other software for an instance. When you create a product license, you're prompted to select an image. A list of all images available is provided for you to select from. After you create the product license, you can add, update, and remove images associated with the product license.

You can perform the following image tasks:

[Add an image to a product license](https://docs.oracle.com/en-us/iaas/Content/General/LicenseManager/Tasks/add-images.htm).

[Remove an image from a product license](https://docs.oracle.com/en-us/iaas/Content/General/LicenseManager/Tasks/remove-images.htm)
