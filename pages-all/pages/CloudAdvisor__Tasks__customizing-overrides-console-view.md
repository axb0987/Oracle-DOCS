# Viewing Customizations and Overrides

View Cloud Advisor recommendation customizations and overrides.

- Open the navigation menu and select Governance &amp; Administration . Under Cloud Advisor, select Settings .
- Select Global recommendations .
- From the Search and Filter box above the list table, use the Category filter to narrow the list.
- Next to Applied filters , optionally remove the Customizable filter. (You can always add it back using the Search and Filter box.)
- Select Overrides .
- Select an override to view its details.
