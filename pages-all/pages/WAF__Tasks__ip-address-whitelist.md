# IP Address Allowlist for Edge Policies

Describes how IP address allowlists are used within an edge policy.

You can use the IP Address Whitelist tab in Access Control to manage allowlists containing trusted IP addresses that bypass all rules and challenges. See[Access Control for Edge Policies](https://docs.oracle.com/en-us/iaas/Content/WAF/Tasks/wafaccesscontrol.htm#Access_Control)
