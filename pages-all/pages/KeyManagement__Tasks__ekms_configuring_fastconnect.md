# Setting up FastConnect for Colocation

Learn about configuring FastConnect for an EKMS deployment.

Oracle Cloud Infrastructure FastConnect provides an easy way to create a dedicated, private connection between your on-premises data center and Oracle Cloud Infrastructure. FastConnect provides higher-bandwidth options, and a more reliable and consistent networking experience compared to internet-based connections. For more information, see[Fast Connect](https://docs.oracle.com/iaas/Content/Network/Concepts/fastconnectoverview.htm#FastConnect_Overview).

We recommend the FastConnect with Colocation configuration if your third-party key management is collocated in the same data center and also has the OCI cloud services provisioned. For more information, see[FastConnect: Colocation with Oracle](https://docs.oracle.com/iaas/Content/Network/Concepts/fastconnectcolocate.htm).

To use FastConnect by connecting to a third-party network provider of your choice, see[FastConnect: With a Third-Party Provider](https://docs.oracle.com/iaas/Content/Network/Concepts/fastconnectthirdpartyprovider.htm).

For a summary of different cloud connectivity models, see[Use cases for OCI FastConnect](https://www.oracle.com/cloud/networking/fastconnect/)
