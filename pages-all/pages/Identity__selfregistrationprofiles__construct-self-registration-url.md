# Constructing a Self-Registration URL

After creating a self-registration profile in IAM, you must create a self-registration URL.

- On the Self registration list page, select the checkbox of the profile you want to construct a URL. If you need help finding the list page, see[Listing Self-Registration Profiles](https://docs.oracle.com/en-us/iaas/Content/Identity/selfregistrationprofiles/list-self-registration-profiles.htm).
- From the Actions menu (three dots) for the profile you want to update, and select Edit to edit the profile.
