# About Work Requests

You can view Oracle Cloud Infrastructure Work Requests on Autonomous AI Database.

A work request is an activity log that enables you to track each step in an operation’s progress. Each work request has an Oracle Cloud Identifier (OCID) that allows you to interact with it programmatically.

Autonomous AI Database work requests are created for many operations, including the following operations:
- 

Creating or terminating an Autonomous AI Database instance
- 

Starting or stopping an Autonomous AI Database instance
- 

Restoring an Autonomous AI Database instance
- 

Cloning an Autonomous AI Database instance
- 

Scaling database storage or CPU
- 

Updating the database license type
- 

Updating a database's network access control list (ACL)

To view work requests for an Autonomous AI Database instance:

On the Oracle Cloud Infrastructure Console, on the Autonomous AI Database details page, select the Work requests tab.

[Description of the illustration atpc_work_request_console.png](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/img_text/atpc_work_request_console.html)

Click the work request link under the Operation column to see more details for a work request.

[Description of the illustration atpc_work_request_details.png](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/img_text/atpc_work_request_details.html)

See[Work Requests Integration](https://docs.oracle.com/iaas/Content/Database/Concepts/databaseoverview.htm#WorkRequestsIntegration)for more information.
