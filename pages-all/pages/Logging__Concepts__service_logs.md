# Service Logs

Oracle Cloud Infrastructure services emit service logs. Each of these supported services has a Logs resource you can use to enable or disable logging for that service.

## Supported Services

You can enable service logs for the Oracle Cloud Infrastructure services listed in the[Service Log Reference](https://docs.oracle.com/en-us/iaas/Content/Logging/Concepts/../Reference/service_log_reference.htm)
