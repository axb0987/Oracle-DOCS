## Application Dependency Management (ADM)

Application Dependency Management is a developer service in Oracle Cloud Infrastructure that detects security vulnerabilities in application dependencies. ADM relies on scores provided by the Common Vulnerability Scoring System: an open framework for communicating the characteristics and severity of software vulnerabilities
