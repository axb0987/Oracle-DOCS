# Sorting Service Search Results

Sort results from a search to better help you find the pages you need in the Console.

## Using the Console

These steps assume that you already performed a free text search and selected the Services category of results according to the instructions in[Performing a Free Text Search](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/queryingresources_topic-To_perform_a_free_text_search.htm).

- On either the Service search results page or the Services page, in the list of results, select the column header of the column that you want to use to sort results:
- To sort results by the page display name, select Display name .
- To sort results by the service group, select Service group .
The results on the page are now shown in reverse alphabetical order by service group name.
