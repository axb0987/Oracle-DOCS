## Operations Insights (OPSI)

Use the Operations Insights API to perform data extraction operations to obtain database resource utilization, performance statistics, and reference information.

For more information, see[About Oracle Cloud Infrastructure Operations Insights](https://docs.oracle.com/iaas/operations-insights/doc/operations-insights.html).
