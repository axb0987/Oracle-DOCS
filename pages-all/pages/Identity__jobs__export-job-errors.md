# Exporting Job Errors

Download a comma-separated value (CSV) file of job errors for an identity domain in IAM to a local machine so that you can review and correct them.

- On the Jobs list page, select the job that you want to work with. If you need help finding the list page or the job, see[Listing Jobs](https://docs.oracle.com/en-us/iaas/Content/Identity/jobs/list-jobs.htm).
- In the Job details URL column, select Go to details .
- Select Download exported file .
