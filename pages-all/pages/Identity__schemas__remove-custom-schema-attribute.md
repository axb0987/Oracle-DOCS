# Deleting a Custom Attribute

Remove a custom attribute for the user schema in IAM when you no longer need it.

Note  
  
If data exists for the attribute, you can't remove it.

- On the User attributes list page, in the Filter attribute field, select Custom . If you need help finding the list page or the recipe, see[Listing User Attributes](https://docs.oracle.com/en-us/iaas/Content/Identity/schemas/listing-schema.htm).
- From the Actions menu (three dots) for the custom attribute that you want to delete, select Remove .
