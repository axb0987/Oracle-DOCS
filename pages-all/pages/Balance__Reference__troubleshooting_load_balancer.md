# Troubleshooting Load Balancer

Use troubleshooting information to identify and address common issues that can occur while working with the Load Balancer service.

Enable Oracle Cloud Infrastructure load balancing access and error logs to troubleshoot common errors. See[Logging](https://docs.oracle.com/en-us/iaas/Content/Balance/Reference/../Tasks/managingloadbalancer_topic-Logging.htm)for more information.

Troubleshooting topics are organized by the following categories:
- [Common Load Balancer Errors](https://docs.oracle.com/en-us/iaas/Content/Balance/Reference/../Troubleshooting/common_load_balancer_errors.htm)
- [HTTP Issues](https://docs.oracle.com/en-us/iaas/Content/Balance/Reference/troubleshooting_http.htm)
- [SSL Issues](https://docs.oracle.com/en-us/iaas/Content/Balance/Reference/troubleshooting_ssl.htm)
- [Backend Server Issues](https://docs.oracle.com/en-us/iaas/Content/Balance/Reference/troubleshooting_backend.htm)
- [Health Issues](https://docs.oracle.com/en-us/iaas/Content/Balance/Reference/troubleshooting_health.htm)
- [Response Match Failures](https://docs.oracle.com/en-us/iaas/Content/Balance/Reference/response_match_errors.htm)
