# Oracle Alloy Branding

Oracle Alloy supports private-label branding across the end-customer experience. Operators can tailor logos, themes, commercial terms, customer communications, and recipient targeting. These controls present the service as the operator's cloud offering rather than as a pass-through of Oracle public cloud.

## Branding and Content Controls

Branding controls are available from Custom Branding on the Operator Console home page and from Branding &amp; Content in the navigation menu. The workflow is preview driven. Review changes before publication, and then publish the changes to the customer-facing experience when they are ready.

## Names, Images, and Theme Colors

You can define the cloud name and company name that are used in sign-in screens, documentation, the browser tab, and other customer-facing areas.

Branding assets use the following requirements:
- 

Company logo: Use a PNG or SVG file. Use a minimum size of 34 x 34 pixels and a maximum size of 200 x 34 pixels.
- 

Browser tab icon: Use a 32 x 32 pixel ICO file, such as favicon.ico.
- 

Theme colors: Define up to seven colors by using hexadecimal or RGB values.

Preview the home and service pages before publishing theme changes.

## Notices and Footers

You can publish home page notices in the left and right banner areas on the Customer Console home page. Use these notices to deliver service updates, campaigns, or other important messages.

You can also publish Markdown-based footers for the Customer Console and documentation. The customer console footer uses separate left and right areas. The documentation footer uses one centered footer. The Powered by Oracle text on the right side of the customer console footer is fixed.
