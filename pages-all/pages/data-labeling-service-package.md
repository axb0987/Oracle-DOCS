## Data Labeling Service

Data labeling is the process of identifying properties (labels) of documents, text, and images (records), and annotating (labeling) them with those properties. Data Labeling lets you create and browse datasets, view data records (documents, text and images), and apply labels to build AI/ML models. Datasets can be exported as line-delimited JSON for use in machine learning model development.
