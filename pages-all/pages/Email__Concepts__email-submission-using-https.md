# Using HTTPS for Email Submissions

Use Hypertext Transfer Protocol Secure (HTTPS) submission to effortlessly send secure bulk marketing and transactional emails and improve the chances of getting your email delivered to the inbox.

HTTPS submissions support any standard OCI SDK authentication mechanisms. Ensure that the HTTPS submission connections are sent over an SSL connection and use any of the[standard OCI SDK authentication mechanisms](https://docs.oracle.com/iaas/Content/API/Concepts/sdk_authentication_methods.htm)(API key of an Identity user,[instance principal](https://docs.oracle.com/iaas/Content/Identity/Tasks/callingservicesfrominstances.htm), or resource principal).

To submit emails through HTTPS, use the[Email Delivery Submission API](https://docs.oracle.com/iaas/api/#/en/emaildeliverysubmission/latest/)and easily find the details about API methods and the data types used for email sending. We recommend using the Email Delivery Configuration API, as part of the main[Email Delivery API](https://docs.oracle.com/iaas/api/#/en/emaildelivery/latest/)
