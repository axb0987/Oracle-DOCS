# Security Monitoring

Use the following requirements for security monitoring.

Requirement Area Requirement Details
Door coverage Monitor all doors that lead to the security corridor and each room with CCTV. Coverage must include all doors within Oracle-controlled data center space, storage rooms, and Oracle-occupied MMRs.
Recording method Record CCTV footage on digital media. The archive must support retrieval during incident response or audit.
Retention Retain video footage for the required review period. Minimum 5 FPS and 90-day retention. Middle East builds require 180-day retention.
Archive access Make recorded footage available when required. Oracle, approved assessors, and approved vendors must be able to review archived footage upon request.
