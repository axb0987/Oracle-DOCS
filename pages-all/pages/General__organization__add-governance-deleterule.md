# Deleting a Governance Rule

Delete a governance rule from an organization.

- On the Governance rules list page, select the rule that you want to delete. If you need help finding the list page, see[Listing Governance Rules](https://docs.oracle.com/en-us/iaas/Content/General/organization/list-governancerules.htm).
- On the details page, select the Actions menu and then select Delete rule .
