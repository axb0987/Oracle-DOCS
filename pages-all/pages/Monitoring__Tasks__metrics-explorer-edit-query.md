# Editing a Query in a Custom Metric Chart

Edit a query used to generate the metric chart the Metrics Explorer page in the Console.

- [Create a basic query](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/metrics-explorer-basic-query.htm)on the Metrics Explorer page.
You can optionally use multiple queries.
- If the query isn't open, open it by selecting Edit queries .
- If more than one query is displayed, then select ( Edit query ) for the one that you want.
- Update the fields that you want.
For reference, see[Creating a Query](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/query-metric.htm).
- Select Update Chart .

For information about directly editing MQL expressions or changing queries by using the CLI or API, see[Editing the MQL Expression for a Query](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/query-metric-mql.htm)
