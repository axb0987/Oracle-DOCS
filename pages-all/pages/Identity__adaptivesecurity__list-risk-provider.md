# Listing Risk Providers

List risk providers in adaptive security.

- On the Domains list page, select the name of the identity domain that you want to work in. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/adaptivesecurity/../domains/to-view-identity-domains.htm).
- Perform one of the following actions depending on the options that you see:
- On the Security tab, scroll to view Adaptive security .
- Under Security , select Adaptive security .
