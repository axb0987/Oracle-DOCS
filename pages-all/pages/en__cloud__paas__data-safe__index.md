# Oracle Data Safe

## Get Started

Oracle Data Safe delivers essential data security services for Oracle AI Databases, both in the cloud and on-premises, all through an accessible, easy-to-use cloud-based interface that requires no installation or deployment.

Watch an introductory[video](https://cdnapisec.kaltura.com/p/2171811/embedPlaykitJs/uiconf_id/54927872?iframeembed=true&entry_id=1_qzygqqzb&config%5Bprovider%5D=%7B%22widgetId%22%3A%221_nrcakkem%22%7D&config%5Bplayback%5D=%7B%22startTime%22%3A0%7D)about Oracle Data Safe, or read the[text version](https://docs.oracle.com/iaas/data-safe/doc/introduction-oracle-data-safe-video-transcript.html).
