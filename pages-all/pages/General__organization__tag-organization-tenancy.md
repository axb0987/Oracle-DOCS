# Tagging a Tenancy

Describes how to add tagging metadata to a tenancy. You can define keys and values, and associate them with resources.

You can apply tags to a tenancy to help you organize them according to your business needs. You can apply tags when updating a tenancy. When you're signed in as the parent tenancy, you can tag only the parent tenancy. When you're signed in as the child tenancy, you can tag only the child tenancy. For more information about tagging, see[Resource Tags](https://docs.oracle.com/iaas/Content/General/Concepts/resourcetags.htm)
