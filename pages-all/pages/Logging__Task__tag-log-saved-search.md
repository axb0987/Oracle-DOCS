# Tagging a Log Saved Search

Add metadata to a log saved search, which enables you to define keys and values and associate them with resources.

You can apply tags to your log saved search to help you organize it according to your business needs. Apply tags at the time you create a log saved search, or update the log saved search with tags later. For more information about applying tags, see[Tagging Overview](https://docs.oracle.com/iaas/Content/Tagging/Concepts/taggingoverview.htm#Tagging_Overview).

The following topics describe how you can apply tagging to a log group:

[Tagging a Log Saved Search at Creation](https://docs.oracle.com/en-us/iaas/Content/Logging/Task/tag-create-log-saved-search.htm)
- 

[Tagging a Log Saved Search When Updating](https://docs.oracle.com/en-us/iaas/Content/Logging/Task/tag-update-log-saved-search.htm)
