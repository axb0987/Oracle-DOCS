# Launching Code Editor

This topic describes how to launch Code Editor.
You can start code editor by selecting the Cloud Shell/Code Editor icon in the Console header and selecting Code Editor from the drop-down menu.
Note  
  
Code Editor will not function properly if launched in a private ("incognito") browser window. :
