# Access Dashboards

You can access Management Dashboards (Dashboards) in the Oracle Cloud Infrastructure console.
- Sign in to the Oracle Cloud Infrastructure console.
- Open the navigation menu, click Observability &amp; Management , and then click Management Dashboards .

The Dashboards page is displayed, with the list of Oracle-defined dashboards along with custom dashboards, if any.
- Click the Compartment and other applied filters to select alternate options, if required. To view dashboards across all compartments in the tenancy, clear the compartment selected in the Compartment applied filter so that Compartment All is displayed. You can also use the Search and Filter field to search for dashboards or filter the dashboard list.
In the Search and Filter field, you can either type text to search for specific dashboards or click inside the field to view and use the following filters. Note that if a filter is already added and displayed as an applied filter, it's no longer listed in the Search and Filter field.
- Created by : Select a user name in the drop-down list to view the dashboards created by the user.
- Updated by : Select a user name in the drop-down list to view the dashboards updated by the user.
- Services : Select services in the drop-down list to view the dashboards that display data for those services.
- Tags : If a tag filter is added to the dashboards, select the type of tag from the Namespace menu. Then, in the Key field, specify the value or values you want the filter to match. Finally, specify whether you want to Match any value or Specify matching values .

On the Dashboards page, you can:
- Click Create dashboard to create a custom dashboard. For information, see[Create a Custom Dashboard](https://docs.oracle.com/iaas/management-dashboard/doc/create-custom-dashboard.html#GUID-C94BC101-35ED-48BB-891B-8BFF516D44CB).
- Click Import dashboards to import a dashboard. For information, see[Export and Import Dashboards](https://docs.oracle.com/iaas/management-dashboard/doc/export-import-dashboards.html#GUID-8C99E36A-2C95-4B8B-A528-1DB39E9AB0DA).
- Sort the list of dashboards by clicking the Sort ascending or Sort descending icon ( ), which is displayed when you hover the mouse over column headings.
- Click the Manage columns icon ( ) on the right to choose which columns are shown or hidden on the page.
- Click the name of a dashboard to open it.
- Click the Actions icon ( ) for a dashboard and select the available options to perform tasks such as duplicating the dashboard, moving the dashboard to another compartment, or deleting the dashboard. For Oracle-defined dashboards, only the Open and Duplicate options are enabled in the Actions menu.

On the left pane, under Dashboards :
- Click Widgets to view the list of available widgets in the widget library for supported Observability &amp; Management services. For information, see[View Widgets](https://docs.oracle.com/iaas/management-dashboard/doc/view-widgets.html#GUID-C7FEAAAB-6DBB-479A-B120-D2AAB54C9D96).
- Click Filters to view the list of available filters in the filter library for supported Observability &amp; Management services. For information, see[View Filters](https://docs.oracle.com/iaas/management-dashboard/doc/view-filters.html#GUID-84A3B2AD-2C75-447D-9200-E893CD825FF8).
