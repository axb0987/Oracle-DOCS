# Human Interaction Challenge for Edge Policies

Describes the use and management of the human interaction challenge for an edge policy.

The human interaction challenge is an advanced countermeasure that looks for natural human interactions such as mouse movements, time on site, and page scrolling to identify bots. When an edge server receives requests from a client, instead of instantly reporting with the requested content, the human interaction challenge checks various event listeners in the user's browser to determine if a human user is making the request.
