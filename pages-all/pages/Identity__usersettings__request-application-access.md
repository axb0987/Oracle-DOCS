# Requesting Application Access

Request access to applications to which you want use. If you don't see the application on the Catalog page, the administrator has not allowed the application to be requested. To make the application accessible, contact your administrator.

- Go to your My Profile console page, and select Integrated applications to request access to an application. If you need help finding the My Profile console page, see[Getting Your Profile Details](https://docs.oracle.com/en-us/iaas/Content/Identity/usersettings/get-details-my-profile.htm).
- Select the My resources tab and find Integrated applications on the page.
- Select Request access to a new application .
- In the Catalog page, select Applications .
- Select the plus (+) sign for the application to which you want access.
- In the Add Access dialog box, enter the reason for the request, and then select OK .

Two emails are sent to you.
- 

The first email verifies your request. To go to the My requests tab and verify that your request has been submitted, select the My Requests link in the email.
