# Monitor and Manage Performance

Describes the Database Dashboard card in Database Actions where you can find information about the performance of an Autonomous AI Database instance.
- 

[Monitor the Performance of Autonomous AI Database with Database Actions](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/monitor-performance-intro.html#GUID-54CCC1C6-C32E-47F4-8EB6-64CD6EDB5938)

The Database Dashboard card in Database Actions provides the Overview and Monitor tabs where you can find information about the performance of an Autonomous AI Database instance.
- 

[Monitor Autonomous AI Database with Performance Hub](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-monitor-perf-hub.html#GUID-1EA329A7-3875-477E-B656-18F191D8C4B1)

Use Performance Hub to monitor your database for a defined time period and download statistical reports. Performance Hub also lets you view real-time and historical performance data for an Autonomous AI Database instance.
- 

[Manage Concurrency and Priorities on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/manage-priorities.html#GUID-19175472-D200-445F-897A-F39801B0E953)

Concurrency and prioritization of user requests in Autonomous AI Database is determined by the database service the user is connected with, and whether compute auto scaling is enabled.
- 

[Use Fast Ingest on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-fast-ingest.html#GUID-BB7C87CA-6440-4BC9-86D8-B37F08977303)

Fast ingest optimizes the processing of high-frequency, single-row data inserts into the database from applications, such as Internet of Things (IoT) applications, to improve data insert performance.
- 

[Enable Database Management Service to Monitor and Manage Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/mdw-oci-database-management.html)You can use the Diagnostics &amp; Management features in the Database Management service for advanced monitoring and management of Autonomous AI Databases.
- 

[Perform SQL Tracing on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/application-tracing.html#GUID-25A5160B-C72A-4897-9CC9-0BE23EA7EC01)

Use SQL tracing to help you identify the source of an excessive database workload, such as a high load SQL statement in your application.
- 

[Monitor Performance with Autonomous AI Database Metrics](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-monitor-metrics.html#GUID-110919C2-840D-4D37-9C48-5D6DAA60E29A)You can monitor the health, capacity, and performance of your databases with metrics, alarms, and notifications. You can use Oracle Cloud Infrastructure Console or Monitoring APIs to view metrics.
- 

[Available Metrics: oci_autonomous_database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-monitor-metrics-list.html#GUID-C52DF6AC-EF10-437A-AEEA-6E79A173AB7F)This topic describes the metrics emitted by the Database service in the`oci_autonomous_database`namespace.
