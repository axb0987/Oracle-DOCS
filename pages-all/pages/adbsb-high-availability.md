# High Availability

You can configure and manage Autonomous Data Guard and maintain continuous availability using disaster recovery.
- 

[Use Application Continuity on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/application-continuity1.html#GUID-E7AA2543-2CF3-4A42-9440-BB238BA679AE)

Autonomous AI Database provides application continuity features for making connections to the database.
- 

[Use Standby Databases with Autonomous Data Guard for Disaster Recovery](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-data-guard.html#GUID-2AFA2C06-BBD9-496E-94B9-B3C54EC567D1)

When you add an Autonomous Data Guard standby database, Autonomous AI Database provides data protection and disaster recovery for your database.
- 

[Backup and Restore Autonomous AI Database Instances](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/backup-restore.html#GUID-9035DFB8-4702-4CEB-8281-C2A303820809)

This section describes backup and recovery tasks on Autonomous AI Database.
- 

[Use OraMTS Recovery Feature on Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/autonomous-oramts-recovery.html#GUID-65268FDC-49B8-4658-BB1E-70D53E04F4DB)

Use Oracle MTS (OraMTS) Recovery Service to resolve an in-doubt Microsoft Transaction Server transaction.
- 

[Use Backup-Based Disaster Recovery](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/backup-based-disaster-recover.html#GUID-76B1D0AF-2FCE-47FF-8BAC-9A83754065FC)

Backup-Based Disaster Recovery provides a lower-cost disaster recovery option for Autonomous AI Database (the RTO is higher with this option, as compared to using Autonomous Data Guard).
- 

[Track Table Changes with Flashback Time Travel](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/flashback-time-travel-autonomous.html#GUID-A98E1F8B-FAE4-4FFF-955D-3A0E5F8EBC4A)

Use Flashback Time Travel to view past states of database objects or to return database objects to a previous state without using point-in-time media recovery.
- 

[Use OCI Full Stack Disaster Recovery with Autonomous AI Database](https://docs.oracle.com/iaas/autonomous-database-serverless/doc/full-stack-disaster-recovery.html#GUID-939B0D49-84FB-4E61-AB00-1E17F44911D4)

You can enable the Oracle Cloud Infrastructure Full Stack Disaster Recovery on Autonomous AI Database.
