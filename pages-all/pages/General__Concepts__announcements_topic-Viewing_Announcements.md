# Viewing Announcements

View announcements. The Announcements icon displays a green dot if you have any unread announcements.

You can perform the following management tasks on announcements:
- [Viewing a List of All Announcements](https://docs.oracle.com/en-us/iaas/Content/General/Concepts/announcements_topic-To_view_a_list_of_all_announcements.htm)
- [Viewing the Details of an Announcement](https://docs.oracle.com/en-us/iaas/Content/General/Concepts/announcements_topic-To_view_the_details_of_an_announcement.htm)
- [Dismissing a Banner Announcement](https://docs.oracle.com/en-us/iaas/Content/General/Concepts/announcements_topic-To_dismiss_a_banner_announcement.htm)
- [Filtering Announcements](https://docs.oracle.com/en-us/iaas/Content/General/Concepts/announcements_topic-To_filter_a_list_of_announcements.htm)
- [Sorting Announcements](https://docs.oracle.com/en-us/iaas/Content/General/Concepts/announcements_topic-To_sort_a_list_of_announcements.htm)
- [Marking an Announcement as Read](https://docs.oracle.com/en-us/iaas/Content/General/Concepts/announcements_topic-To_mark_an_announcement_as_read.htm)
- [Viewing the History of an Announcement](https://docs.oracle.com/en-us/iaas/Content/General/Concepts/announcements_topic-To_view_the_history_of_an_announcement.htm)
