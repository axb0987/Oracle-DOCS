# Editing an Events Rule for a Roving Edge InfrastructureDevice

Describes how to edit an events rule on your Roving Edge Infrastructure device.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Rover/Events/update_rule.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Rover/Events/update_rule.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Rover/Events/update_rule.htm#)
- 

- Open the navigation menu and select Events &gt; Rules . The Rules page appears. All events rules are listed in tabular form.
- Select the events rule that you want to edit. The events rule's Details page appears.
- Select Edit Rule . The Edit Rule dialog box appears.
- Edit the events rule's settings. See[Creating an Events Rule](https://docs.oracle.com/en-us/iaas/Content/Rover/Events/create_rule.htm#top)for descriptions of each setting.
- Select Save Changes .

The Edit Rule dialog box closes. The updates you made are present in the details of the events rule.
