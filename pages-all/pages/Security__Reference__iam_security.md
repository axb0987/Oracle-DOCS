# Securing IAM

## Security Recommendations

Oracle Cloud Infrastructure Identity and Access Management (IAM) provides authentication of users, and authorization to access resources .

We recommend that you periodically monitor Audit logs to review changes to IAM users, groups, and security policies.

Use the topics in this section to secure your tenancies using security best practices.
