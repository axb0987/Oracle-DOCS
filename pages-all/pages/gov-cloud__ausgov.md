# Oracle Cloud Infrastructure for Australia Government and Defence

Review information specific to Oracle Cloud for Australian Government and Defence.

See also[Oracle Cloud for Australian Government and Defence](https://www.oracle.com/au/government/).

## Region

The region name and identifier for the Oracle Cloud for Australian Government and Defence are shown in the following table:

Region Name Region Identifier Region Location Region Key Realm Key Availability Domains
Australia Dedicated Region (Canberra) ap-dcc-canberra-1 Canberra, Australia WGA OC10 1

### Oracle's BGP ASN

This section is for network engineers who configure an edge device for[FastConnect](https://docs.oracle.com/iaas/Content/Network/Concepts/fastconnect.htm)or[Site-to-Site VPN](https://docs.oracle.com/iaas/Content/Network/Tasks/managingIPsec.htm).

Oracle's BGP autonomous system number (ASN) for the Oracle Cloud for Australian Government and Defence is 54253.

## Console Sign-in URL

To sign in to the Oracle Cloud for Australian Government and Defence, enter the following URL in a[supported browser](https://docs.oracle.com/iaas/Content/GSG/Tasks/signinginIdentityDomain.htm#supported-browsers):
- [https://oc10.cloud.oracle.com](https://oc10.cloud.oracle.com)

## SMTP Authentication and Connection Endpoints

Email Delivery only supports the AUTH PLAIN command when using SMTP authentication. If the sending application is not flexible with the AUTH command, an SMTP proxy/relay can be used. For more information about the AUTH command, see[AUTH Command and its Mechanisms](https://www.samlogic.net/articles/smtp-commands-reference-auth.htm).

## SPF Record Syntax

An SPF record is a TXT record on your sending domain that authorizes Email Delivery IP addresses to send on your behalf. SPF is required for subdomains of`oraclecloud10.com`and recommended in other cases. The SPF record syntax for the Oracle Cloud for Australian Government and Defence sending region is shown in the following table:

Realm Key SPF Record
OC10`v=spf1 include:rp.oraclecloud10.com ~all`
