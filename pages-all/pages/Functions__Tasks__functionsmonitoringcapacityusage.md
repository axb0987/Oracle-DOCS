# Monitoring Memory Usage and Availability for OCI Functions

Find out how to monitor the usage of available memory capacity by OCI Functions.

You can use OCI Functions limits and metrics to monitor:
- the overall total amount of memory that is available for concurrent execution of all functions in a region, and how much memory has been allocated for concurrent function execution (see[Monitoring Memory Usage and Availability for Concurrent Function Execution](https://docs.oracle.com/en-us/iaas/Content/Functions/Tasks/functionsmonitoringcapacityusage_topic-Monitoring-concurrent-function-execution.htm))
- the overall total amount of memory that is available for provisioned concurrency for all functions in a region, and how much memory has been allocated for provisioned concurrency (see[Monitoring Memory Usage and Availability for Provisioned Concurrency](https://docs.oracle.com/en-us/iaas/Content/Functions/Tasks/functionsmonitoringcapacityusage_topic-Monitoring-provisioned-concurrency.htm)
