# Physical Security

Use the following physical security requirements for Oracle-occupied areas.

Requirement Area Requirement Details
Security staffing Provide continuous 24x7x365 physical security monitoring. Security personnel must be trained to follow and enforce security policy.
Facility entry control Control entry into the facility by using security staff and badging. Oracle-occupied areas must not be accessible through general, uncontrolled access routes.
Room construction Avoid outward-facing windows and glass doors for data center floor space and storage areas. If the Oracle data hall is on the ground floor and has an exterior-facing wall, exterior fencing is required.
Visitor management Issue visitor and vendor badges individually after verifying government-issued identification. Retain visitor logs for at least 3 months and make logs available for review on request.
Badge logging Retain access records that identify the person, location, and time of access. If badges resolve only to a badge ID or number, retain the associated identity records for the same retention period.
