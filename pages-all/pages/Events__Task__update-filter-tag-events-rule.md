# Editing a Filter Tag for an Events Rule

Update a filter tag for a rule.

See[Matching Events with Filters](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Concepts/filterevents.htm)for more information on using filter tags in a rule.

- [Console](https://docs.oracle.com/en-us/iaas/Content/Events/Task/update-filter-tag-events-rule.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/Events/Task/update-filter-tag-events-rule.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/Events/Task/update-filter-tag-events-rule.htm#)
- 

- Navigate to the events list page. If you need help finding the list page, see[Listing Events Rules](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Task/list-events-rule.htm).
- Select a rule and then select Conditions .
- Under Filter Tags , select the checkbox next to the filter tags you want to edit.
Tip  
  
To select the entire list, select the checkbox in the header row.
- From the the Actions menu (three dots) , select Edit .
- Make your changes and select Save Changes .
- 

See[Matching Events with Filters](https://docs.oracle.com/en-us/iaas/Content/Events/Task/../Concepts/filterevents.htm)for information on how to use filter tags.
