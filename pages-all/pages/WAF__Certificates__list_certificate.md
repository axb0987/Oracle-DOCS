# Listing Web Application Firewall Certificate

Describes how to display a list of certificates for a web application firewall policy.

- [Console](https://docs.oracle.com/en-us/iaas/Content/WAF/Certificates/list_certificate.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/WAF/Certificates/list_certificate.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/WAF/Certificates/list_certificate.htm#)
- 

- Open the navigation menu and select Identity &amp; Security . Under Web Application Firewall , select Edge Policy Resources .
The Policies list opens. All edge policies are listed in a table.
- Select the Compartment from the list.

The WAF Certificates page appears.
- Select Certificate under Resources .

All the certificates in that compartment are listed in tabular form.

The WAF Certificates list displayed shows the Name , Status , Expires On , and Created dates (UTC date timestamp) information for each entry.
