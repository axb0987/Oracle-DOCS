# Fiber Optic Cabling

Fiber readiness combines capacity, diversity, testing, and clear labeling so circuits can be installed, operated, and expanded without ambiguity.

Requirement Area Requirement Details
Fiber type Install dedicated SMF from the MMR to Oracle space. All fiber optic cabling for these pathways must be SMF.
Path A Provide a dedicated A-path fiber run from the MMR to Oracle space. Minimum 48 strands terminating in panel A on the Oracle cage or suite and panel A in the MMR.
Path B Provide a dedicated B-path fiber run from the MMR to Oracle space. Minimum 48 strands terminating in panel B on the Oracle cage or suite and panel B in the MMR.
Scope confirmation Expect final quantities and terminations to be confirmed during deployment design. Oracle provides the final fiber quantities and termination locations in the scope of work.
Testing Test installed fiber to Oracle specifications before handover. Oracle Data Center Engineering Services provides the applicable test criteria.
Labeling Label all cross-connects at the Oracle demarcation patch panels. Labels must include the circuit ID, A-side and Z-side patch panel ports, and A-side and Z-side rack locations.
Documentation Maintain route and termination records for all trunks and cross-connects. Provide information for all termination points and cable routing paths so the plant can be supported and expanded cleanly.
