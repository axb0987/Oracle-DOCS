# Accessing Host Capacity Planning Resources

In the left pane, when you click Capacity Planning , and then click Hosts , the Hosts navigation options are displayed.
The following pages comprise the hosts Capacity Planning application of Ops Insights:
- Summary
- CPU
- Storage
- Memory
- I/O
- Host Explorer

Use the Applied filters bar at the top of the page to define the global scope and filters shared across the Capacity Planning application:
- Compartment : Scopes Capacity Planning to hosts enabled for Ops Insights in the selected compartment.

In the Compartment applied filter, select Include child compartments to include hosts in child compartments when enabled.
- Date : Defines the time range for the data shown.
- Platform type : Filters hosts by operating system platform type. For a complete list see:[Supported Configurations for Ops Insights](https://docs.oracle.com/iaas/operations-insights/doc/supported-configurations-operations-insights.html#GUID-BC1ACC9D-F08A-4329-900D-82770C0DB56A).
- Host by entity : Filters hosts by related host entities, such as host name.
- Ops Insights state : Filters hosts by Ops Insights state, such as Enabled.
- Created by : Filters hosts by how they were enabled or created.
- Tag filter : Adds a tag filter to filter hosts by defined or free-form tags.
