# Sharing a Default Metric Chart

Share a default metric chart from the Console by copying its URL. Default metric charts are available on the Service Metrics page and resource details pages in the Console.

Note  
  
To view the chart, the person you share the chart URL with must have the required IAM policies for access to metrics.

- View default metric charts in one of the following ways:
- [Open](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/view-chart-namespace.htm)the Service Metrics page.
- [Go to the Metrics area on the details page for a resource.
- In the chart, select Options and select Copy chart URL .
