# Removing Apps from the Policy

You can remove apps from an identity provider policy. After removal, any user who used the apps will no longer be able to authenticate into the identity domain using the identity providers assigned to the policy.

- On the Identity provider (IdP) policies list page, select the policy from which you want to remove apps. If you need help finding the list page, see[Listing Identity Provider Policies](https://docs.oracle.com/en-us/iaas/Content/Identity/idppolicies/list-idp-policies.htm#console).
- Perform one of the following actions depending on the options that you see:
- Select Applications .
- Under Resources , select Apps .
- Select each app that you want to remove from the policy.
- Select Remove app .
