# Setting up Email Submissions

Use OCI Email Delivery for a fast and reliable managed solution to submit secure, high-volume marketing, and transactional emails using the Hypertext Transfer Protocol Secure (HTTPS) interface or the Simple Mail Transfer Protocol (SMTP) interface.

We recommend to use the HTTPS over SMTP endpoint for your development as it streamlines your development with a restful endpoint, and provides more options for authentications.

Set up[HTTPS email submissions](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/../Concepts/email-submission-using-https.htm)or create[SMTP credentials](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/gettingstarted_topic-Configure_the_SMTP_connection.htm#smtp)and[set up SMTP email submissions](https://docs.oracle.com/en-us/iaas/Content/Email/Reference/../Concepts/email-submission-using-smtp.htm)
