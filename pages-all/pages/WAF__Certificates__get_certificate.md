# Getting a Web Application Firewall Certificate's Details

Describes how to get the details of a certificate for a web application firewall policy.

- [Console](https://docs.oracle.com/en-us/iaas/Content/WAF/Certificates/get_certificate.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/WAF/Certificates/get_certificate.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/WAF/Certificates/get_certificate.htm#)
- 

- Open the navigation menu and select Identity &amp; Security . Under Web Application Firewall , select Edge Policy Resources .
The Policies list opens. All edge policies are listed in a table.
- Select the Compartment from the list.

The WAF Certificates page appears.
- Select Certificate under Resources .

All the certificates in that compartment are listed in tabular form.
- Select the certificate whose details you want to get.

The WAF Certificate Details dialog box appears.

The Details page contains information about the certificate, both general information and links to its resources. Some items in the page are read-only, while other items allow you to edit and update the certificate configuration.
