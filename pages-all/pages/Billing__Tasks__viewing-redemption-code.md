# Viewing the Redemption Code for Support Rewards

Customers need a redemption code to apply accrued rewards toward support invoices in the Billing Center system.

New Oracle Cloud Console users can obtain the redemption code in either the new user authorization email that they receive, or by using Oracle Support Rewards in the Console. Existing users can view the redemption code only in the Console.

For[Multicloud](https://docs.oracle.com/iaas/Content/multicloud/Oraclemulticloud.htm)customers that want to confirm if they're enrolled in Oracle Support Rewards through a Multicloud order, you will have one redemption code assigned to your Multicloud subscription, in addition to your Oracle Universal Credits subscription. Your[redemption user](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/create-redeemable-user.htm)must be authorized on both subscriptions to redeem all support rewards. For more information, see[Redeeming Rewards](https://docs.oracle.com/en-us/iaas/Content/Billing/Tasks/redeem_rewards.htm).

- 

- Open the navigation menu and select Billing &amp; Cost Management . Under Programs and Rewards , select Oracle Support Rewards .
- On the Oracle Support Rewards page, select View redemption code .
- In the View redemption code panel, for Redemption code , select Show or Copy .
- 

This task isn't available in the CLI.
- 

For monthly reward details and the corresponding`redemptionCode`attribute related to viewing the redemption code, see[RewardDetails](https://docs.oracle.com/iaas/api/#/en/usage-proxy/latest/datatypes/RewardDetails)
