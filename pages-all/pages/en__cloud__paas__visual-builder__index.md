# Oracle Visual Builder Studio

## What do you want to do?

Oracle Visual Builder Studio (VB Studio) brings you all the functionality previously available with Oracle Developer Cloud Service and Oracle Visual Builder, along with the ability to extend certain Oracle Cloud Applications to customize the UI for your business needs.
