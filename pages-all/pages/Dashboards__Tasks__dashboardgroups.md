# Working with Console Dashboards Groups

Dashboard groups let you share collections of dashboards with designated groups of people.

For example, each team within an organization can have its own dashboard group. Use IAM polices to control membership in dashboard groups and access to dashboards. The following topics explain how to create, edit, and manage your dashboard groups:
- [Creating a Dashboard Group](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/create-dashboard-group.htm#top)
- [Listing Dashboard Groups](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/listing-dashboard-groups.htm#top)
- [Getting a Dashboard Group's Details](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/getting-dashboard-group-details.htm#top)
- [Editing a Dashboard Group](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/edit-dashboard-group.htm#top)
- [Deleting a Dashboard Group](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/delete-dashboard-group.htm#top)
- [Moving a Dashboard Group Between Compartments](https://docs.oracle.com/en-us/iaas/Content/Dashboards/Tasks/move-dashboard-group.htm#top)
