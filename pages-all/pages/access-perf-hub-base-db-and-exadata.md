# For Base Database Service and Exadata Databases

To access Performance Hub for Base Database Service and Exadata databases:
- 

Open the navigation menu and click Oracle AI Database .
- 

Select the type of database that you are managing.
- 

Select your Compartment .
- 

Access the database details page for Base Database Service or Exadata databases.
For Base Database Service:
- Click a DB system name . The DB system page is displayed.
- In the list of databases, click a database name . The database details page is displayed.
For Exadata:
- 

Click the VM Cluster .
- 

Click the database name. The database details page is displayed.

Note  
  

The Associated Services section on the database details page shows the status of the Database Management service, whether the service is enabled for the database. It also shows which database management option (Basic or Full) is enabled.
- 

If Database Management is Enabled , then you can click Disable to disable it.
- 

If Database Management is Disabled , then you can click Enable to enable it.

Click Edit to display the Edit Database Management page. For information about changing database management settings, see About Management Options in[Enable Database Management](https://docs.oracle.com/pls/topic/lookup?ctx=en/cloud/paas/database-common/performancehub&id=oci-enable-db-mgmt).
- 

On the details page of the database, click Performance Hub to open the Performance Hub page.

Note  
  

Performance Hub is enabled only under the following conditions.
- The Database Management service must be enabled.
- The database must be an Enterprise Edition, version 12.1.0.0.0 or later.

Note  
  

To exit the Performance Hub page and to go back to the database details page, click Close at the bottom-left of the page.
