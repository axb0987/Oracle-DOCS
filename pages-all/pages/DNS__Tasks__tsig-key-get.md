# Getting a TSIG Key's Details

View details for a specific TSIG key.

See[Managing TSIG Keys](https://docs.oracle.com/en-us/iaas/Content/DNS/Tasks/tsig.htm)for more information about TSIG keys and how they're used in zones.

For general service information, see the[DNS Service Overview](https://docs.oracle.com/en-us/iaas/Content/DNS/Tasks/../Concepts/dnszonemanagement.htm).

- [Console](https://docs.oracle.com/en-us/iaas/Content/DNS/Tasks/tsig-key-get.htm#)
- [CLI](https://docs.oracle.com/en-us/iaas/Content/DNS/Tasks/tsig-key-get.htm#)
- [API](https://docs.oracle.com/en-us/iaas/Content/DNS/Tasks/tsig-key-get.htm#)
- 

On the TSIG keys list page, select the key you want to work with. If you need help finding the list page, see[Listing TSIG Keys](https://docs.oracle.com/en-us/iaas/Content/DNS/Tasks/tsig-key-list.htm#top).
The details page contains information about the TSIG key, both general information and links to its resources. Some items in the page are read-only, and other items are editable. See[Editing a TSIG Key](https://docs.oracle.com/en-us/iaas/Content/DNS/Tasks/tsig-key-update.htm).
