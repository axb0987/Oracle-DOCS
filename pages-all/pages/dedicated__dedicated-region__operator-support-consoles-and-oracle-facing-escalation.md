# Operator Support Consoles and Oracle-Facing Escalation

Use operator-facing support tools when customer requests require operator review, Fusion support processing, My Oracle Cloud Support coordination, phone status follow-up, or curated OCI knowledge assistance.

Support Channel Use Operational Notes
Fusion Support Use Fusion Support to view and process support requests that customers submit through the Customer Console. From the Operator Console home page, open Fusion Support under My tools, complete authentication, and use the Fusion Console Service Requests site. Bookmark the Fusion Console URL only when direct future access is required.
Phone SR status follow-up Use phone support when an Oracle-facing SR requires a status update or Duty Manager callback. Find the local Oracle Support number, call the support line, and follow the Sovereign / Alloy route when prompted. Provide the Group ID from My Oracle Cloud Support user-group preferences, then provide the ask, business impact, ticket number, and contact details to the support agent.
Dedicated Region Realms Support Chatbot Use the chatbot for OCI service questions that can be answered from curated knowledge content. Open the Customer Console Help icon, select Chat with us, enter the OCI question, and end the chat after the answer is sufficient. Use Dedicated Region documentation, not the chatbot, for Dedicated Region administration questions.
Oracle-facing escalation records Use when escalating from an internal or customer-facing SR to Oracle support. Retain the SR number, business impact, tenancy or subscription context, Group ID when used, contact details, and current status. Minimize customer data in Oracle-facing records and include only the information required for triage.
