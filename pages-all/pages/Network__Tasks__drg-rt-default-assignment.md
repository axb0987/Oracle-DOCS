# Changing Route Table Assignment Defaults for DRG Attachments

Learn to change the default route table assignments for DRG attachments.

By default, VCN attachments are assigned the Autogenerated Drg Route Table for VCN attachments . Also by default, remote peering connection attachments, virtual circuit attachments, and IPSec tunnel attachments are assigned the Autogenerated Drg Route Table for RPC, VC, and IPSec attachments . You can't customize the DRG route table for loopback attachments or cross-tenancy attachments

When you change the default DRG route table for an attachment type, this changes the default for new resources of that type. All future attachments of that attachment type use the new default route table. Existing attachments continue to use the same route table assigned when they were created. You can change the route table assignment for an existing attachment using the steps described in[Updating a DRG Attachment](https://docs.oracle.com/en-us/iaas/Content/Network/Tasks/drg-update-attachment.htm).
