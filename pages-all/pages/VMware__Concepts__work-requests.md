# VMware Solution SDDC Work Requests

Use the Oracle Cloud Infrastructure Console, CLI, or API to manage work requests for SDDCs, VLANs, and ESXi hosts.

Work requests let you monitor long-running operations. When you start such an operation, the service spawns a work request . A work request is an activity log that lets you track each step in the operation's progress. Each work request has an OCID (Oracle Cloud Identifier) that lets you interact with it programmatically and use it for automation. Work requests are retained for 12 hours.

To use Oracle Cloud Infrastructure, an administrator must be a member of a group granted security access in a policy by a tenancy administrator. This access is required whether you're using the Console or the REST API with an SDK, CLI, or other tool. If you get a message that you don't have permission or are unauthorized, verify with the tenancy administrator what type of access you have and which compartment your access works in.

For more information and examples of OCI IAM policies you can use to create, change, and delete VMware Solution resources, see[VMware Solution Identity and Access Management (IAM) Policies](https://docs.oracle.com/en-us/iaas/Content/VMware/Concepts/../Reference/iam-policy-reference.htm).
