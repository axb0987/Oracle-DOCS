# Listing Trusted Partner Certificates

Retrieve a list of Trusted Partner Certificates.

- On the Domains list page, select the name of the identity domain that you want to work in. If you need help finding the list page or the domain, see[Listing Identity Domains](https://docs.oracle.com/en-us/iaas/Content/Identity/trustedpartnercert/../domains/to-view-identity-domains.htm).
- Perform one of the following actions depending on the options that you see:
- On the Security tab, scroll to view the trusted partner certificates.
- Select Settings and then select Trusted partner certificates .
