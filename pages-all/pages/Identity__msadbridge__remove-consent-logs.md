# Remove Consent to Sharing Client Logs

Remove consent for Oracle to fetch AD bridge client log files.

- From the Windows Start menu, open the AD bridge client from Identity Cloud Service Microsoft Active Directory Bridge .
- Under Share Client Logs , clear Upload client logs and select Update .
