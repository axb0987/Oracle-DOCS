# Getting a Resource Collection's Details

Get a resource collection's details to learn more about it.

## Using the Console

On the Resource collections list page, select the name of the resource collection for which you want to view details. If you need help finding the list page, see[Listing Resource Collections](https://docs.oracle.com/en-us/iaas/Content/Search/Tasks/list-resource-collections.htm).
The details page of the resource collection displays the following information:
- The friendly name of the resource collection.
- The current lifecycle state of the resource collection.
- Description: A description of the resource collection.
- OCID: The OCID of the resource collection, if the resource collection exists in a compartment in the tenancy.
- Type: Whether the resource is personal or in a compartment, which affects who can see and use it.
- Compartment: The compartment where the resource collection exists, if it was published in a compartment.
- Date created: When the resource collection was created.
- Last updated: When the resource collection was last updated.
- Search query: The query syntax that produced the results in the resource collection. All resource collections save search criteria in the form of an advanced resource query, even if you created a resource collection based on a search performed in basic search mode.
- A search box that you can use to update the resource collection's search query and results by searching or filtering in basic search mode or using query language in advanced query mode.
- Applied filters: What filters are applied to the search to help produce the results in the resource collection.
- Actions : A menu of bulk actions that you can perform on the results in the resource collection.
- A list of resource results that match the search query.
