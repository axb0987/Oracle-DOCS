# Getting a Job's Details

Review the details for a specific job, copy the Oracle Cloud Identifier (OCID) and download a job file for a job in an identity domain in IAM.

- On the Jobs list page, select the job that you want to work with. If you need help finding the list page or the job, see[Listing Jobs](https://docs.oracle.com/en-us/iaas/Content/Identity/jobs/list-jobs.htm).
