# Introduction to Oracle Autonomous AI Database on Exadata Cloud@Customer

Autonomous AI Database offers a fully autonomous, easy-to-use database solution that delivers fast query performance, scales elastically, and eliminates the need for manual database administration.

Oracle Autonomous AI Database on Cloud@Customer provides a highly automated, fully managed database environment running on Oracle Cloud Infrastructure (OCI) with dedicated hardware and software resources. This isolation enables organizations to meet stringent security, availability, and performance requirements—while also reducing operational complexity and cost.
Note  
  
To avoid duplication and deliver a more streamlined, consistent experience, content related to Oracle Autonomous AI Database on Exadata Cloud@Customer has been removed from this guide. Going forward, refer to the[Oracle Autonomous Database on Dedicated Exadata Infrastructure](https://docs.oracle.com/en/cloud/paas/autonomous-database/dedicated/adbaa/index.html)documentation, which now serves as the authoritative source for the most current guidance.

Autonomous AI Database features are largely consistent across Oracle Public Cloud and Exadata Cloud@Customer deployments, with a few differences. Where applicable, these differences are explicitly highlighted using badges.
