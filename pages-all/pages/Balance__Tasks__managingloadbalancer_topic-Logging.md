# Logging for Load Balancers

Manage access and error logs for load balancers using the Oracle Cloud Infrastructure Console.

The Load Balancer service uses the Oracle Cloud Infrastructure Logging service to manage logging. See[Logging Overview](https://docs.oracle.com/iaas/Content/Logging/Concepts/loggingoverview.htm)for general information on logging, including how to name log files and create log groups.

See[Details for Load Balancer Logs](https://docs.oracle.com/iaas/Content/Logging/Reference/details_for_load_balancer_logs.htm)for information on how to understand load balancer log entries.

No other policies are required to enable logging. You need to have permission to configure the load balancer.
Note  
  
Logging is an option in the Load Balancer service. Standard limits, restrictions, and rates apply when enabling the logging features. See[Oracle Cloud Infrastructure Logging](https://www.oracle.com/devops/logging/)for more information.

You can perform the following log management tasks:

[Display the logs in a load balancer](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/list-log.htm).

[Enable a log for a load balancer](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/create_log.htm).

[View a log's details](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/get_log.htm).

[Update a log's settings](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/edit_log.htm).

[Delete a log from a load balancer](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/delete_log.htm).

[Disable or re-enable a logging a load balancer's log](https://docs.oracle.com/en-us/iaas/Content/Balance/Tasks/disable_log.htm)
