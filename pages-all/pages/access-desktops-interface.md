# Accessing the Secure Desktops Interface

Use the Secure Desktops interface to connect to your virtual desktop. Log in using the URL and credentials provided by your desktop administrator.

- Using a[supported browser](https://docs.oracle.com/iaas/Content/GSG/Tasks/signinginIdentityDomain.htm#identity_faq_technical_issues_and_troubleshooting), go to the URL supplied by your desktop administrator.
`https://published.desktops. <region-id> .oci.oraclecloud.com`

Where`<region-id>`is your region identifier.

For example, for the US East (Ashburn) region:

`https://published.desktops.us-ashburn-1.oci.oraclecloud.com`

For a list of available regions and their identifiers, see[Availability](https://docs.oracle.com/iaas/secure-desktops/overview-secure-desktops.htm#availability).

For a list of optional parameters that can be added to the URL, see[Providing Access to Users](https://docs.oracle.com/iaas/secure-desktops/provide-user-access.htm#provide-access).
- If prompted, enter the Oracle Cloud Infrastructure tenancy name and select Continue .
- Sign in with your user credentials.
- Use the interface to[open your desktop](https://docs.oracle.com/iaas/secure-desktops/connect-to-desktop.htm#connect-to-desktop)
