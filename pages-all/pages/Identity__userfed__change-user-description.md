# Changing a user's description

Change a user's description.
- On the Users list page, select the user whose capabilities you want to edit. The user's details are displayed. The description is displayed under the user's sign in. If you need help finding the list page, see[Listing Provisioned Federated Users in the Console](https://docs.oracle.com/en-us/iaas/Content/Identity/userfed/viewing-provisioned-federated-users.htm).
- Select the user you want to update.
- Select Edit user .
- Select Description .
