# Managing External Key Management Vaults

Learn about managing vaults that hold External Key Management Service (EKMS) key references.

The OCI External Key Management System (KMS) lets you to create a vault of type "External" that holds the key references for the actual keys in your external key manager.
Following are the topics related to managing vault in External KMS:

- [Replicating an External Key Management Vault](https://docs.oracle.com/en-us/iaas/Content/KeyManagement/Tasks/ekms_replicate_vault.htm)
