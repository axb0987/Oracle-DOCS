# Verified CPE Devices

Note  
  
Oracle provides configuration instructions for the vendors and devices in the following table. Ensure that you use the configuration instructions for the correct vendor.

If the vendor, device, or software version isn't in the following table, the device might still work with Oracle Cloud Infrastructure Site-to-Site VPN. Consult the vendor's documentation for configuration help and see[supported IPSec parameters](https://docs.oracle.com/en-us/iaas/Content/Network/Reference/supportedIPsecparams.htm)for supported phase 1 and phase 2 configurations parameters for Site-to-Site VPN.
