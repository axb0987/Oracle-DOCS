# To create an IAM Database User Name

Use the Console to create a database user name.

To change your IAM database username:
- Log in to the OCI IAM console.
- Select Identity&amp; Security .
- Under Identity , select Users .
- In the table of database users, select Create User .
- In the Name field, enter your database user name. Enter only letters, numerals, hyphens, periods, underscores, +, and @. You cannot use spaces in the name.
- In the Description field, optionally enter the name of the database that this user name is for or any other relevant information.
- Optionally select Advanced Options to show the Tags dialog box.
- In the Tag Namespace, Tag Key, and Value fields, enter a tag name
