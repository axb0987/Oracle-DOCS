# Listing Users

Learn how to list users in an HSM partition with the Dedicated KMS user management utility.

The`listUsers`command gets users in each HSM partition along with user type and other attributes.

In the User Management utility, open a command prompt and run`listUsers`command display a list of current users. The command displays users based on the mode you run the command. In server mode, the system displays current users of a specific HSM and in Global mode, the system displays current users of all HSMs.
