# Changing the Interval for a Default Metric Chart

Change the time window for aggregating metric data points plotted on a default metric chart. Default metric charts are available on the Service Metrics page and resource details pages in the Console.

- View default metric charts in one of the following ways:
- [Open](https://docs.oracle.com/iaas/Content/Monitoring/Tasks/view-chart-namespace.htm)the Service Metrics page.
- [Go to the Metrics area on the details page for a resource.
- For Interval : Select the aggregation window, or the frequency at which data points are aggregated. You can create a custom interval if needed. See also[Interval](https://docs.oracle.com/iaas/Content/Monitoring/Reference/mql.htm#Interval).

For information about directly editing MQL expressions or changing queries by using the CLI or API, see[Selecting the Interval for a Query](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/query-metric-interval.htm). For more information about the interval query component, see[(Monitoring Query Language (MQL) Reference)](https://docs.oracle.com/en-us/iaas/Content/Monitoring/Tasks/../Reference/mql.htm#Interval)
