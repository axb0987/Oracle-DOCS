# To create an IAM Database Password

Use the Console to create a database password.

You can create an IAM database password to meet the Oracle Database password-creation guidelines.
- Log in to the OCI IAM console.
- In the upper right corner of the window, select the profile icon to display your user profile page.
- In your user profile page, select your user name.
- Under Resources , select Database Passwords.
- In the Database Passwords section, select Create Database Password.

The Create Database Password dialog box is displayed.
- Enter a description of the password.
- Note the password guidelines and restrictions listed on the page. See[Creating an IAM database password](https://docs.oracle.com/en-us/iaas/Content/Identity/Tasks/../Concepts/usercredentials_topic-creating_a_database_password.htm)for more information about password rules.
- Select Create Database Password.
